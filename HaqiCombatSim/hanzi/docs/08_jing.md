# 08 · 径（`jìng`）—— 曲径通幽，步步生苔（`hanzi_jing.html` 精品重制版）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：径；拼音：`jìng`；本义：步道，林间或田野仅容步行的小路；引申为直接（径直）、穿过圆心的线段（直径）。
   - 《说文解字·彳部》：“径，步道也。从彳，巠声。”
   - 诗意典故：唐·常建《题破山寺后禅院》“曲径通幽处，禅房花木深”。页面在词意幕注明出处，不将唐诗当作字源史实。
2. **古文字演进与规范楷书（8 笔）**
   - **甲骨文 / 金文部件源流**：
     - 左部 **「彳」**（`chì`）：甲骨文「行」象十字通衢之形，取其左半即为「彳」，表示道路与迈步前行，是全字的意义线索。
     - 右部 **「巠」**（`jīng`，规范简化作右上横撇、点与下「工」）：金文与小篆象织机上纵向绷直的经线，在「径」中作为声音线索（`jīng` 与 `jìng` 音近），同时“一条细线纵贯上下”亦帮助记忆“细长步道”之意。
   - **小篆**：左「彳」三笔柔韧相随，右「巠」上承川流纹理、下立织机经架，规整秀逸。
   - **规范楷书（8 笔，严格核对 Make Me a Hanzi 轮廓与中线）**：
     1. 撇（彳上撇） 2. 撇（彳下撇） 3. 竖（彳垂露竖） 4. 横撇（右部上） 5. 点（右部上长点） 6. 横（工上横） 7. 竖（工中竖） 8. 横（工底长横）。
   - 笔画轮廓与中线内联自 `skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（1024 字框，基线 900）。
3. **事实与艺术边界**
   - 左下角与成字幕清晰区分：“左边「彳」与道路行走有关，右边「巠」提示读音；竹林石径画面为艺术联想，书写使用现代规范字形。”

## 二、一句话主题

> 烟雨初歇的翠竹深处本没有现成的路，戴竹笠的孩子踩着覆苔青石一步一步往前走，身后的脚印串成发光的来路，拨开垂竹，便遇见溪畔亮着暖灯的幽亭——路，是走出来的。

## 三、美术升级重点（对齐《云》《森》《光》艺术标杆）

1. **江南烟雨青绿洒金宣纸长卷**：
   - 离屏生成**竹青宣纸纤维 + 细碎冷金洒金肌理**（`multiply` 叠印），配合四角烟墨暗晕，取代旧版纯色平涂。
   - **五层视差景深**：远景烟雨黛山与流岚 → 中远景疏密有致的墨竹林影 → 中景清溪流泉、落花锦鲤、拱形编竹小桥与十块覆苔青石板 → 中近景飞檐竹亭（亭内石案茶烟袅袅、暖琥珀纱灯摇曳）→ 近景带雨珠摇曳的修竹枝叶与流萤晨尘。
2. **光影与动态细节**：
   - 每踏上一块青石，石面青苔泛起温润玉色涟漪，身后浮现金色步迹流光丝线；溪中红鲤闻步轻游，竹叶震落晶莹露珠。
   - 拨开垂竹帘幕支持**手势横向拂拨**与点击/键盘双通道，竹影随指尖左右分披，晨曦丁达尔金光自竹梢斜射入亭。

## 四、分镜（七幕 · 约 2.5–3 分钟）

| 进度 | 场景 | 画面与字幕 | 互动 |
|---|---|---|---|
| 片头 | `introPlay` | 烟雨竹林长卷上晨雾轻流，金色笔意缓缓书出「径」，指针移动时竹影与流萤轻随 | 点击「开始」进入正片；片头绝不触发 `written` / `completed` |
| 入林 | `sGate` | 清晨竹林薄雾笼罩，林口露出第一块覆苔青石。“清晨的竹林，薄雾还没有散。”“林子深处藏着一条小路，通向安静的地方。” | 观看镜头推入竹径起点 |
| 曲径 | `sPath` | S 形青石小径隐在竹影与清溪拱桥之间 | **互动 1（踩石寻径）**：依次点亮 6 块青石（或点按钮/空格），孩子逐石前行、跨过竹桥惊起红鲤，身后连成一条温润发光的曲径；闲置自动前行 |
| 通幽 | `sReveal` | 曲径尽头垂竹成帘，竹后透出一点暖琥珀灯火 | **互动 2（拨竹见亭）**：按住横向拂开垂竹（或点按钮“拨开竹叶”），竹叶分披、晨光斜照，溪畔竹亭与袅袅茶烟豁然显现；闲置自动拨开 |
| 成字 | `sGlyph` | 身后发光的曲径与路口化作左部「彳」，纵贯的经线化作右部「巠」，历经甲骨/金文 → 竹简小篆（引《说文》“径，步道也。”）→ 宣纸楷书八笔，分色标注「彳」与「巠」 | 观看古今演进与形声拆解 |
| 写字 | `sWrite` | 八笔描红：撇、撇、竖、横撇、点、横、竖、横 | **互动 3（八笔描红）**：宽容趋势投影描红，完成后盖朱砂「径」印并触发 `haqiHanziWritten()` |
| 词意 | `sWords` | 依次呈现 `小径`、`径直`、`曲径通幽`（注明唐·常建诗句），竹林天色随词由晨雾转为晴翠与暖金 | 逐词与字幕严格同步 |
| 余韵 | `sFinale` | 孩子在竹亭中提灯远望，来路如星河般蜿蜒林间 | **自由互动**：点击竹林摇落露珠、惊起流萤与清越竹音；触发 `haqiHanziComplete()` |
