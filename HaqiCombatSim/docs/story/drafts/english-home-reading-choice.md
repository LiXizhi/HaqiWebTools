# 今天想读书吗

家园独立对话故事 `en-l1-my-reading-choice`，使用已学 want/read/book。孩子可以愿意或暂时不愿意读书，两个答案均为有效表达，不将否定意愿判错。不新增新词、奖励或强制活动。

开场：“我有点想看书，你呢？你可以想和我一起看，也可以今天不想看。告诉我你的主意吧。”

- 请求：Read with me?
- 愿意：I want to read. → Yes. We can choose a book.（好呀。我们可以挑一本书。）
- 暂时不愿意：I do not want to read. / I don't want to read. → OK. We can do something else.（好的。我们可以做别的事情。）

两种回应都尊重孩子的意愿，结束后回到选择玩法。仅当正确表达并听完原伙伴回应才记录 want/read 一次。没有真实阅读动作，因此不声称已经看过书；book 是辅助词，不计有效练习。退出、错误和重复回调不计完成。

实现：既有 alternatives 可为 talk 模式增加 reply/replyGloss，必须完整且答案无歧义。每轮根据本次实际回答选择回应，不改变动作、目标词或下一步身份。旧替代表达未提供分支回应时仍沿用原回应。故事导出记录分支台词来源，角色或会话失效时仍走原取消流程。

边界：这是有限作者分支，不是自由聊天。没有将意愿长期保存成性格或偏好，不按一次“不想读”改变今后课程。其他邀请式故事仍需逐篇审核，不能宣称所有选择都已经有分支。

正式场景 S2838。
