## 验证入口

- [testing.md](testing.md)：本轮命令、通过范围、基准数据与限制。
- `tests/parity/formulas.test.mjs`：直接从原文件提取 Lua 函数执行比较，非手抄预期值。
- `tests/engine/`、`tests/simulation/`：平台确定性、回放、非法动作、补丁、采样分片。
- `tests/browser/`：真实 Chrome、Worker/Node 对照、候选复测、取消、移动端、离线、万场性能。
- `data/manifests/`：逐文件源 hash、缺项、加载顺序、效果能力清单。
