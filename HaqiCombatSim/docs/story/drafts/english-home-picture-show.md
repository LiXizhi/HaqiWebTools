# 画完以后，介绍给伙伴

man、woman、baby各增加四幕家园创作故事：选纸、真实保存画作、原纸人物标签、回应伙伴并实际指认原画。成年男子是“雨伞下的来客”，成年女子是“远航者的第一封信”，宝宝是“宝宝也在故事里”。人物的样子、用品和后续情节由孩子创作，职业、衣服、发型不作为性别或年龄判定依据。

每个故事最多首次介绍paper、draw和一个人物词；末幕复现人物词，不引入第四个新词。接受A man.和This is a man.等短句；语音和文字均可。对应人物词另有两次标签回访。

七个人物词boy/girl/child/person/man/woman/baby共用“介绍自己的画”复习：只选已学词、已保存笔画、标签明确匹配该人物词的纸张。伙伴先邀请介绍，孩子可读自己的标签说出名字，再实际点选该作品。回答和指认都满足才记录；展示、试听、不指认、指别张画、标签或笔画变更均不计本轮完成。

作者开关readCharacterLabel只允许人物词、find模式与requiresDrawing，不用于未知词首次测试。运行时冻结原纸标签与笔画，后续任何变化使原结果失效。标签本身可见，所以该轮属于有支架的作品介绍；不得伪装成无提示看图辨认，不识别画中的真实性别、年龄或内容。

连续故事和普通回访使用独立稳定身份，原四个人物画室不追加阶段，不改变已完成的故事长度。当前修桥、远航、避雨和照顾宝宝仍是创作题材，不是已实现世界行为。
