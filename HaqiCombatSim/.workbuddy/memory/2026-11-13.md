## 汉字「孙」动画重做（hanzi/hanzi_sun.html）

用户反馈旧版「奶奶的燕子风筝」做得不好，要求重制、不限定 3D、要有艺术美感。

**改法**：弃用风筝隐喻（风筝与「糸」无形体关系），改为**纯 Canvas 2D**「灯下缫丝」——
蚕室 → 缫丝 → 相续 → 成字 → 写字 → 词意 → 余韵七幕。字义本身就是「一根连续的丝」，
一条能被抽出、接长、交到孩子手里的线比空间景深更能解释它，故不上 3D。

**关键实现约定（后续同类页可复用）**：
- 简繁字形都用 makemeahanzi 固定 commit `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`：
  `孙` 6 笔、`孫` 10 笔，繁体不再用系统字体贴字。繁体 SVG 可从
  `raw.githubusercontent.com/skishore/makemeahanzi/<commit>/svgs/23403.svg` 取，
  clipPath 内是轮廓、`make-me-a-hanzi-animation-N` 的 d 是中线。
- 横幅 / 竖幅两套布局常量 `LAYOUT_WIDE` / `LAYOUT_TALL` + 两套机位 `VIEW` / `VIEW_TALL`；
  竖屏必须单独排锚点，否则丝车、丝结、孩子会被裁出画外。长案与地面要铺到画外避免露底。
- 剪影手臂末端由「要够到的目标点」反算（奶奶手跟摇柄转、孩子手落在丝头），
  比固定姿势自然得多。
- 叶缘缺口必须做进轮廓（`LEAF_EDGE` 按 bite 收缩控制点），
  **不能**事后盖色块或用 `destination-out`——前者留黑点，后者打穿整个背景。
- 竹简阶段的字必须换深墨：浅底浅字看不见（`inkOnSlip` 插值）。

## 汉字「泉」动画（hanzi/hanzi_quan.html，2217 行，新建）

月夜山水 + 粒子水流，纯 Canvas 2D 七幕：空山 → 寻声 → 泉涌 → 成字 → 写字 → 词意 → 余韵。
字形「白（泉穴）+ 水（涌流）」直接对应崖洞涌泉画面。设计说明见 `hanzi/docs/16_quan.md`。

**浏览器验收在本环境已跑通（推翻上一条"无头浏览器不可用"的结论）**：
- 可用组合：`C:/lxzsrc/keepwork-family-pad-launcher/node_modules/playwright`（1.64.1）
  + `executablePath: 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'`
  + `args:['--no-sandbox','--disable-gpu']`。本仓 node_modules 无 playwright；
  keepwork-nuxt 的 1.44.1 用 `channel:'msedge'` 启动失败。
- 脚本 `scripts/check_hanzi_quan.mjs`（`--only <tag>` 可单视口跑，`--playwright/--executable` 传路径）。
  四视口 + `?auto&fast` 全通过、控制台零异常，耗时约 45 分钟（每视口真走七幕 + 三次重播）。

**写这类验收脚本的三个坑（都踩过，务必复用）**：
1. **必须 `page.clock.install({time})` + `pauseAt()` 冻结时钟**，只靠 `runFor` 推进。
   否则 `camTo` 补间会在"取屏幕坐标"与"点击"之间继续移动相机，产生间歇性假失败。
2. **就绪判据要用真实信号**：描红幕等 `document.body.classList.contains('trace')`，
   不能只等 `glyph.ghost>0.99`——`S.handler` 是在 `await captionDone()` 之后才挂上的。
3. **别拿演出中间量当断言**：开泉后 `W.crack = 1 - t*0.4` 会回落，`crack>0.9` 永远不成立；
   应断言 `spring>0.42`（越过封泉水位）与 interactions 计数。
4. 自建 http server 用 `req.url.split('?')[0]` 匹配路径，否则 `?auto&fast` 直接 404。

**本次修掉的真实产品缺陷（不是测试问题）**：
- **竖屏主交互完全不可用**：`CV.k=max(SW/vw, SH/880)` 是 cover 语义，竖屏横向可视世界仅约 400 单位，
  而水纹横跨 806、崖壁宽 436，三处水纹连同泉眼、月亮全在屏外（实测 x=-368/444/-31）。
  修法：竖屏 `vw=700`+`SH/1240` 适配缩放、`VIEW_TALL` 六幕机位、`MOON_TALL`/`SPOTS_TALL`/
  `POOL_ROCKS_TALL`、`moonPoolX()`、流萤分布与钳位、字号放大（描红 4.3 / 词意 3.2）；
  `resize()` 切画幅时同步锚点并保留已寻得进度。
- **潭面光圈被水色盖住**：光圈原画在 `drawCliff` 内，`drawPool` 在其后填充 y≥762。
  抽出 `drawInteractHints()` 排到 `drawMist(true)` 之后、`drawVeil()` 之前。
- **天空两条黑长斜线**：`drawPine` 树干终点 `P.lean*P.h*-52` 偏移可达 815 单位，
  而针簇层偏移只有 ±30（`-2*lean*ty`），量级差 50 倍。改为 `P.lean*P.h*1.92` 与层对齐。
- 视差命中错位：`camCenter(px)` 统一投影中心，`toWorld/toScreen` 带 px，
  指针读 `S.handler.px ?? 1`（寻声/叩泉为 0.94）。
- 补 `#pause` 暂停（冻结虚拟时钟 + `Sound.setSuspended`），`begin()` 自动解暂停。
