# 象形之美

入口：[hanzi_xiangxing.html](hanzi_xiangxing.html)。原生 HTML、CSS、ES Module、Canvas 2D 与 Web Audio，无第三方依赖，无图片、视频、字体或音频下载。

在 HaqiCombatSim 根目录运行 `python -m http.server 8793 --bind 127.0.0.1`，访问 `http://127.0.0.1:8793/hanzi/hanzi_xiangxing.html`。使用 HTTP 静态服务；随机生成器复用 `../js/rng_core.js`，不能只拷贝 hanzi 目录或用 file:// 打开。无需构建。

## 改编依据

根据[奇仔的 Paracraft 作品《象形之美》](https://keepwork.com/palaka/paracraft_video/作品类/作品欣赏：象形之美)的实际视频逐段查看后重新演绎。参考视频为页面播放器提供的 `https://api.keepwork.com/ts-storage/siteFiles/22022/raw`，时长 331.2 秒。

23 段保留原片叙事次序：日山、云雨、花草、林果巢鸟、羊鹿、鱼龟、水河、人舟、犁、创、建、安、好、画书、文、乐礼、家、嫁、士、国、爸、梦、片尾。时间分段为按原片画面整理的近似边界；不是逐帧复制。字幕为本次重写的中文诗意短句。

原作中的三维方块场景改绘为程序山水长卷，配合前景动作、运镜、纸色转场与意象/现代汉字渐变。手绘意象只是艺术化说明，未声称严格复原甲骨文、金文等字形。原片音乐《龙文》与录音未复制，声音按钮启用原创实时合成五声音阶。

## 操作与实现

- 点击“展开长卷”开始，默认静音；支持暂停、拖动进度、上下景、23 段目录、倍速、全屏与重播。
- 空格播放/暂停，左右键前后 5 秒；焦点位于表单、链接或按钮时保留原生键盘操作。
- 手机自适应竖幅裁切；页面不可见时停止推进，返回后继续。系统减少动态效果时取消运镜及摇摆式镜头缩放，仍可播放影片本身。
- `xiangxing.js` 中 `shots` 管理剧情时间轴；所有动态状态由当前影片时间计算，同时间可重复渲染。画笔在浏览器层，未修改战斗模块。
- 图案采样使用固定种子 `20261014`；背景缓存只保留一张 1600×900 画布，纸纹另缓存一张。渲染 DPR 上限 2，暂停时仅在跳转、布局变化时重绘。

## 验证

`node scripts/check_hanzi_xiangxing.mjs --playwright <已安装的 playwright 包目录>`

脚本用隔离本地服务器验证桌面/手机画幅、23 景、暂停、进度、上下景、目录、倍速、音频开关、结尾与重播、键盘和同时间截图一致性。截图与报告写入 `.cache/hanzi-xiangxing/`。浏览器为本机 Edge，虚拟时钟加速检查，不代表实体手机或所有浏览器验收。
