# 走到伙伴的休息角

英语 L1 家园连续故事，作者源 english-home-practice.json；核心词 walk，结合 chair、sit。复用真实主角寻路、家具和宠物坐下，不增加传送、移动速度或假到达动画。

伙伴想选一个休息角。孩子先认识并点选椅子，再告诉伙伴 I can walk.，亲自控制主角走到那把椅子附近；最后用 Sit, please. 邀请伙伴，实际把伙伴带到原椅子上坐下。每一步先有伙伴对白，再完成英语回应和世界动作。

- D-home-walk-01：chair 是椅子；A chair. 后点选真实椅子。
- D-home-walk-02：walk 是走路；I can walk. 后选择开始散步，点击草地或用已有移动按键走到标出的目的地。
- D-home-walk-03：sit 是坐下；Sit, please. 后将伙伴拖到第一步的椅子。

每轮开始散步清除旧路线，只记录主角之后的实际连续移动。累计至少 1.5 格且到达家具外侧 1.25 格以内才可完成；这是动作验证阈值，不是语言能力标准。原地等待、点击家具、瞬移、不连续轨迹、重复帧、第二角色移动都不提供证据。目的地身份、位置、大小冻结，编辑或移除它后须重开；异步学习保存前再次核对主角仍在附近。

路线仍受家园碰撞、河流、已加载土地和双人边界限制；没有自动放松碰撞、生成桥梁或传送。走不到时可自由布置或选其他活动。已经在附近时可以先走开再回来。刷新保留已经完成的故事和词记录，未完成的路程不保存、不补计。

普通散步另有椅子、桌子两种目的地的初次介绍和两段复习，共六段。只覆盖走路，不把原有统一速度称作 run，也不把停住冒充 stand 的教学完成。真实语音、触屏移动、儿童体验、充分延迟复习和更多生活用途仍待验证。
