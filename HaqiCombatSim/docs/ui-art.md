# 经典魔法绘本界面

`Haqi.html` 的主界面、对话框及通用按钮使用一张 **512×512、94,572 字节** 的 RGBA WebP。入口保留左上角无头像的角色状态，右上角为签到、地图、云存档、设置四个功能按钮；底部为任务、卡包、背包、宠物、商店。商店有独立图标，NPC 继续使用原有立绘。

## 资源和复用

- 本地归档：`assets/adventure/ui/storybook-d835b3634eee.webp`。
- 永久资源：[Keepwork CDN 图集](https://cdn.keepwork.com/haqi/haqicombatsim/ui/storybook-d835b3634eee.webp)。所有域名默认使用此地址；源码 `?assets=local` 使用归档。
- 清单：`data/adventure/ui-art.json`，记录本地/CDN、尺寸、字节数、SHA-256、源图哈希、原图裁剪、图集坐标和九宫格切线。
- 提示词：`docs/ui-art-prompt.md`；内置 `image_gen` 生成，`scripts/prepare_ui_art.py` 裁切归一、打包并尝试无损。无损超预算后最终采用 WebP quality 84，保留 alpha。重生成命令：`python scripts/prepare_ui_art.py <原始透明PNG>`。更换图后必须重新上传并核验 CDN，再填写清单，不能猜链接。

图集是 4×4 等格布局。第一排为 `paper` 羊皮纸面板、`wood` 木框、`jade` 绿色按钮、`cream` 浅色按钮；其余十二格为 `book/cards/bag/pet/shop/map/cloud/settings/gourd/close/arrow/coin`。`rect` 是实际裁剪矩形，`cell` 是零起始列/行。图标使用同一张背景图、`background-size:400% 400%`，按 cell 定位，格间留空避免相邻图标串色。

`js/adventure_ui_art.js` 下载一次图集，设 `crossOrigin='anonymous'` 后加载，在内存 Canvas 中裁出四个面板并设置 CSS 变量。`css/adventure_storybook.css` 用 `border-image` 做九宫格拉伸，`slice` 顺序为上/右/下/左，保留四角，仅拉伸边和中央。裁剪结果为内存 data URL，没有额外图片网络请求或发布文件。要复用面板，可沿用 `--ui-paper/wood/jade/cream` 和各自的 `--ui-*-slice`。

文字保持真实 DOM，支持动态角色名、任务、选项及换行。图集不包含字。加载或跨域失败时保留基础 CSS/SVG 界面，不影响存档与游戏流程。新增素材不打包进 dist，发布构建仍只有 HTML、JS、CSS、JSON。

## 响应式

- 桌面：右上四列工具按钮；对话立绘在左、正文在右。
- 手机竖屏：右上两列；对话立绘与姓名在顶部，正文和选项在下方；选项按钮最小 44px 高。
- 手机横屏：缩短 HUD 和底栏，限制对话框高度，正文可滚动。
- 适配 safe-area，长内容限制在屏幕内滚动，减少动态效果设置保留。

## 用户反馈后的紧凑版（2026-09-19）

以上首版布局已调整：状态栏、顶部工具和底部菜单不再有整块外框。底部使用独立徽章；任务只保留小纸条。内容面板使用图集中央纹理与细边，不再渲染四个大卷角。对话的立绘放在框外、姓名牌骑在上沿；桌面正文与选项左右排，手机选项可同排并自动换行。通用按钮仍支持九宫格。没有新增或重新上传图片，94,572字节预算保持不变。

第三版恢复紧凑的连续背景：状态栏全部内容同底，底栏添加窄底座；对话立绘主体位于纸面上，仅上部少量露出，移动端侧边立绘、底部选项。当前布局以balanced-desktop/mobile实际截图为准。
