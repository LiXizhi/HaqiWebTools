# 旧书里的新故事

英语 L1 字源岛 en-hanzi-05；阿初863000、溪禾863001、石伯863002。课程无需先完成其他故事，不更改旧进度或奖励。六幕均先在真实NPC身边交谈，再作短句回应。

阿初想把一本旧故事书带去故事会，却担心旧封面不好看。溪禾有新本子，以为换成新本子就能解决问题。石伯发现旧书里有阿初与奶奶一起画的小船：封面新旧不能代替里面的故事。最后保留旧书，也留地方写新的故事。不是“旧东西总比新东西好”，而是两者都有用途。

1. 阿初介绍 old（旧的），孩子请求看旧书 An old book, please.。旧书只在NPC故事中存在，不发放到背包。
2. 溪禾介绍 new（新的），孩子请求看看新本子 A new book, please.。溪禾承认里面还没有故事。
3. 石伯说明溪禾曾提议撕下旧页换新封面，但纸上的旧画会丢掉。孩子回应 A bad idea.；评价主意，不评价人物。
4. 回阿初，孩子邀请 Let's read.；阿初读出小船故事及奶奶的题句，揭示他想保留的内容。
5. 溪禾提出旧书保留，新本子用来写大家的故事。孩子回应 A good idea.。新本子不需要假装比旧书差。
6. 石伯邀请孩子把自己的故事接下去，回应 I can write.。岛屿只完成邀请；真正绘画、写字与保存发生在家园，NPC不能口头代替孩子完成作品。

家园《旧故事，新开头》：听伙伴讲小球的老故事→实际邀请伙伴读书→请求编一个新故事→亲手画图→在同一张图上写A new story.。书本和伙伴跨幕绑定，画纸为实际可用物件。old/new各有首次与回访，保留朗读及打字。只校验表达与真实动作，不推断画的内容，也不评定故事艺术质量。
