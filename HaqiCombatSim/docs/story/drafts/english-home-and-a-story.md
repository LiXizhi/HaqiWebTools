# 回家后的小约定

家园四幕 `en-l1-home-and-a-story`：复现机会较少的 home、here、please，以及结束相处时的 thank you。孩子介绍当前家园，给伙伴安排座位，邀请它一起看书，最后感谢陪伴。不编造出门、搬家或已完成的阅读动作；不设置连续游玩惩罚。

前置 chair/book/sit/read/thank you；最多新教 home、here、please 三词。四幕共用第一幕伙伴，坐下及最后交谈复用第一幕椅子，阅读使用家园真实书。有效回应和实际动作共同通过才计目标词；辅助词不加次数。

1. “这里有你选的东西，还有我们可以一起待着的地方。你愿意把这里介绍给我吗？”回答 This is my home.，可选 This is our home.；必须听完伙伴回应。
2. “谢谢你带我认识这里。我想先坐一会儿，你给我指个位置，好吗？”说 Sit here. 后把原伙伴带到原椅子，真正在家园坐下。
3. “坐了一会儿，舒服多了。接下来想和我做什么？一起看看你家的书吗？”说 Read, please. / Please read. 后让同一伙伴在书旁执行看书动作。仅说话不算完成。
4. “和你一起坐坐、看看书，真好。下次想一起玩的时候，还可以来找我。”说 Thank you.，听回应后完成，不催促继续游玩。

词义与操作说明只在练习面板中显示，不由伙伴朗读。home首次教学登记到词条台账。仍未提供这几个抽象词的独立听读选择或任意自由表达，不将单次剧情等同掌握。
