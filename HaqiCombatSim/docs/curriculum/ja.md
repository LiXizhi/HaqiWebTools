# 日语：L0—L3 日常交流教学大纲

更新：2026-10-26。教学结构与故事群已设计；除明确列出的现有样例外，以下故事为待创作／接入的课程概要，不是已上线任务。返回[总纲](README.md)。

## 教材范围与语言专属路径

以 Irodori 入门 A1、初级 1/2 A2 的生活 Can-do 为主，Marugoto A1/A2 补充。只取儿童适用任务，不把成人工作／行政情境直接缩小成儿童对白。以下语料须日语教师复审后才可发布。

L0：听辨拍、长音、促音和常见问候；平假名分组出现在熟悉词中，不一次塞完整字表。L1：逐步认平假名、常见片假名姓名／物品，汉字给假名；输入姓名和标签。L2：识别高频汉字词、助词和词尾，读短留言，学假名输入与选字。L3：读生活短消息，写简短邀请和回复；不以汉字字数代替日语理解，也不要求先学完整常用汉字表。

来源核验边界见[教材台账](sources-and-vocabulary.md)。本页例句是作者拟定的课堂表达，候选词不是完整官方分级词表，具体来源页码／Can-do 与 WordTree 映射仍待 CUR-02、CUR-04 完成。

## Level 能力进阶

| 项目 Level | 听说目标 | 读写目标 |
| --- | --- | --- |
| L0 | 问候、名字、听懂简单动作 | 分辨常见假名与声音，尝试写姓名 |
| L1 | 介绍、询问物品和所在、礼貌请求 | 读假名标签与带注音短句；写标签和一句请求 |
| L2 | 说时间、天气、数量、需求与简单过去 | 读生活清单和便条；写两三句安排或原因 |
| L3 | 确认约定、转达消息、简单协商和叙述 | 读消息串；写三到五句有对象、有时间地点的短文 |

L0 小故事：认识自己的名字 → 听指令帮宠物做一个动作 → 给熟悉物品贴标签。三项均为新增教学设计，需各语声音／文字资源和实际动作接入，不用纯选择题冒充已经会听说读写。

## 九岛单元与故事群

各单元的 A／B／C 为三个主故事位，T1／T2／T3 为三个迁移故事位；每个故事都要另写完整分镜与真实动作。下列词以基本形式或固定语块列出，台词必须使用自然形式。每篇仅选其中少量首次教，其余分散到后续故事。

### JA-U01 · L1 · 字源岛：失物与名字

**能做什么：** 问物品归属、姓名、所在，请重说。

**种子词／语块：** こんにちは、名前、私、友達、本、水、家、どこ、ここ、これ、誰、もう一度。

**关键表达：** これは誰の本ですか。／ここです。／もう一度お願いします。

**语言结构：** です／ですか、の、これ／それ；礼貌表达先作整句。

**A → B → C 故事链：** 《忘れ物の本》：溪禾捡到书，玩家读名字、逐个询问归属找到主人（现有首岛需重写成完整因果）。→《同じ名前》：姓名相似，确认全名而不是猜。→《もう一度お願いします》：留言没听清，请对方重说后找对地点。

**T1／T2／T3 迁移变化：** 换一本书；改掉姓名；家园找不同物品。换情境时不能给完整答案让孩子抄过关。

**读写落点：** 读假名姓名与物品标签；写自己的姓名和物品归属。听力必须至少有一次隐藏原文后做动作；口语至少有一次只给意图、不给整句答案的回应。

**家园与战斗复现：** 家园从本单元已学目标中选 1—3 个，围绕照顾、找物、布置或轮流游戏使用；后续单元至少再次使用其中一个表达。文字卡只复现当前目标语言实际练习过的词。

## 单元之间怎样复现

U01 的招呼、问位置、请求重说贯穿九岛；U02 的喜欢和需要用于 U04 照顾；U03 的停止与求助用于 U05 旅行；U04 的时间用于 U07 约见；U05 的数量用于 U09 分工；U06 的解释与道歉用于 U08 澄清；U07／U08 的消息与位置最终在 U09 综合使用。每条目标的具体故事位置仍需在词条账本登记，不能只靠这段说明宣称已覆盖。

## 毕业任务与范围终点

用目标语言筹备一次小型聚会：听两位伙伴的需要，读一份物品清单，问清一处时间或地点，按真实场景完成一项行动，自己写一条有效邀请；随后对一个变化重新安排。允许查一个生词或请求重复，不能显示整句答案。再换 NPC／物品和另一次会话复测。听、说、读、写分别评价，任何一项缺证据都不标完成。详见[验收规则](assessment.md)。

L3 之后继续在基础结构内增加新情境、新词和新人物，不追加高级 Level。教材词汇预算及系统缺口见[词汇台账](sources-and-vocabulary.md)与[RSI 队列](backlog.md)。
