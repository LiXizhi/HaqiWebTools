# 13 · 李（`lǐ`）—— 春花如雪，树下成蹊（`hanzi_li.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：李；拼音：`lǐ`；本义：李树、李子（落叶果树及其果实）；亦为中华常见姓氏。
   - 《说文解字·木部》：“李，果也。从木，子声。”
   - 典故与常用词：`李子`、`桃李`（春花繁茂，亦喻栽培的后学；西汉司马迁《史记·李将军列传》赞曰：“桃李不言，下自成蹊”）、`行李`（古指往来使者，后指远行所携行装）。
2. **古文字演进与楷书七笔**
   - **甲骨文 / 金文**：「李」由「木」与「子」组成（甲骨早期或左右并置，金文至小篆定型为上「木」下「子」）。「木」象上展枝条、下扎树根之形，表果木本义；「子」表读音线索（古音同属之部）。
   - **小篆**：上「木」枝干匀称舒展，下「子」圆转抱合，结构端稳。
   - **规范楷书（7 笔）**：
     1. 横（木） 2. 竖（木） 3. 撇（木） 4. 捺（木，舒展如树冠覆荫） 5. 横撇（子） 6. 弯钩（子，居中承托上木） 7. 横（子，平展托稳全字）。
   - 笔画轮廓与中线内联自 `skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（1024 字框，基线 900），不改动游戏运行时 `strokes.json`。
3. **事实与艺术边界**
   - 「李」在文字学上属形声字（从木，子声）；故事中“枝头李子熟落竹篮、树下孩童仰望摘果”与下「子」相呼应，帮助儿童直观记住“上木下子”，页面字幕与左下角注释明确区分字源本训（上木表果树、下子表读音）与画面记忆联想。
   - “桃李不言，下自成蹊”标明典出《史记》，用“李树不会说话，可花香果甜，树下自然走出一条小路”向儿童浅白传达诚实温润的品格。

## 二、一句话主题

> 春风吹开满树雪白的李花，夏阳酝出覆着薄霜的紫红李子；大树从不夸耀自己，可树下早已踩出了一条温暖的小路——上「木」下「子」，就是「李」。

## 三、美术、材质、色彩与声音

- **视觉语言：南宋院体折枝花鸟工笔设色 + 暖春宣纸长卷。**
  - 离屏生成手工楮皮宣纸纤维与微细银粉底纹（`multiply` 叠印），边缘施宋册页檀褐绫边暗晕。
  - **四季光色流转**：早春清晓雾青 `#cfdcd8` → 盛春晴昼暖玉 `#f6efe0` 与雪白五瓣李花 `#fffdf9`（淡青花萼 `#8eb29a`、鹅黄花蕊 `#f2c96b`）→ 盛夏熟果暮金 `#f4dfc0` 与绛紫果皮 `#7b2949`（覆一层半透明银蓝果霜 `rgba(218,228,242,0.42)`）。
  - **场景层次**：远景江南春山黛影、青瓦粉墙村舍 → 中景老李树苍劲赭墨树干与三级分枝、树下井栏与竹编果篮 → 前景随风飘旋的五瓣李花瓣、停驻枝头的黄鹂，以及随来往行人渐渐浮现的暖土小蹊。
- **声音设计（WebAudio 原生合成，零外部音频）**：
  - 温暖大调五声音垫（`F4, G4, A4, C5, D5`）；拂枝开花的筝弦泛音琶音；果实落入竹篮的温润木竹轻响；黄鹂清脆双音滑哨；描红笔锋沙沙声与成字编磬余音。

## 四、分镜（七幕 · 约 2.5–3 分钟）

| 进度 | 场景 | 画面与字幕 | 互动 |
|---|---|---|---|
| 片头 | `introPlay` | 折枝白李花探入古宣纸画幅，微风吹落花瓣，指针拂过时花枝轻颤生香 | 点击「开始」解锁音频并入画；片头绝不触发 `written` / `completed` |
| 春花 | `sSpring` | 村口老李树刚过寒冬，枝头缀满含苞青蕾。“春风刚到村口，老李树还睡着。”“枝头上，藏着一粒粒小小的花苞。” | 观看，镜头自远山推进枝头 |
| 开花 | `sBloom` | 三枝主干上的花苞泛起微光 | **互动 1（拂风催花）**：轻点或划过三簇花枝（或点按钮/空格），春风拂过，五瓣雪白李花成簇绽放，花瓣纷飞，黄鹂飞落枝头；闲置自动绽放 |
| 结李 | `sFruit` | 春去夏来，白花谢去，枝头挂满覆着白霜的紫红李子；树下放着竹篮，渐渐走出一条小蹊 | **互动 2（摇枝采李）**：轻点三颗饱满熟透的李子落入竹篮，行人闻香而来，树下踩出暖色小径，呼应“桃李不言，下自成蹊”；闲置自动采摘 |
| 成字 | `sGlyph` | 树冠枝干收束于上（「木」），竹篮熟果与树下孩童收拢于下（「子」），浮现龟甲金文 → 竹简小篆（引《说文》“李，果也。从木，子声。”）→ 乌丝栏宣纸楷书七笔，分色标注上「木」下「子」 | 观看字源演进与上下结构拆解 |
| 写字 | `sWrite` | 七笔描红：横、竖、撇、捺、横撇、弯钩、横 | **互动 3（七笔描红）**：宽容趋势投影描红，支持“看示范”与超时自动演示；完成即盖朱砂「李」印并触发 `haqiHanziWritten()` |
| 词意 | `sWords` | 依次点亮 `李子`、`桃李`、`行李` 三组词，背景随词切换盛夏果香、春风桃李与远行晨星 | 逐词与字幕严格同步 |
| 余韵 | `sFinale` | 字形化回满树繁花与累累紫李，树下小径温暖发亮 | **自由互动**：点击树冠洒下漫天白李花雨与筝音；触发 `haqiHanziComplete()`，支持「再看一次」 |
