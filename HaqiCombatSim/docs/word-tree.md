## 2026-10-26：场景任务证据与旧练习兼容

场景课程使用 `courses[id].scene={version,next}`，不覆盖原答题版 `next`。接受任务可保留原 `acceptedAt`，但不凭旧答题进度跳过NPC／地标／战斗。有效回答须附当前步骤匹配的对象与岛屿证据，普通互动还须在既有语言交互距离（默认85）以内；战后对话须有实际胜利记录 `sceneWins[stepId]`。到达、展示、试听、胜利本身不写有效练习；对话校验通过才复用同一回执累计。

## 2026-10-26：课程以语言任务展示

既有 `courses` 进度直接投影进“全岛任务”和右上角追踪，无需迁移或重做。新增 `acceptedAt` 记录本地接取时间，不算练习；完成步骤保留该字段，继续使用同一有效练习回执。任务详情关闭或切换语言后，旧会话不得推进课程。

## 2026-10-26：课程、四语言字卡与家园情境练习

新增入口统一经过 `language_course.js` 的角色／语言隔离事务及既有 `recordEffectivePractice`。课程进度存于本地 `courses`；家园须回答和真实动作均通过，字卡只有明确正确的词语输入、朗读或原中文书写计数。旧字卡部分朗读容错不算有效练习。展示、试听、错误、取消、重复回调不计；10次提升基本理解规则不变，不新增云端掌握资格或奖励。

词库在原2000个中文键基础上补齐12个课程／旧字卡缺词，四语均为2012个中文键；“请”从分组中拆出并校正对应词形，不新增重复键。只加载所选语言及中文键，其他语言按需读取。课程和家园实现范围见 [多语言岛屿](language-island-plan.md)。

## 2026-10-19：新标记立即验证与奇豆兑换

标记已理解的字词可直接参与出题，不要求12个遇见词、3个标记或2段上下文；自评不伪造遇见次数。新标记绕过一分钟自动重试间隔，生成期间新增标记会补发准备请求；校验通过的果实同时可用，画面优先显示最新三颗。单词很少时允许一个内容词的新句。在线生成仍需登录和模型应答，离线或失败明确提示，不伪造题目。

继续要求两个不同句子、无提示首次连续答对才验证掌握。服务器 mastered.json 的 en/zh 清单只增不减；答错、自评降级或清除本机学习不会删除服务器资格。只有此次新加入服务器且成功应答的词可自动兑换50奇豆，服务器已有词不重新发奖。待兑换回执留在本机，领取记录 languageTreeClaims 随角色 records 分片保存，奇豆进入 battle 分片；本地领取失败可重试，重复回执不会重复增加奇豆。沿用单客户端写入约定，未新增跨客户端事务服务。

# 世界树 JS 类库

## 2026-10-19：四语词库与对话标记

`data/adventure/locale/word_zh.txt`、`word_en.txt`、`word_ja.txt`、`word_ko.txt` 共用同一份中文键集合（2026-10-20 格式更新）。中文单字和多字词共存；原有汉字故事、笔顺和完整学习卡继续保留，未提供完整课程的新词在标记“不认识”后直接返回词树，不再弹出重复词义页。词汇数量不是语言精通认证。

- **按需加载**：`word_lexicon.js` 不在模块导入时请求数据。打开某语言词树或呈现所选学习语言的正文才加载该文件；双语对应加载当前目标语言、母语以及共享的中文键表，并校验展开后的键集合一致。每种语言的请求 Promise、解析数据和索引共用内存缓存，并发打开只请求一次；失败移除缓存，之后可重试。不请求在线词典、不向浏览器添加第三方依赖。
- **格式（用户约定，2026-10-20）**：UTF-8，`word_zh.txt` 每行只有一个中文键或逗号分隔的一组中文键，无 JSON、注释或其他内容。其他语言每行 `中文键1,中文键2,...||词形1,词形2,...`，相同右侧词形列表合并到一行；展开后四份文件键集合完全相同，行顺序可以不同；空右侧表示待补译词。每个已收录词形反向索引到中文键，英文→日文等跨语匹配也经中文键求交集，不再依赖运行时 WordNet 编号。语言内学习节点使用首个目标语词形，重复首词合并；同一拼写可关联多个中文键，配对歧义仍留给语境处理。
- **匹配**：词形用 `Map`，连续文本用前缀树最长匹配，词义用倒排索引；不逐词遍历 2,000 条记录。原文位置、大小写和标点不变。`worried / worrying / worries → worry`；中日文优先长词；韩语检查词块边界并允许收录的助词尾缀，避免把“선물”里的“물”误作“水”。有歧义的词形不强行归并。
- **词树与正文共用**：四语页签、朗读、正文采集、状态及果实题词汇校验均使用同一索引。词库预置节点的遇见次数为零，正文仍需实际呈现 800ms 才计入遇见。英语词形、常见日语／韩语活用保存在数据中，运行时不猜词尾。
- **对话（2026-10-20 更新）**：显现结束后通过中文键自动匹配两侧未掌握词并显示同色标记与连线，无需请求模型。点击任一侧对应词，标记的是目标语言词条，复用词树的三档选择。自评全掌握立即隐藏该原形所有变形的提示；降级后恢复。朗读按钮与词语按钮是兄弟节点，避免按钮嵌套。
- **模型只由按钮触发（2026-10-20 更新）**：“模型连线”使用原模型适配器及缓存，仅排除已掌握词形，由模型根据整句语境补充词表未配对的对应关系。结果校验原文范围、不重叠及掌握状态；本地已配对范围保留，模型补充仍校验词条归一化、原文范围与掌握状态。网络失败保持原文与可点击词语，允许重试；关闭视图与身份切换使迟到结果失效。模型缓存不自动显示。
- **存储兼容**：保留英语原存储键及中文 `:zh`，新增 `:ja`、`:ko`。旧变形节点一次性归并，保留上下文、计数和最近显式标记；无时间信息时优先保守状态，不拼接不同词形的答题证据来制造掌握资格。只保留原来的中英验证掌握清单云同步，日韩及各语言自评标记仍只存本机。

### 来源与维护

基础词义来自 [Open Multilingual Wordnet](https://github.com/omwn/omw-data)，固定修订 `406bf83b3c507a3d1f26e88252d5d66893fd36bf`：英语 Princeton WordNet、中文 Chinese Open WordNet、日语 Japanese WordNet、韩语 Wiktionary 派生表。频率选词使用作者工具 wordfreq 3.1.1；不发布频率数值，不将词频当作学习等级。`word-overrides.json` 保存项目常用词、基础功能词与明确词形校订；`word-sources.json` 记录实际源文件哈希和条目／词形数。

`python scripts/prepare_word_lexicons.py` 可复现词库，作者环境需安装 wordfreq；源文件下载仅在准备阶段，缓存于 `tmp/word-lexicons/`。运行时不会执行该工具，也不会请求这些外部来源。韩语改编词表保留 CC BY-SA 3.0 标注；各语言附带对应源许可证及中文释义来源许可。许可证集中保存到 `locale/word-LICENSE.txt`，发布时 `package_locale.mjs` 原样保留该文件；词表本身只含键和词形。

这些是常用词选集，不是完整形态分析器。未收录的少见活用、词义歧义和意译不伪造对应，可显式请求模型补齐；词库的释义标签可继续按儿童阅读场景校订。

专项测试：`tests/word_lexicon.test.mjs`、`tests/battle_word_dialogue.test.mjs`，覆盖实际四语文件、按需缓存／重试、复杂度、最长匹配、词形冲突、迁移、模型触发边界、点击标记与身份失效。测试结果及已有失败见当日开发日志与 QA 记录。

唯一 UI 入口是 `js/word_tree.js` 导出的 `WordTree` 类。字典中英日韩页签直接调用此实现；没有 iframe、srcdoc、旧版渲染器或模式分流。类内部使用 Shadow DOM 隔离样式，不替换宿主 body，不接管宿主窗口。

## 使用

```js
import {WordTree} from './js/word_tree.js';

const tree = new WordTree(container, {
  key: learnerKey,
  getKey: () => currentLearnerKey,
  data: dictionary,              // {language: 'en' | 'zh' | 'ja' | 'ko', entries: [...]}
  index: loadedWordIndex,        // 可选；省略时按 data.language 加载并复用词库缓存
  store: localTreeStore,         // read(key), update(key, reducer)
  online: () => isLoggedIn,
  request: generateQuestions,    // 现有模型适配器 (messages, signal)
  onUnknown: openLearningCard,   // 有额外学习内容时接管并返回 true，否则直接返回词树
  onMastery: syncMasteredWords,
  syncMastery: restoreAndRetryMastery,
});
await tree.ready;
await tree.refresh();            // 外部本地数据变化后重读
// 只读快照：tree.state / camera / hits / fruits / stats
// 切换页签、角色或移除容器时：
tree.dispose();                  // 可重复调用；初始化途中也可调用
```

容器需有明确宽高。类按需加载自己的 CSS 与词义补充数据，不引入第三方库。dispose 释放绘制、观察器、定时器、页面监听、语音、弹窗与异步请求；每个实例的画布、相机和学习会话独立。

## 重复练习与基本理解（用户约定，2026-10-19）

### 目标与接入状态

所有明确的词语学习交互共用 WordTree：包括家园咒语召唤、对话跟读、词语朗读、正确打字及后续同类玩法。玩家无需先打开词树；各场景积累的有效练习应汇入同一词条，词树负责统一呈现学习状态。

**本节是开发约定；2026-10-20 已接入家园召唤的有效练习与本地 basic 提升，其他入口按各自实施记录验收。** 当前已有规范词库、正文遇见采集、三档本地标记及词树刷新／订阅；`recordTreeExposure` 的 `count` 是遇见次数，不是有效练习次数，不能直接以 `count >= 10` 实现本规则。家园成功召唤通过本机事务待处理记录提交规范目标词事件；每包16块仍只计一次。错误、试听及取消不计，事件可重试并去重。

### 计数与提升

- 默认阈值为 **10次**：同一规范词条正确完成10次有效练习后，可自动将未知／不认识提升为绿色“基本理解”（`basic`）。这个数字是可调整的玩法阈值，不是语言能力认证。阈值在共享学习核心统一定义，不散落在每个场景。
- 朗读以已有识别／练习校验成功为依据，打字以完整回答匹配成功为依据；二者累计到总有效次数，同时保留来源和输入方式。播放TTS示范不等于用户读过；未获得可靠完成结果时不猜测成功。
- 每次独立完成的练习，对每个明确目标词最多加1。同一句反复正确练习可以累计；同一次录音的partial/final回调、重复点击、重复提交处理、存储重试不能重复计数。复用稳定练习回执／事件标识，跨重载保持去重。
- 计数按账号／角色／目标语言／规范词条隔离，跨场景及跨会话累计；复用 `word_lexicon` 的原形与已收录词形归并，不按显示字符串建立平行节点。短语优先对应已收录的短语节点；没有可靠词条映射时先补映射，不把含糊拆词当作已理解。
- 只计任务明确练习的目标词。例：完成 `Create a chair.`，本次物品练习目标是 `chair`，给它加1；不会同时将 `create / a` 当作本次已练习目标。若任务明确练习颜色与物品两个词，则分别匹配并各计一次。不是朗读一句包含10个词就让10个词自动达标。
- 展示、普通正文遇见、听示范、自动填入、空输入、错误、取消、切换角色／语言后的迟到结果均不计。被动遇见继续遵守原800ms呈现和原去重规则，不因练习完成伪造遇见次数。

### 状态与存储

自动提升保留“重复练习达标”的来源和时间，不伪造成用户手动自评；不得降低自评全掌握或已验证掌握状态。用户后来手动标回“不认识”时保持该选择，以这次标记后的新有效练习重新累计自动提升阈值，不能因旧总数已达10而立即改回。可保留历史总数，并另记录本轮计数基线。

有效次数、去重记录、自动提升来源和基线只存现有账号／角色／语言隔离的本机IndexedDB，不放入家园物品分块、不新增每次练习云请求。清除本机学习记录后，不从服务器掌握清单伪造这些练习次数。复用 `languageTreeStore` 的更新与订阅，已打开的词树及时反映变化，未打开的词树下次读取即可显示；学习记录保存失败不得虚报已计数，保留可重试的完成回执且不重复发放玩法物品。

“基本理解”可进入现有果实出题候选流程；自动标记不强制请求在线模型。**已验证掌握仍要求两个不同新句、无提示、首次连续答对**，云端清单和奇豆兑换仍走已有资格与确认链路。重复10次本身不新增 `masteryEarned`，不调用掌握奖励，不写服务器 `mastered.json`。

### 后续接线与验收

在共享学习核心定义有效练习事件及纯计数／提升规则，再由各场景适配。家园使用成功句子匹配的目标物品词条及稳定召唤回执；对话／朗读／输入复用各自真实完成回调。接口名称和字段以实现后的源码为准，本节不宣称已有通用写入API。

接入测试至少覆盖：第9次不提升、第10次提升；重复同一句的独立练习可累计；同一事件重放不累计；错误／试听／取消不计；跨场景累计、词形归并、账号及语言隔离；未打开词树也持久化；手动降级后需新的10次；更高状态不降级；写入失败重试不重复召唤物品；本地basic不产生云端资格与奖励。


## 果实缓存与不会作答（2026-10-19）

果实题目、完成状态及上次成功出题时已理解的词条集合 `generatedWords` 一起保存在角色隔离的 IndexedDB。重新打开直接复用未完成果实；只有没有未完成果实，且存在上次成功出题后新增的基本理解／自评全掌握词条，才允许请求模型。答完旧题、重复打开、重复标记同一个词不会单独触发生成。生成失败不推进词条基线，仍沿用一次格式修复与后续重试；本地数据库不可用时明确提示仅保存在内存，不能保证跨会话缓存。

题面明确要求选择整句含义，正确选项必须与完整中文译文一致（校验忽略空白和标点），其他两项为不同句意；提示词要求保留主语、动作、对象及修饰关系。此规则能拦截选项与译文不一致，不能替代语言语义审核。旧缓存中不符合此约束的未完成题被移除，不写答题证据；迁移记录当前已理解词条作为基线，不因清理旧题额外请求模型。

每题另有暖橙色“我不会”按钮，不属于模型生成的三选项。点击后结束该题、打断连续答对证据并保留基本理解，不授予掌握资格或奖励；反馈面板保留原句与参考译文，用户主动返回语言树。

## 渲染开销（2026-10-20）
