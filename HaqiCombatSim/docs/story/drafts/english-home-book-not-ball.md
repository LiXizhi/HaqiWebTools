# 书能当球吗？

英语 L1 家园故事。目标 good / bad，复习 read。伙伴想一起玩，提出拿书抛接；孩子可以不同意这个主意，再和伙伴一起读书。评价的是主意，不把伙伴或孩子称为“坏”。不出现真实扔书或损坏物品。

## 三幕与真实动作

1. 伙伴：“我想和你玩抛接！这里有一本书，可以拿它当球吗？书页可能会散开。bad 是不好的；A bad idea. 是‘不是个好主意’。你可以告诉我这个主意不好。”孩子回应 A bad idea.，点伙伴后得到 “You are right. No throwing books.”／“你说得对。不扔书。”收到回应并继续才记录 bad。
2. 伙伴：“那就不扔书。我们坐下来，一起看书里的故事，好吗？good 是好的；A good idea. 是‘好主意’。你愿意这样做吗？”孩子回应 A good idea.，伙伴回答 “Yes! Let's read together.”／“好！我们一起读吧。”仍绑定同一本书、同一伙伴；继续后才记录 good。
3. 伙伴：“书不用飞起来，也能带我们去冒险。邀请我一起读，再把我拖到这本书旁边吧。”孩子回应 Let's read.，实际把伙伴拖到原书边触发 read 动作，才记录 read。

## 回访与边界

good / bad 各有首次和回访独立情境。回访用“用书盖住小脸躲猫猫／一起读书”，不是重复播放同一开场。保留文字输入，不强制开麦；支持 That is a good/bad idea.。只明确计 good、bad、read，不给辅助词 idea/together 计数。不把作者对白当成开放式 AI 理解，不把回复播放当独立听力通过。
