# 宠物标签与捕获成长

2026-10-05 实现于本地，未发布。此规则覆盖早期“同种多个独立个体”的设计。采用属性标签收集玩法，数值为本项目设计，不声称复刻 Palworld 公式。

## 数值体系与边界

现有战斗仍由卡牌基础值、角色等级、装备属性及原 Lua 伤害/治疗/命中公式决定。标签是宠物属性覆盖层，复用已有 damagePct、resistPct、hpPct 等入口，不改原版公式。宠物等级、阶段卡包、重复获得经验继续生效；捕获次数本身不无限叠加攻击。

同一种宠物只保留一只；不同种仍独立培养。每次获得累加 obtainedCount，成功捕获另累加 captureCount。每种标签只保留最高等级，不相加、不降级；最多收集九种。既有宠物倒下不会丢标签。旧存档无法推断的历史捕获次数按 0 开始，既有个体视作至少获得一次。

宠物详情的养成页展示基础战斗属性：最大生命、攻击伤害加成、防御减伤、暴击属性、命中加成、超级魔力率、治疗加成和卡包容量。读取当前等级及标签的永久属性，不计临时战斗效果；攻击加成0%不代表没有伤害，命中与暴击仍受卡牌和对手影响。标签仅更换称号，编号、数值与存档兼容性不变。

原有属性与标签加成相加后进入既有公式。表中的暴击属性不是无条件最终暴击率，仍遵循战斗双方的原判定。支援位宠物只在施放它的卡牌时提供强攻、会心、专注、仁心，不把坚甲或健壮直接加给主角；独立出战宠物使用自己的全部战斗标签。

上限检查：宠物标签的攻击伤害加成最多 60%，最大生命加成最多 60%，减伤属性最多增加 30 个百分点，食量最低为原来的 55%。这限制了重复捕获的最终属性收益；等级和卡牌成长仍是另一条成长线。八种全部传奇3级是收集终点，不继续无上限强化。高生命和高防御会同时增加有效耐久，后续平衡应联合观察胜率与战斗时长，不能只看面板战力。

所有标签权重、收益与缓存上限在 `BalanceParams.petTraits`；已有捕获难度在 `BalanceParams.adventure`。默认每分钟消耗 1 饱食时，节食传奇3级实际消耗 0.55；休息、投喂、死亡恢复继续走原规则。

## 首次登场与刷新

世界加载不生成野怪标签。`beginEncounter` 首次建立战斗时读取玩家同种宠物摘要，使用独立种子随机流抽取 1–3 个标签，数量概率分别为 65%、28%、7%。普通等级权重为 5000/2500/1250/650/350/170。

每只怪物有 5% 概率进入传奇抽取，传奇1/2/3级权重为 80/17/3；已拥有的标签等级会提高本次最低升级等级，因此后期传奇3级占比可上升，但有光圈怪物的总概率仍是 5%。普通抽取优先选尚未达到6级的标签，保证至少一项新增或提升；全部普通满级后，普通怪保留不同的标签组合，只有传奇抽取能继续升级。全部传奇满级仍保持组合差异。

传奇1/2/3级脚下分别显示紫色、金色、粉色光圈；普通怪没有光圈。以最高标签等级决定颜色。敌人登场、捕获结果与宠物详情展示标签；捕获结果显示本次升级。“我的伙伴”的阵容台座、收藏卡片及战斗角落状态卡不显示标签或空标签提示，已拥有宠物可在详情查看。

同一存活遭遇撤退重进不重抽；标签与参数写入战斗检查点，重演沿用原快照。胜利或有敌人被击败后清除该遭遇缓存，下次刷新重新比较玩家宠物。缓存仅在本机运行态，最多128个遭遇；缓存被淘汰或本机运行态丢失后会重新生成。已收服宠物标签不受这些刷新影响。

## 捕获与存储

所有具有宠物物种身份的活怪都可以尝试捕获，重复物种、狂暴或隐身不再直接禁止。当前生命、等级差、持久度和狂暴共同影响概率，新规则限制在 1%–95%；以实际卡牌目标提示为准。健壮提高最大生命，也会通过实际耐久影响捕获难度。捕获成功复制该怪物本次标签，自动合并同种最高等级，并保留原重复获得经验奖励。

标签和次数随每只宠物的独立文件保存，摘要也携带标签供开战比较，无须在世界加载时读取全部宠物正文。合并之前必须加载已有同种宠物正文。旧存档的同种重复个体在无未结束战斗时归并：保留上阵优先个体、最高经验和冷却、最高标签并累计次数，旧个体持久字段归档在 legacyMergedPets；petMergedIds 防止旧文件引用重新出现。此迁移不删除服务器旧文件。

旧战斗检查点没有 petTraitRulesVersion，按旧规则重演；新检查点使用版本1，保存标签和参数快照。怪物标签随机流独立于战斗随机流。

## 验证入口

`tests/battle_pet_traits.test.mjs` 检查随机分布、最高等级合并、次数、实际属性、食量、首次登场、重演、运行态分层、迁移、领养与光圈。`tests/fixtures/pet-traits.html` 是隔离内存的显示验收页，不读写玩家存档。日常回归运行 `npm run test:battle`。

### 成长节奏抽样

固定种子范围0–19999独立抽取出现1002只传奇怪（5.01%）。1000组独立连续捕获模拟，从空标签开始，每次抽取后立即合并，不计捕获失败、战斗耗时及其他奖励：八项至少普通6级的 P10 / 中位数 / P90 为31 / 36 / 41次；八项全部传奇3级为324 / 433 / 566次。此结果用于初版调参，不是实际玩家耗时预测，也不代表整体产品长期平衡已完成验收。


## 2026-10-06：采集小能手

新增gathering标签，1—9级采集效率加成为10/20/35/50/70/95/125/160/200%。普通携带宠物仅在主人采集时协助同一资源，默认协助间隔12秒；效率同时缩短出发间隔和1.5秒采集时间。倒下或饥饿为0不采集，双人只使用共享阵容中各自的宠物。

为保持旧战斗随机结果与回放，新标签使用独立种子：保留原八种标签的完整随机流和数值，仅在原结果不足3种时按20%概率追加，等级沿用该次结果的最高等级，不额外增加传奇概率。生成概率与等级曲线都由BalanceParams.petTraits配置；标签沿用既有宠物文件、合并和详情展示。
