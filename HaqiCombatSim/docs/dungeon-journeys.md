## 岛上入口

六岛各有两处蓝光剧情入口、一座试炼塔。入口按固定道路位置选址，避让居民、怪物、桥梁和建筑，清除遮挡树木；点击后沿现有寻路靠近。小地图以蓝色标记剧情入口、金色标记塔楼。塔楼三档外观与蓝光法阵共用 `entrance-art.json` 的一张WebP，入口均不显示场景名称/等级字幕，只保留缓存蓝光。点击后显示名称、建议等级和进入/取消。试炼塔出战人数沿用组队席位或宠物阵容，确认框不再另选；塔可展开原有奖励。

## 剧情与备战

六座塔和十二个精英副本各有八句独立中英剧本（序幕、三轮NPC/玩家交流、结尾），配置仍在 `dungeon-journeys.json`。确认并成功进入副本后播放全屏剧情，真实入场场景只截图一次作为背景，每条对话两侧显示静态头像与名字，玩家仅显示头部；点击继续推进，录音完成后自动继续，支持右下角跳过；减少动态效果时关闭气泡淡入。队伍不足则转到原备战界面，补齐后出发再播放剧情。

开启语言学习时按目标语言显示英文或中文，按“显示释义”偏好双语呈现。复用现有Keepwork语音服务；玩家台词出现后随时点击/长按气泡或配音按钮开始，无倒计时，松开或再次点击结束。20秒录音上限，识别后用既有大小写、标点、数字、缩写归一化规则核对台词；不伪称发音评分，不保存原始语音或转录。空白、错误台词、取消、跳过、切后台及过期异步响应均不授奖。朗读功能不算用户配音。

剧情跟读接入[全局语言学习设计](language-learning.md)：每句有效录音随机叠加每日属性，生命／攻击／防御各上限10%，叠满后超级魔力生成率最多10%。离开副本不清除，本机午夜重置；仅当前角色本机 IndexedDB 保存，战斗冻结入场加成。统一规则、参数与修改入口以该文档为准。旧 `dungeonLanguageBuff` 仅用于历史记录兼容，不再作为新故事的奖励来源。

`pauseBackgroundScene`统一决定地图是否被遮挡：战斗、全屏剧情、标题/建角、地图/其他面板、学习/角色对话以及隐藏页面均暂停世界绘制、社交移动和宠物场景更新；战斗自身及当前UI继续工作，关闭后自然恢复。原入场截图在全屏开始前绘制一次，播放中不重复渲染后台。

固定双方人数为1–4，敌方编队仍来自来源模板。没有组队伙伴时使用主角与宠物，有伙伴时沿用既有快照队伍；不足人数提示补齐，只给实际上阵宠物发放经验。原版Lua公式不变，语言奖励为明确的网页覆盖层。

当前组队沿用项目已有 AI／异步快照伙伴，不是新增实时多人服务。

## 试炼塔

每层支持1v1–4v4；敌方人数与当前组队或宠物阵容一致，确认进入时不再另选人数。一层中任何模式获胜都推进同一个最高层数；失败和撤退不推进。改用其他人数或伙伴时退出并重新备战，重返直接接续下一层；“重新挑战”不会重置塔记录。普通副本原有重新挑战语义不变。

守卫来自原试炼塔可运行关卡，按原始生命排序逐渐引入更强模板，沿用其卡牌和 AI。每层生命另按 `BalanceParams.dungeonJourney.hpGrowth` 递增，默认每层增加来源生命的5.5%；这是明确的网页难度覆盖，不是 Lua 公式改写。每十层可领取一次奇豆，封顶有大奖。默认 `rewardPerFloor=30`，封顶 `summitMultiplier=5`；奖励金额、已解锁及已领取状态直接展示。领取与物品到账在同一份角色核心状态中保存。

## 独立存储

`save.towerRecords[towerId] = {floor, claimed}` 记录最高层及已领取的里程碑。单人和组队结算共用。入场时按当前阵容写入 `dungeonMode`；探索迷雾及进行中的组队／战斗仍仅本机 IndexedDB；层数和奖励领取为持久核心状态。

每座塔独立保存到 Keepwork `HaqiAdventure` workspace：

`roles/<roleId>/towers/tower-<island>/<revision>.json`

`roles/index.json` 的 `files.towers` 只保存塔 ID → 文件引用。未变化的塔复用原引用，没有记录的角色不创建空文件。文件带账号、角色、分片名和不可变版本，使用现有 cache API 写入并回读核验，全部成功才发布角色入口；沿用账号检查及并发版本冲突处理。旧存档无此字段正常恢复；错误塔号、越界层数、提前领取、重复领取、跨塔／跨角色路径拒绝。

## 地形

湖泊与同材质河流按共同水岸层逐层绘制，内部水面覆盖交界岸线，并以联合裁剪绘制水纹。四种材质均有预览。迷雾覆盖改为不透明，外圈保持遮罩且禁止视野清除地图外部，隐藏矩形海岸和左上角硬边；已走过的道路仍保持揭开。

## 验证入口

- `tests/dungeon_journeys.test.mjs`：六岛入口可达、索引与完整数据一致、层数上限、难度递增、单人／组队共享、恢复、防重复领奖、独立文件复用、失败不发布入口和跨塔路径拒绝。
- `tests/fixtures/dungeons.html?island=camp`：岛上入口；`?brief=journey:first-watch`：进入确认；`?dungeon=journey:tower-camp&learning=1`：全屏双语剧情；`?brief=journey:tower-dark`：100层奖励；`?dungeon=dungeon:HaqiTown_FireCavern`：探索迷雾。
- `tests/fixtures/water-junctions.html`：清水、熔岩、冰湖、幽暗水域交汇。

浏览器验收使用隔离内存角色，不读写玩家存档。真实账号远端读写仍待登录后的正常游戏同步验证；本轮使用 SDK 模拟适配器检验存储语义。
