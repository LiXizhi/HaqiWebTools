# 听来的小画约定

家园连续故事 `en-l1-listen-and-make-picture`，复习 paper、pencil、draw、name。伙伴想与孩子留下自己的小作品，先通过听请求选择材料，再读请求找工具，随后创作与签名。复用已有图集和家园画纸、标签功能，不增加新词门槛或奖励。

1. 伙伴：“我想和你做一件小作品。我们先玩一个听请求的小约定：我说，你来找。准备好了吗？”听 Find the paper. 后点选真实画纸；中文开场不说纸，不提供已圈出的正确物品。可重听、改读。
2. 伙伴：“你找到刚才请求的东西了！这次我把需要的工具写下来。你能照着这条请求找到它吗？”阅读 Find the pencil.，点选铅笔。即使前一步改读，开场仍如实描述已经找到了物品。
3. 伙伴：“东西准备好了！我想看看你的主意。画什么都由你决定，我不提前猜答案。”说 I can draw. 后实际打开第一步选中的画纸，保存自由笔画。不声称铅笔已被拿起或消耗。
4. 伙伴：“这是你创作的小画！给它留下一个你喜欢的游戏昵称吧，下次回来就能认出它了。”在原画纸写 My name is … 并保存；不要求真实姓名，图案不由模型评分。

前两步仅记对应理解证据，不增加有效表达次数。改读只记阅读；错误、示范和重复回执不计完成。后两步只计明确 draw/name，不能给辅助词或画中内容自动加分。原画纸丢失或画作清空时原签名步骤不能完成。重新进入保留理解进度、画作与标签。

这是新的混合技能故事，不代表独立四技能达标。仍需更多变式、跨天复习、真实语音和儿童试玩。
