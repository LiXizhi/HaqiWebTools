# 孙 sūn · 一根丝，接着一代人

[独立互动页](../hanzi_sun.html)

夜里的一间蚕室。奶奶摇动缫丝车，从温水的茧盆里抽出一根丝；丝绕过导丝钩、缠上丝锭，再经过三个丝结，交到孙女手里。丝的那一头连着孩子——这就是「孙」。

## 为什么换掉风筝版

旧版把「孙」讲成奶奶教孙女放燕子风筝。问题有三：

1. **隐喻不落在字上。** 风筝与「糸」没有形体关系，孩子看完记住的是风筝，不是「子 + 糸」。
2. **画面单薄。** 一张静态 SVG 版画配几个位移关键帧，没有材质、光源与景深，缩到手机宽度只剩色块。
3. **字形环节弱。** 古文字是随手描的线图，繁体直接用系统字体贴一张「孫」，与描红用的规范楷书不同源。

新版改用**纯 Canvas 2D**（不引入 3D）：字义本身就是「一根连续的丝」，一条能被抽出、被接长、被交到手里的线，比空间景深更能解释它。

## 字形与故事

「孙」从子从糸，糸是丝，取世代相续之意。甲骨、金文可辨孩子形的「子」与丝束形的「糸」；小篆右旁写作「系」；繁体楷书作「孫」（10 笔），简化后右旁作「小」，成「孙」（6 笔）。

- 描红与繁体演示**都**使用 Make Me a Hanzi 固定 commit `bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的规范轮廓与中线（`孙` 6 笔、`孫` 10 笔），不再用系统字体贴字。
- 甲骨 / 金文与小篆是**部件示意**（页面 `#note` 已声明），不冒充拓片。
- 简体笔顺：横撇、弯钩、提、竖钩、撇、点。左「子」末笔为提，让位给右旁。
- 字形演变参考[中研院「孫」字形演变](https://chardb.iis.sinica.edu.tw/evolution.jsp?cid=10101)与[香港中文大学「孫」字头](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=%E5%AD%AB)。

## 美术与实现

- **色彩**：靛蓝夜色 → 琥珀灯光 → 暖金灯河 → 宣纸米白，四段 mood 插值，不是换背景图。
- **光**：单一油灯为光源，光晕随灯焰轻微呼吸；尘埃按到灯的距离决定亮度；月光从花窗斜切进屋。
- **材质**：木墙板缝、竹匾编织、陶盆水面、麻纸肌理与暗角均为程序化绘制，无外部图片、无外部依赖。
- **人物**：剪影的手臂末端由「要够到的目标点」反算——奶奶的手真的跟着摇柄转，孩子的手真的落在丝头上。
- **构图**：横幅长卷与竖幅立轴两套机位与锚点（`LAYOUT_WIDE` / `LAYOUT_TALL`），竖屏下丝车、丝结、孩子与灯河全部收进画内，长案与地面铺到画外避免露底。
- **声音**：WebAudio 实时合成——蚕食桑叶的高频脆响、缫车摩擦白噪（随轮速联动）、木轴咔哒、丝弦五声拨奏、灯焰低鸣与落印闷响。仅在用户手势后启动。
- **可访问性**：`prefers-reduced-motion` 降低动效并保留每步终态；暂停冻结虚拟时钟与声音链；触控 / 鼠标 / 键盘（空格、回车）同一动作；描字容错，写不动可看示范，26 秒无输入自动演示，不会卡死故事。

## 验收

离线渲染验收（Node + Skia 画布驱动页面真实脚本）：桌面 1440×900、竖屏 390×844、横屏 844×390 三种视口各走完七幕，六笔全部由真实指针轨迹描写通过，事件顺序 `written → completed`，`save/restore` 平衡，无非法颜色与非有限坐标，无控制台错误。`?auto&fast` 全自动演示同样跑通。三语词条（en / ja / ko）覆盖全部 67 条字幕与 UI 文案。
