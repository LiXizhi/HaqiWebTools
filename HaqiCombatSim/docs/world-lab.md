# 哈奇岛 · 三维世界实验室

用户提供海岛地图作为视觉参考，通过已连接的 Blender 5.2.1 MCP 创建真实三维场景，独立 H5 入口为 `demos/HaqiWorldLab.html`。这是程序建模的风格化技术验证，不是原图精确重建；背面与被文字遮挡的区域为设计推断。无图生 3D 服务、无外部下载模型与纹理。

## 打开

在项目根目录运行 `python -m http.server 8793 --bind 127.0.0.1`，访问 `http://127.0.0.1:8793/demos/HaqiWorldLab.html`。依赖已经登记的 Keepwork Three.js r164 CDN；无需账号。页面为本地独立实验，不加入正式 Vite 发布入口、不改冒险存档，也未上传发布。

鼠标拖动环绕、滚轮缩放、Shift/右键拖动平移；触屏单指旋转、双指缩放。画布聚焦后方向键环绕、WASD 平移、加减号缩放、Home 返回全景。通过五个视角按钮或地标进入全岛、城堡、瀑布、村庄、港湾。支持巡游、晴日/日落、动画暂停、地标开关及线框。自由观察不含行走碰撞或寻路。

## 场景与导出

- `scripts/create_world_3d.py`：在 Blender MCP `execute_blender_code` 中执行的确定性建模脚本。所有变化使用固定解析函数，无随机服务。每次新建独立场景，保留原场景。
- `assets/world-lab/haqi-island.blend`：可编辑的 Blender 源文件副本；最终场景为 `Haqi Island · World Lab.001`，包含 861 个物件。海岛地表、岩岸、山体、蓝顶白墙城堡、72 棵树、谷地河流、两座过河木桥、12 间房屋、田地、凉亭、灯塔、码头和两艘帆船。
- `experiments/world-lab/island.json`：按材质及语义层合并的网格，共 40 组、28,642 三角面、2,196,513 字节。坐标 Z 向上。实验目录避免被正式数据打包器纳入；不需 GLTFLoader 或额外第三方库。
- `js/world_lab.js` / `css/world_lab.css`：浏览器渲染与独立界面。39 组模型网格被加载；Blender 的单面静态海洋改由额外程序海面网格替代。海面动画、泡沫、水帘扰动、旗帜摆动和小船起伏由网页驱动，不是 Blender 视口串流。Blender 文件中保留静态海面与瀑布几何。

海面额外约 64,800 个三角面；界面里的模型三角面数不包括程序海面。实际绘制调用数受视锥裁剪和渲染实现影响。运行时无纹理、美术 CDN 上传或云端存储。
