# 韩语：L0—L3 日常交流教学大纲

## 教材范围与语言专属路径

以世宗学堂 Introduction、Beginner 1/2 的初级范围为依据；本表是儿童游戏任务编排，不等同教材册号、TOPIK 或 CEFR 等级。例句、活用和语体须韩语教师复审后发布。

L0：谚文基本元音、辅音和音节块，先拼自己的名字与熟悉物品。L1：常见收音及连音在整词中练，认简单标签；学习韩文输入和空格。L2：听读礼貌词尾、常见过去式，区分天气冷和物体冰凉等语境；写短便条。L3：读生活消息串，写连贯的三到五句说明。以해요体为主要交流语体，固定问候另讲，不混用原形和礼貌体当同一台词。

来源核验边界见[教材台账](sources-and-vocabulary.md)。本页例句是作者拟定的课堂表达，候选词不是完整官方分级词表，具体来源页码／Can-do 与 WordTree 映射仍待 CUR-02、CUR-04 完成。

## Level 能力进阶

| 项目 Level | 听说目标 | 读写目标 |
| --- | --- | --- |
| L0 | 问候、姓名、听懂简单动作 | 识别基本音节块，尝试拼写姓名 |
| L1 | 说明人和物、所在、喜好与需要，请对方重复 | 读简单谚文标签；自己写一句请求或介绍 |
| L2 | 谈时间、数量、天气、感受和简单过去 | 读短便条和清单；写两三句安排与说明 |
| L3 | 约见、传话、分工、解释差异与简单叙述 | 读多条生活消息；写三到五句可用的邀请或回顾 |

L0 小故事：认识自己的名字 → 听指令帮宠物做一个动作 → 给熟悉物品贴标签。三项均为新增教学设计，需各语声音／文字资源和实际动作接入，不用纯选择题冒充已经会听说读写。

## 九岛单元与故事群

各单元的 A／B／C 为三个主故事位，T1／T2／T3 为三个迁移故事位；每个故事都要另写完整分镜与真实动作。下列词以基本形式或固定语块列出，台词必须使用自然形式。每篇仅选其中少量首次教，其余分散到后续故事。

### KO-U01 · L1 · 字源岛：等候与问候

**能做什么：** 介绍自己、找朋友、问位置、请求重说。

**种子词／语块：** 안녕하세요、이름、저、친구、물、집、어디、여기、누구、오다、가다、기다리다。

**关键表达：** 저는 …예요. / 친구가 어디에 있어요? / 다시 말해 주세요.

**语言结构：** 이에요/예요、이/가、은/는 的常见句；不一开始讲全部规则。

**A → B → C 故事链：** 《기다리는 의자》：小灯留了等候位置，朋友却认错椅子；玩家问清名字与位置再传话（首岛骨架待重写）。→《이름표를 찾아요》：读姓名牌找到主人。→《다시 말해 주세요》：只听见部分请求，重问后选择正确方向。

**T1／T2／T3 迁移变化：** 换等待者；改位置；家园找走错角落的宠物。换情境时不能给完整答案让孩子抄过关。

**读写落点：** 读姓名牌和常见位置词；写自己的名字和一句等候信息。听力必须至少有一次隐藏原文后做动作；口语至少有一次只给意图、不给整句答案的回应。

**家园与战斗复现：** 家园从本单元已学目标中选 1—3 个，围绕照顾、找物、布置或轮流游戏使用；后续单元至少再次使用其中一个表达。文字卡只复现当前目标语言实际练习过的词。

## 单元之间怎样复现

U01 的招呼、问位置、请求重说贯穿九岛；U02 的喜欢和需要用于 U04 照顾；U03 的停止与求助用于 U05 旅行；U04 的时间用于 U07 约见；U05 的数量用于 U09 分工；U06 的解释与道歉用于 U08 澄清；U07／U08 的消息与位置最终在 U09 综合使用。每条目标的具体故事位置仍需在词条账本登记，不能只靠这段说明宣称已覆盖。

## 毕业任务与范围终点

用目标语言筹备一次小型聚会：听两位伙伴的需要，读一份物品清单，问清一处时间或地点，按真实场景完成一项行动，自己写一条有效邀请；随后对一个变化重新安排。允许查一个生词或请求重复，不能显示整句答案。再换 NPC／物品和另一次会话复测。听、说、读、写分别评价，任何一项缺证据都不标完成。详见[验收规则](assessment.md)。

L3 之后继续在基础结构内增加新情境、新词和新人物，不追加高级 Level。教材词汇预算及系统缺口见[词汇台账](sources-and-vocabulary.md)与[RSI 队列](backlog.md)。
