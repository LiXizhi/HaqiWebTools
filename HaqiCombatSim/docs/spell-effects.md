## 配置格式

`palettes`按学派设置主色、亮色、暗色；`timeline`定义普通/召唤攻击起点与命中点（0–1）。`frames`是图集像素裁剪矩形。生成图集不是严格等距网格，因此使用明确裁剪，不调用通用4×2 tile切片。

`cards[原card key]`包含：`name`、`kind`、`duration`毫秒、`count`粒子上限、`scale`、原定义`source`。召唤类另外设置`summon`与`attack`。`summons`指定资源ID、登场/攻击frame、基础显示尺寸。例如海狮冰剑使用`seaLion`和`swords`，2600ms。

在JSON中修改卡牌参数即可，不需要构建。新增效果种类在`spell_effects.js`实现绘制，并在`spell_effects_core.js`登记、验证。缺失卡牌、非法种类、召唤引用、时间轴和粒子数量会阻止资源加载并显示恢复提示。粒子数量不超过160；帧采样基于归一化进度，不依赖帧率；缓存最多129组后清理。手机按画布尺寸缩放。

`spell_effects_core.js`只有验证/视觉种子/时长解析；`spell_effects.js`只调用传入Canvas context，不改变游戏状态。`adventure_app.js`为cast选择配置时长；`adventure_renderer.js`按caster/target映射位置。存档无需迁移，加载战斗仍重演引擎决定，不保存瞬时粒子。

## 预览

运行静态服务后打开 `http://127.0.0.1:8791/HaqiEffects.html`。追加 `?assets=cdn` 检查线上素材模式；默认仍是本机local、线上CDN。主入口仍为 `Haqi.html`。

召唤角色默认从战斗大法阵中心登场，主战斗和技能工坊显式传入各自法阵中心。中心法阵、升起粒子和攻击弹道使用同一原点；攻击阶段可向目标短距离前冲，角色朝向随目标方位翻转。普通施法与失败消散仍以施法者为起点。

压缩图集后，`atlasSize`保留frames的设计坐标系，绘制时按实际media尺寸换算，避免缩图导致裁剪错位。WebP准备强制单张200,000字节以内。

## 全基础与共享变体（配置版本2）

- `bases[baseId]`：225套基础参数，保留kind、duration、count、scale、friendly、area、secondary、source和已手工制作的召唤参数。
- `cards[cardKey]`：701条轻量引用，仅base、原名及variant（rank、level、lowLevel）。没有为每个变体创建独立文件，也没有复制完整演出。
- `variantAuras`：绿/蓝/紫/金共享光环颜色和圈数；普通等级变化只改变光环半径，金卡追加金色晶芒。粒子由基础ID播种，变体共用基础轨迹。
- 先去除品质/低等级后缀，再根据原spellName合并别名。`Level0`的数值变体共享；原版不同法术（例如冰霜破/陨落冰石）不会仅因Level字样而错误合并。
- 新增吸收、反射、光环、净化、偷取、眩晕、冻结、隐身、激怒、魔力球、捕捉、宠物、消散与跳过演出；群体模板可接受targets数组。预览提供三目标演示。
- 完整工坊按学派、基础技能、等级/品质三级选择。已打包原卡面可由变体共用，其他技能画“演出示意 · 非原版卡面”，不会加载未准备或超过200KB的额外原图。

开发命令：`npm run export:spell-names`可从原数据库安全解析中文名称（不执行Lua），快照为`data/kids/card_names.json`；`npm run prepare:effects`用显式类型映射补齐配置并保留现有基础参数，重复执行结果一致；`npm run audit:effects`验证701/701、缺项0且所有基础引用有效。运行游戏不执行这些命令，也不依赖父仓库。

完整卡库基础名来自本地数据库661条直接名称，其余使用通用演出名称或共享基础名称。支持当前导出内容；新出现的未知type必须先补显式映射，准备命令会失败，不自动用默认光球代替。
