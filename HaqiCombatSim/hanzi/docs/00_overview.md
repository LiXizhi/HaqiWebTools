## 二、后续开发原则（对齐《森》与《光》）

1. **禁止使用通用模板批量拼凑**：
   - 不再用 `scripts/build_hanzi_stories.mjs` / `hanzi/source/player.js` 套壳生成。
   - 每一个字都必须像 [`hanzi_sen.html`](../hanzi_sen.html)（约 1800 行独立 3D 剧场）和 [`hanzi_guang.html`](../hanzi_guang.html)（约 2100 行独立 2D 剧场）一样，作为**完全独立的单文件作品**从头定制镜头、光影、粒子、音效与分幕状态机。
2. **逐字精做，做一个验收一个**：
   - 每次只专注打磨 1 个字（或最多与用户确认的小步），真正在浏览器里对比《森》《光》的视觉表现、交互手感、甲骨/金文→小篆→楷书过渡动画与毛笔描红体验，达标后再进入下一个字。
3. **保持协议兼容**：
   - 保留 `<head>` 中的 Haqi H5 Protocol v1（`haqiHanziWritten`、`haqiHanziComplete`、`haqiHanziCaption`、`haqiHanziUi`），确保与游戏内字源岛任务和汉字字典无缝衔接。
