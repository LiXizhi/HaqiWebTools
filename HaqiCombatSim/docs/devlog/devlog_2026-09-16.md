## 关键决策

1. 纯 JS 1:1 移植 Lua 公式，不桥接 NPL（`combat_server.lua` 与 GSL / PowerItemManager 强耦合）。
2. 无构建、无框架，与 MagicHaqi 一致。
3. Bot 策略复用官方 `deck_attacker_ai/Aggressive{School}.csv` 情境权重。
4. 所有可调数值集中在 BalanceParams 覆盖层；数据集只读、不入库。

## 复核中修掉的引擎问题（影响胜率结论）

1. 单体陷阱 / 虚弱被贴到自己身上（目标阵营按 type 一律 friendly）→ 按 charm / ward 模板 `positive` 推断。
2. X 费 DOT（`"42p"`）被解析为 0 → 按实际消耗倍乘（kids 烈火 8% → 21%）。
3. 溅射 DOT（负值段）被跳过 → 打持有者及相邻队友。
4. `SymmetryWards` 读错参数名；先手统计口径；`perSchool.damage` 原为「预留」现已生效；Life 光环 UI 文案 `+null%`。

## 观察（供数值同学）

- teen 生命系在官方 Aggressive 卡组下 1v1 对外胜率 17%、平局 43%，团队模式趋近 0%：低伤害攻击牌 + 各系卡组都带 `Life_LifeGreatShield`，80 半回合上限内拖成平局。
- kids 死亡系随人数增强（1v1 69% → 4v4 91%），寒冰全模式 65~74%。
- 先手优势 53~61%。
