# 抱抱龙随行引导与三段训练

本地实现与后续设计，2026-11-10。未发布。目标是让玩家始终找得到下一步，同时保留自己探索的空间。

## 两个角色如何配合

青龙负责关键教学和任务交接，每次只讲眼下一个动作。抱抱龙负责一路陪玩：玩家不知道怎么办时点头像或场景同行伙伴，显示当前目标，再提供一个直接可执行的按钮。不会代替玩家出牌、领取奖励，也不把点击提示算成语言学习。

新手不需要先读功能说明。固定入口叫“抱抱龙 · 带我玩”；展开后左侧仍保留已有伙伴形象，说明一次不超过两句话。进入另一个任务、选择卡牌、完成挑战时读取真实状态，不另存一套容易与任务脱节的进度。玩家可以收起；不定时催促、不反复打断、不把付费作为继续条件。

## 本轮已接入

- 世界场景：开始阶段衔接咕噜噜目标；之后衔接当前主线接取、进行、领奖。其他岛屿优先既有语言任务推荐，没有可识别任务时打开任务列表，不编造指路。
- 场景同行伙伴可点击打开帮助；固定头像入口在伙伴暂时不在视野时仍可使用。
- 战斗：未选牌时指向当前可用牌，已选牌时指向目标操作；动画播放时等待效果，失败后说明可以调整再试，胜利后指向领奖。只突出按钮，不自动代打。
- 青龙：帽子说明简化为“赢下这次训练，这顶帽子就是你的”；装备卡效果单独展示，领取后才提示穿戴。取消把历史完成规则塞进新手对白。
- 火焰训练：低威力小招，练习选牌和目标。
- 寒冰训练：回合开始先施放已有全系护盾，玩家可用小招消耗盾、伙伴接力。盾按原引擎消耗，不能假称“等一回合自动消失”。
- 风暴训练：第一回合试探，第二回合用已有攻击增益蓄力、不攻击，第三回合重击。每回合出牌前提供预告。玩家可以抢攻、恢复或利用增益准备；不要求拥有某张新卡。

训练适配只作用于带新手旅程记录的营地三场新战斗。保存训练版本；此前已经开始的战斗保留原规则。奖励与原始怪物数据不改，数值从 BalanceParams 取值。不是原版数值的宣称，也不是全游戏平衡调整。

## 后续全游戏陪伴设计（尚未全部接入）

| 场景 | 抱抱龙怎么陪 | 玩家自己做什么 |
| --- | --- | --- |
| 第一次到岛屿 | 先发现一个具体的人或事件，让玩家选要不要去看看 | 决定路线，不自动接下所有任务 |
| 帮助居民 | 记住当前任务的实际进度，只说下一步 | 找人、交谈、完成行动 |
| 英语交流 | 先说明表达意图；需要时给示范、释义和自选输入 | 选择或表达；系统分别记录练习证据 |
| 拿到装备 | 展示外观与一个最直接的用途，提供穿戴入口 | 选择是否穿戴 |
| 家园布置 | 首次只提示摆一件东西；摆完再按物品给出反应 | 自由布置，不强制照模板装修 |
| 战斗失利 | 根据实际回合指出一个可改进动作 | 重试或先去做别的事 |
| 一段任务完成 | 对刚发生的事作一句具体回应，再给两个可选去处 | 选择继续冒险或休闲 |
| 隔天回来 | 说出上次未完成的真实目标 | 继续或换件事，不补课、不惩罚 |

家园专属反应、跨天记忆、全岛独立事件、可选路线与通路变化仍属后续接入；现有入口不是已经完成全部情境引导的证明。优先继续用真实任务和角色状态驱动，禁止用通用AI闲聊冒充已经完成的剧情。

## 陪玩语气与触发边界

陪伴感来自一起做过的事。青龙负责交代缘由，抱抱龙负责眼下的一小步；不让两个角色同时讲同一件事。下列为后续情境接入的示例，不表示现有地图已完成这些剧情。

- 不知去向时：“刚才青龙让我们找茜茜，我带你过去？”只有一个“带我去”，另留关闭入口。
- 拿到新帽子时：“这顶帽子还带一个新招式，要不要穿上试试？”先看外观和用途，再谈数值。
- 完成一段冒险时：“刚才多亏你了。想再去探险，还是回家歇一会儿？”两个去处都必须真的能进入。
- 家园摆好灯后：“这里亮起来了，我想坐在旁边。”仅在真实摆放完成后出现短回应或已有动作，不凭打开菜单就称赞完成。
- 失败时先说明一个有证据的原因，例如“它蓄力后那一下很重，下次我们先准备护盾？”没有可用护盾就不建议不存在的操作。
- 熟悉玩法后，默认收起成小头像。只有任务阶段变化或玩家主动点开才更新解释，不要求每一步都点“知道了”。

先把“任务带路—战斗求助—领奖看用途”做好，再补家园反应和跨天接续。全岛独立陪伴台词随着岛屿玩法打磨一起补，不能用一套夸奖文本掩盖岛屿内容重复。

## 验收重点

能找到入口；展开后说得清下一步；按钮能带到实际入口；选牌后提示随之变化；收起后不挡路；换角色不串状态；刷新不重置任务；没有匹配任务时诚实引导到任务列表。战斗检查真实盾与蓄力行为、各系初始牌可应对、旧战斗恢复、胜利不重复发奖。手机布局与桌面分别验证，不用自动测试代替真人留存结论。
