# 2026-10-15 · 汉字互动故事「雨 yǔ」

## 选题

用户要求再做一个汉字动画，自己选题，且要比之前的好。已有正式故事：门、休、森、光、国。

选「雨 yǔ」：云是盖子、四点是雨滴，故事里的物件可以直接长成笔画（水汽聚云成盖、雨滴落下成点），
比光（火在人上）更顺，比门国的纯演变路线多一层天气叙事。八笔，描字比三笔的门、六笔的光更耐写。

一句话主题：天上的水，落下来就是雨。

## 分镜（引子 → 探索 → 变化 → 成字 → 亲手写字 → 余韵）

久旱（裂土、低头小苗）→ 聚云（点三团水汽送进云）→ 降雨（点乌云、电闪雷鸣、雨声）
→ 生长（点小苗助长、彩虹）→ 成字（雨滴汇成甲骨文，变形为楷书，云四笔水四点）
→ 描字（八笔笔顺、看示范、超时自动示范）→ 雨后（组词雨水、下雨、及时雨，点天再下一场小雨）。

字源只写两句可核对的话：甲骨文云在上水在下；《说文解字》：“雨，水从云下也。”
古字形按艺术示意处理，页面角落有统一标注。

## 做法

- 单文件 `hanzi/hanzi_yu.html`，Canvas 2D + 内联样式脚本，无外部资源，普通 HTTP 静态服务可直接打开。
- 复用光的故事机（虚拟时钟、镜头、WebAudio 合成音、逐字字幕、甲骨楷书逐点变形、描字容错），新增：
  天空四段调色（旱黄、阴灰、雨青、霁蓝）、云团合并、雨滴水花涟漪水洼、小苗五株生长开花、
  七色彩虹、循环雨声（带通噪声，随雨势推子）、雷声（正弦滑音加噪声）。
- 八笔笔顺：横、竖、横折钩、竖、点、点、点、点；描字区分云笔与水点两组提示。
- 随机数只走 mulberry32；`prefers-reduced-motion` 降低粒子与镜头漂移；竖屏重排镜头；
  每个画布互动都有按钮等价操作（聚集水汽、呼唤下雨、看它们长大、看示范、再看一次）。

## 修正：雨字形重做（用户指出字不对）

- 症状：手绘示意的雨把中间一竖画短、左竖起笔接上横、四点排成一横排，笔画像火柴头。
- 对照 `data/adventure/hanzi/strokes.json` 里 Make Me a Hanzi 的真数据渲染后确认：
  中间一竖自上横直贯而下、左右各两点，左竖起笔在中横处。
- 修法：楷书八笔骨架改用真 medians（x/9、(900-y)/9 换算到局部坐标，轻平滑），

  粗细改成书法收放（横蚕头燕尾、竖上细下足、钩末收尖、点作泪滴），云水标注框跟随新布局。
- 用同一套 headless 黑盒重走全场，无异常，截图确认字形正确。

## 与之前相比好在哪里

- 故事与字形同一套因果：云和雨滴既是剧情也是笔画，成字转场是收集的结果。
- 天气是一套连续系统（云量、云色、雨势、土壤湿度、水洼、彩虹、日光互相挂钩），
  不是几段独立动画。
- 八笔描字加云水的分色标注与分组提示，教学信息比之前密。

# 2026-10-15 · 五大岛实际场景美术包（沙漠岛样板完成）

## 背景

用户反馈：世界地图里的岛屿插画很精致，但进入岛屿后地面仍是平涂色块。魔法营地已经优化过，这次继续处理哈奇、火鸟、寒冰、沙漠、幽暗五岛。

## 本次完成

- **数据驱动的岛屿美术包**：`config/maps/islands/<id>.json` 新增 `sceneArt` 块（地表/道路/水体材质、路边道具、散布道具与地貌、山体贴图、平铺类帧），通过 `generate:maps` 进入 `layout.sceneArt`。五岛的配置都已写好；还没有对应图集的岛会自动保持原来的画面。
- `js/island_scene_art_core.js`（纯核心）：负责材质查找、山体贴图选择，以及按世界坐标、固定种子散布道具和地貌，避开道路、居民、怪物、建筑、树、水体与山体，不消耗游戏随机数，也不影响采集。
- `js/island_ground_textures.js`：地表、道路、水体按世界坐标图案填充，切块之间无接缝；区域使用与原色块相同的径向软遮罩。生物群系配置为 `null` 时保留原色（哈奇岛雪地/海滩、沙漠绿洲）。主线程和 Worker 共用同一套逻辑。
- `adventure_large_terrain.js`：地表有材质时跳过程序噪点；道路材质铺满路面后不再画程序石板；山体有贴图时替换多边形台阶，图集未到时仍回退原样。
- 地表图集新增 `pattern()` 接口（`adventure_environment_art.js`、`island_terrain_worker.js`、渲染器包装层），图集加载完成后切块按原有机制重新烘焙。
- 寒冰岛森林改用积雪树图集，去掉绿色阔叶树和旁边的绿色灌木。
- `tests/fixtures/exploration.html` 进入岛屿时预热场景图集，与正式游戏一致（以前预览页从不加载地表装饰图集）。
- `scripts/prepare_island_scene_art.py`：2×2 地表格子用重叠条带交叉淡化做成可平铺材质；道具和地貌支持真透明、白底、品红底三种来源，并去除白边残留；全部 ≤200,000 字节。
