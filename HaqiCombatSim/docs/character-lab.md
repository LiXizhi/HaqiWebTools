# 3D 角色工坊

独立实验入口 `demos/HaqiCharacterLab.html`，不接入冒险状态、不包含在正式 Vite 发行入口中。使用普通 HTTP 静态服务运行，例如 `python -m http.server 8793 --bind 127.0.0.1`，打开 `http://127.0.0.1:8793/demos/HaqiCharacterLab.html`。

参考用户提供的棕发、蓝金制服、水晶护肩儿童角色图，使用 Blender MCP 创建风格化三维原型。当前未启用 Rodin、Hunyuan3D 或 Tripo，模型由 `scripts/create_character_3d.py` 程序建模，并非图生模型或原图的精确复刻。背面结构为设计推断。

## 资产与动画

- `assets/character-lab/hero.blend`：Blender 5.2.1 源文件副本；新建独立场景，保留原有场景。时间轴 1–60 为待机，61–120 为行走预览。
- `experiments/character-lab/hero.json`：第二版静态网格、关节层级与材质配置，169 节点、43,703 三角面、1,033,306 字节。坐标 Z 向上，前向 -Y；浏览器根节点绕 X 转 -90 度。独立目录避免纳入正式运行时数据打包。
- `js/character_lab.js`：Three.js r164 从已核验的 Keepwork CDN 加载；自有 JSON 读取器，不引入额外 loader 或第三方依赖。
- 待机包含呼吸和眨眼；行走包含对侧摆臂、屈膝及披风摆动，支持渐变切换、速度和暂停。
- 发色、制服、镶边即时更换，披风及水晶护肩独立隐藏，头部比例可调。配色和外观仅保存在当前页面内存中。

当前采用刚性关节层级动画，未实现蒙皮骨骼、足底 IK、服装碰撞或布料模拟。不能把此验证视为量产换装系统已完成。第二版已重做碎发轮廓、后脑头发、眼睛与外套结构，但仍是立体风格化重建，尚未复现参考图的手绘纹理和细碎发丝；换装资产需统一骨架、插槽、尺寸和蒙皮权重，再扩展成可复用服饰库。多人性能尚未测量。

此原型不依赖运行时图片或纹理，也未上传或发布。Blender 文件仅供源码归档下载，不进入正式发行包。若计划上线，模型发布与正式入口需要另行接入项目 CDN 流程。
