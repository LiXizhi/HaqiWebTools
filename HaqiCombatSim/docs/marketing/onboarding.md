## 执行门槛

- 每个平台登记官方政策、核对日期、资格、适配成本、状态及下一步；未知不写通过。
- 50–100 人试运行前核验官网交互、登录、AI、追踪、反馈及真实订单。
- 平台包必需官方 SDK 的限定例外已由负责人授权；官网不能顺带加载这些依赖。
- Discord Bot 与各平台适配器仅在有真实权限后实现和验收，不创建虚假的连接。
- 报告生成、消息提交、消息送达及未来定时准点运行是四种状态，分别记录。
- 海外 CDN／登录／AI 延迟以及峰值并发需要实测；1000 注册不是 1000 并发。
