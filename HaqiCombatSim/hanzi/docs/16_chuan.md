# 16 · 传（`chuán`）—— 一驿接一驿，把灯传下去（`hanzi_chuan.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：传；拼音：`chuán`（本课主音）；本义：驿传、接力递送；引申为传授、传播、传承。
   - 多音辨读：读 `zhuàn` 时指记载人物生平的「传记」、解释经书的「传注」。页面在词意一幕明确点出两读分工。
   - 训诂：《说文解字》：“傳，遽也。从人，專聲。”“遽”即驿站的传车快马；《礼记·玉藻》“士曰传遽之臣”，皆指接力递送之人。
   - 常用词：`传递`、`传承`、`言传身教`。
2. **古文字部件溯源与楷书六笔**
   - 「传」是「傳」的简化字，形声结构（从人，專声）：
     - 左部 **「亻」（人）**（2 笔：撇、竖）：甲骨文、金文象侧身站立之人，作为义符，表明「传」是**人**把东西交给**人**的行为。
     - 右部 **「专」（繁体「專」）**（4 笔：横、横、竖折撇、点）：古文字从「叀」（纺砖，绕线之锤）从「寸」（手），本义为手持纺砖专一旋转，在「傳」中作声符提示读音。简化后写作「专」。
   - 页面 `sGlyph` 先以古文字部件「人 + 叀 + 寸」合璧为小篆结构，再演进为规范楷书六笔，并明确说明：“左边「亻」是一个人，右边「专」提示读音；驿道上把灯与信手手相传为本课的记忆联想。”
   - **教学边界**：驿道传灯是艺术隐喻，不是「传」的造字本义场景；造字本义为驿传递送。页面右下角 `#note` 常驻声明“古字形为艺术示意”。
   - 笔画轮廓与中线内联自 `skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（1024 字框，基线 900，Arphic Public License）。

## 二、一句话主题

> 夜色深沉的山道上，四座驿站依次亮起，一盏灯、一封信在人手中接力向前，直到山谷那头的万家灯火——一个人把东西交给另一个人，就是「传」。

## 三、美术、材质、色彩与声音

- **视觉语言：南宋马远《寒江独钓》式大片留白夜色 + 驿道灯火的暖橙点光。**
  - **Three.js 真 3D 立体剧场**（`#glView` WebGL 基底 + `#inkView` 2D 笔墨与 UI 双层），单 rAF 循环、DPR ≤ 2、几何与材质全局复用（松林 / 村舍 / 窗火 / 升灯均用 `InstancedMesh`）。
  - 色彩系统由题材派生（8 色）：夜驿玄青 `#0a0f1a`、宣纸素白 `#f4ead6`、驿灯暖橙 `#ffb347`、烽火朱橙 `#ff6b35`、朱砂印 `#c8402f`、驿路青碧 `#4ec9b0`、冷月霜白 `#cfe0f5`、雾灰蓝 `#8b98ad`。
  - **戏剧化光照**：冷月主平行光（软阴影 1024 PCFSoft）+ 青碧轮廓光 + 破晓暖阳光 + 四座驿站独立暖橙点光 + 村口烽火点光；线性 `Fog` 夜雾（近 10 / 远 46，破晓后放宽）、四道自定义 shader 体积光柱（边缘与首尾双向柔化，非实心楔形）、520 粒柔光贴图夜雾流萤、自发光灯焰与窗火、缓慢镜头漂移。
  - **构图层次**：相机挂载的天空穹顶（上下渐变 + 破晓地平辉光）、霜月与柔光晕、300 星点 → 世界空间三层连续山脊带（受雾衰减，底缘由深度测试裁掉，任何画幅都不出现水平硬边）→ 中景蜿蜒驿道与四座飞檐驿亭、光轨随接力生长 → 前景驿使提灯、驿马奔驰、210 株实例化松林与 26 户山谷村舍万家灯火次第点亮。
  - **背景层设计要点**：天空下半球严格收敛到雾色，与远处地面同色相接；月轮 / 星点 / 光晕保留深度测试，避免透明队列把天空元素画到地面之上；竖屏时月轮位置单独上移，避开顶部进度条。
  - **字形舞台**：驿墙青砖拓片 → 竹简牍 → 宣纸米字格三段底板；古文字部件 → 小篆 → 楷书逐点 morph；真实 `Path2D` 轮廓 + 中线扫显描红；朱砂「传」印钤盖。
- **声音设计（WebAudio 原生合成，默认开启，顶部一键静音并显示状态）**：
  - 古琴五声拨弦（接力与笔画）、驿铃清响（驿站点亮）、夜风与山雾底噪、马蹄碎响（传书）、印章闷响、低音铺底随破晓渐暖。每一个声音都对应一个可见事件。

## 四、分镜（七幕 · 约 2.5–3 分钟）

| 进度 | 场景 | 画面与字幕 | 互动 |
|---|---|---|---|
| 片头 | `introPlay` | 霜月夜驿全景，驿灯暖金逐笔写出楷书「传」（无纸底时自动切换暖金书写，保证暗背景可读） | 点击「开始」进入正片；片头绝不触发 `written` / `completed` |
| 夜驿 | `sNight` | 夜色深沉的山道上，每隔一段路就有一座驿亭；亭中灯亮，旅人知道可以歇脚换马 | 观看夜雾、孤灯与驿铃 |
| 传灯 | `sRelay` | 四座驿亭沿驿道排开，第一驿已亮 | **互动 1（接力传灯）**：按住驿使手中灯笼拖到下一座带光圈的驿亭，驿使随后步行抵达并点亮该驿，光轨随之生长，共三段；「看示范」或闲置 30 秒自动接力 |
| 传书 | `sSend` | 驿马与马背竹筒里的家书，山谷村舍仍在黑暗中 | **互动 2（送出家书）**：按住「按住 · 送出家书」蓄力（松手回落），满格后驿马奔驰入谷，烽火升起、万家灯火次第点亮、东方破晓；闲置自动完成 |
| 成字 | `sGlyph` | 驿道人影收为「亻」，纺砖与手收为「专」，古文字部件 → 小篆 → 宣纸楷书六笔 | 观看字形结构与部件训释 |
| 写字 | `sWrite` | 六笔描红：撇、竖、横、横、竖折撇、点 | **互动 3（六笔描红）**：宽容趋势投影描红，完成后钤盖朱砂「传」印并触发 `haqiHanziWritten()` |
| 词意 | `sWords` | 依次点亮 `传递`、`传承`、`言传身教`，并辨读 chuán / zhuàn | 逐词与字幕严格同步 |
| 余韵 | `sFinale` | 灯火满谷，驿道如一条暖金的线 | **自由互动**：拖拽环绕 3D 山谷、滚轮 / 双指缩放、点击放飞孔明灯；四种意境（夜驿 / 破晓 / 灯火 / 雪驿）随时切换；触发 `haqiHanziComplete()` |

## 五、协议与验收

- `<head>` 内联标准 Haqi H5 Protocol v1（`scanStatic` 选择器与本页控件 id 对齐，含 `#moodBar button`、`#pause`）；登记入 `hanzi_index.html`、`js/hanzi_story_animations.js`（本地 + CDN 双 key）、三语词库与自动化测试；**不改动** `js/adventure_dictionary.js` 的 30 字字典。
- 确定性 `mulberry32`，零 `Math.random()`、零 `fetch`、零动态 import、零外部 `<script src>`；Three.js 仅从 `https://cdn.keepwork.com/keepwork/cdn/vendor/three/three.module.js` 静态引入。
- WebGL 不可用时先以探测 canvas 判定，静默隐藏 `#glView` 并回退 2D 夜驿（自成投影构图、月轮与孔明灯受 UI 约束、引导线用 `fbProject` 对齐），全部剧情与描红仍可完成，控制台无报错。
- 支持 `?fast`（快进字幕）与 `?auto`（自动演示）；页面隐藏 / 手动暂停时冻结虚拟时钟；`pagehide` 关闭 AudioContext；`prefers-reduced-motion` 降低动效。
- 调试接口 `window.__chuan`：`scene / finished / interactions / state / medians / strokes / strokeNames / toScreen / localToScreen / stationScreen / relayScreen / completeCurrentStroke / renderer / zoom`。
