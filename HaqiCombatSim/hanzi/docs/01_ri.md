# 01 · 日（`rì`）—— 破晓的太阳（`hanzi_ri.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**：
   - **汉字**：日
   - **拼音**：`rì`
   - **本义**：太阳（《说文解字》：“日，实也。太阳之精不亏。从○一象形。”）。
   - **引申义**：白昼（白天）、一天（一日）、光阴与日子。
2. **古文字演进（甲骨文 → 金文/小篆 → 隶书/楷书）**：
   - **甲骨文**：契刻于龟甲兽骨上，外围多作方形或八角棱形框，中央有一短横或小点，象太阳周廓圆满、核心光热充实之形。
   - **金文与小篆**：铸刻或书写线条圆转，外框呈饱满圆轮，中心一横或一点清晰居中。
   - **隶变与楷书**：圆轮方折化，演变为「竖（丨）、横折（𠃍）、短横（一）、底横（一）」四笔方框结构。
3. **事实与艺术边界声明**：
   - 动画中“海面红日外缘收拢为外框、日心金光凝为中间一横”是贴合文字学本义的视觉化引导。
   - 教学提示中明确指出“日”字中间只有**一横**（代表太阳中心实光），帮助儿童与里面两横的“目”（眼睛）区分。
   - 页面左下角保留说明：“古字形为依据甲骨文、金文及小篆通行字形的艺术示意”。

## 二、情感与动作主题（一句话）

> 漫长寒夜后的东海渔村，孩子吹散海面浓雾、亲手托起破晓红日、唤醒海湾三处晨光，看满天霞光里的太阳化作甲骨文与楷书的「日」。

## 三、美术、色彩、构图与声音设计（对齐《光》《明》2D 标杆）

### 1. 色彩与光影递进
- **破晓前（待旦/散雾）**：深靛夜海 `#070b1e`、寒雾青灰 `#394668`、微弱东方曙色 `#6e383e`。
- **日出时（托日升空）**：海天渐染绯红与琥珀金 `#e86f42` → `#f5b95f` → `#fff2cc`，海面随太阳高度实时铺开动态碎金倒影。
- **晴昼（照耀/尾声）**：苍穹明朗、金辉遍洒，远岛、木帆船、迎日石表与向阳花丛呈现温暖受光层与高光边缘。

### 2. 桌面宽屏与手机竖屏自适应构图
- 采用统一的世界坐标系（宽景海湾 `0..3200`，高 `0..900`）与动态摄影机 `VIEW`（`intro`、`bay`、`horizon`、`rise`、`wide`、`noon`、`glyph`、`finale`）。
- 竖屏（`portrait`）自动调整视场宽度 `pw` 与纵向重心 `pcy`，确保太阳、海面、帆船、字形与四笔描红区域在 `390×844` 手机竖屏与 `1440×900` 桌面宽屏下均完整居中、无裁切、无横向溢出。

### 3. WebAudio 实时合成音景（零外部音频依赖）
- **海浪潮汐底音**：噪声缓冲经低通滤波器周期起伏，营造清晨海湾呼吸感。
- **五声暖阳琴音与钟磬**：采用 D 大调五声音阶（`D4, E4, F#4, A4, B4, D5, E5, F#5, A5`）；太阳升起时和弦滤镜由暗转亮。
- **交互音效**：吹雾气流声、日出破海共鸣音、飞鸟清脆滑音、扬帆木铃声、描红逐笔琴音。
