# 第一次来做客的伙伴

家园英语L1两幕故事 `en-l1-first-snack`。前置已学bread、water；本轮只引入give、take两个新词。伙伴第一次扮演客人，担心动了主人的食物不礼貌：孩子先明确招待，再邀请它喝水。两个动作必须由同一只真实家园宠物完成。

第一幕：伙伴说“我是今天的小客人，想吃点东西，又不知道你有没有准备给我”。介绍give是给，此处表示给伙伴食物吃；孩子说“I give you bread.”，将伙伴带到面包篮实际吃饭。第二幕：伙伴吃过面包，仍不好意思碰水杯；介绍take在“Take some water.”中表示请用一些水，孩子说完后将原伙伴带到水杯实际喝水。结尾确认实际吃喝，邀请下次交换招待角色的想象，不承诺已实现角色交换自动流程。

另外给/请用与面包/水各有首次及回访作者变式，共8段，供复习调度。回访用不同礼貌意图：确认分享、户外活动后喝水、先说明招待再吃、回应客人犹豫。动作种类相同不能自动算四种独立生活情境，仍须持续补足十二机会、跨日复习与能力迁移。

当前动作是已有设施的宠物吃喝，不做物品所有权转移、库存扣除或赠礼奖励。take不扩张为随意拿别人东西；对话先明确主人邀请。输入或朗读均可，只有表达和真实吃喝都通过才计本轮目标词。仅有宠物动画、只回答、错误设施、换宠物或重复回调不能增加记录。
