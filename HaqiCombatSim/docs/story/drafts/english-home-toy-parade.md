# 玩具游行，谁来排队

英语 L1 家园连续故事，作者源 `english-home-practice.json`，ID `en-l1-the-toy-parade`。伙伴想演一场小小游行，孩子决定两个玩具的实际摆放。小黄鸭是橡皮玩具，木马是模型；它们不会变成宠物或自己走动。

本批正式导出 S2406—S2425，其中六幕为 S2420—S2425；完整对白见[家园故事集](../story-home-language.md)。

## 六幕与实际操作

| 稳定后缀 | 情节意图 | 明确目标与证据 |
| --- | --- | --- |
| duck | 找第一个游行角色，介绍 duck 是鸭子，眼前为玩具 | A duck.，点小黄鸭 |
| horse | 给小黄鸭找一个伙伴，介绍 horse 是马，眼前为木马 | A horse.，点木马 |
| listen | 伙伴报一个角色的英文名字，孩子来找 | 听 Find the duck. 后选择原小黄鸭，木马提供干扰 |
| read | 用短英文线索找到另一个角色 | 读 Find the horse. 后选原木马，小黄鸭提供干扰 |
| near | 两个角色准备一起排队，孩子决定邻近位置 | Near the duck.，实际移动原木马到原小黄鸭附近，不重叠 |
| label | 给刚排好位置的木马留角色名，下次还可继续演 | 在原木马保存 A horse. |

先用 NPC 开场说明原因，再进入短回应或听读选择。最多三个新目标 duck、horse、near；听读仅用于已练过的词，不计表达次数。听读开场不说目标中文或英文，也不把作者说明当角色台词。

故事保存最初的小黄鸭与木马身份，换另一个同类玩具不能冒充原角色。位置冻结原小黄鸭；删除或移动参照后不能用旧结果计分。结束只说明孩子已摆放玩具和保存标签，不声称已经播放游行动画。

## 同步增加的独立练习

为 duck、horse、picture、cake、wall、floor 各补 read/listen，复用已经存在且已教过的目录道具。至少存在一个不同类物品作选择，多个同类目标均可选。动物玩具辨认不冒充真实动物辨认；wall／floor 使用原装饰墙与木地板对象，不声称检查了完整建筑结构。

duck／horse 另有给模型写角色标签的复习，用于保存到原物品的短词写作。所有新增内容增加的是已覆盖词的技能机会，不增加新词覆盖。跨天、三种生活情境、真实语音、触屏和儿童自主迁移仍需后续验证。
