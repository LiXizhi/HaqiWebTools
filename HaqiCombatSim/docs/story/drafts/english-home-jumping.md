# 小演员跳着打招呼

英语L1家园jump首次故事。伙伴想看一个小演员的开场，孩子先选椅子当观众席，再回应并让游戏主角在椅子附近原地小跳，落地后邀请伙伴实际坐下。三幕分别明确练chair、jump、sit，每幕一词；复用真实椅子与伙伴，不假装舞台、录制或演出系统已经存在。

原地小跳持续0.65秒，用现有角色画面升降，影子留在地面；不改变地面坐标，不用于跨越障碍。必须先回应正确、走到本轮原家具附近、主动按“跳一下”，逐帧起跳落地后才记一次jump表达。仅说词、点击家具、等待、只起跳未落地、重复回调或过期会话不计。跳跃中切换语言、角色或布置使结果失效；未完成动画不写存档。减少动态效果时保留小幅位移和起跳/落地文字。

孩子本人可以坐着玩，不需要现实跳跃、摄像头或麦克风动作识别。没有倒计时、名次或表演评分；角色新动作是原立绘的起落表现，不宣称新增专属骨骼动作。

另有椅子/桌子旁招呼的首次与回访四变式。回访仅选已学词，首次教学遵守会话预算，目标词与角色隔离的WordTree共用。只能证明有引导表达与原地跳操作，不能当作独立听令、自由表达或L1通过；岛屿故事、独立四技能、充分跨日复现和儿童体验仍待补。
