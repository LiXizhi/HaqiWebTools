# 同屏 AI 陪伴（2026-10-06）

双人模式可选两位真人或真人与 AI，使用同一账号/访客的两个已有角色。第一角色始终由用户控制；第二角色可以在场外交给 AI 或接管，战斗中保持进入前确定的控制方式。游戏显示区域至少 800×480 CSS像素，不额外限制宽高比。当前仅本地实现，未发布。

## 行动与战斗

本地 planner 每秒检查有意义的目标，不再随机探索。离主角超过220单位时先安全归队；平时优先原地冶炼、附近拾取和就近采集，采集保持同一资源直到耗尽。没有有用目标且在主角110单位内就停留；超过舒适距离才靠近，跟随落点为主角周围65单位的安全位置。不可达目标冷却30秒再试。参数均读取BalanceParams.companionAI覆盖层，只有语音间隔使用独立播种RNG，不消耗战斗随机序列。沿用地图碰撞、寻路、共享相机、采集和冶炼。AI 不自行触发遭遇、旅行、任务领取、购买或赠送；轻量聊天中的挑战/地图按钮由真人选择。

托管关闭第二角色的键盘、手柄和出牌输入，世界鼠标归主角。场外切换取消旧异步请求；战斗期间不接受切换，也不排队到后续回合执行。战斗使用既有 BattleAIClient 分析公开观察，超时使用合法本地行动回退。AI 英雄仍以 local-hero-1 加入 humanDecisions，沿用双角色独立资源、回放、结算与领取凭据，不改成普通机器人，不自主使用消耗型符文。

托管时战斗建议由 AI 玩家气泡提供，可收起或关闭本场队友提示；选牌/提交后清理旧提示。建议仍由本地战斗分析生成，不等待大模型。双真人和单人规则保留。

## 陪伴 skill 与交流

`data/adventure/companion-ai.json` 是运行时长篇 skill 的唯一作者源，Markdown 正文保存在 JSON 字符串中，随配置发布。包含身份、观察、语言难度、沉默与节奏、共同目标、纠错、战斗、记忆、示例和输出契约。首版复用已有 Keepwork 模型/ASR/TTS 接口；不新增第三方服务。Codex CLI、Workbuddy CLI 与 Keepwork MCP 适配明确留待后续。

双语开启时使用主角的 target，关闭时使用 native。界面语言和第二角色自己的设置不决定对话语言。默认45–90秒检查主动交流；场景、目标和近期事件未变化时保持沉默，连续两次未回应后停止主动邀请，直到玩家再次发言。安静陪伴关闭主动交流，直接聊天仍可用。主动回复每次一至两句；头顶气泡与轻量文字/主动录音聊天共存，释义可以展开、朗读可以关闭或重播。录音复用公共会话和麦克风手势；仅开启学习后的真实非空识别调用已有口语参与奖励，文字与 AI 台词不发奖。

模型收到当前有限场景、具体行动、候选资源名称/剩余数量/距离、伙伴资源估值、主角移动状态、近期真实事件和本机记忆；只能返回 reply、translation、goalId、summary。本地重新校验目标，不执行模型工具。地图/回合、语言、账号、托管、暂停或清除记忆发生变化后，旧响应作废。暂停取消语音；恢复后不补播旧队列。

离线、未登录或模型不可用时保留本地行动和中英基础台词；其他语言没有基础台词时明确提示，不用中文冒充所选语言。真实在线模型的语言遵从、语音质量及麦克风体验仍需要账号实测。

## 仅本机记忆与额度

独立 IndexedDB `haqi-companion-ai-v1`，记忆键为账号/访客、主角和第二角色组合。保留最近24条消息、20条真实事件及2000字以内摘要；支持查看与清除，清除递增 generation 防止迟到写回。包含少量文字/识别文本，不保存录音，不进入云端文件或角色 dirty。与原 NPC 非好友关系会话内存政策分开：这是用户明确要求的本机陪伴记忆。

额度按本机账号共享，默认北京时间每日120次模型生成，主动最多40次，所有会员类型采用同一首版配置。不占原自由聊天每天2次额度，不通过换角色重置。IndexedDB 单事务预留，已发出且结果未知的请求保留占用；明确发送前失败可释放。设备时钟回退不重新刷新额度；这不是服务端跨设备限额。参数集中在 BalanceParams.companionAI。

## 验证入口

- `tests/battle_companion_ai.test.mjs`：语言、额度、记忆、目标校验、确定性、本地决策和回放。
- `tests/fixtures/companion-ai.html`：真实 DOM/IndexedDB，模拟模型与语音，核验会话失效及130次并发额度预留。
- `tests/fixtures/local-coop.html?aiBattle`：仅空白 localhost/127.0.0.1 测试浏览器，准备带双人 AI 检查点的访客角色，不覆盖已有角色。
- 必跑 `npm run test:battle`；真实服务、麦克风和实体手柄不由模拟测试证明。

## 2026-10-07：双人 HUD 与战斗控制权

玩家1的坐骑、双语和私聊入口位于自身信息卡下方；玩家2信息卡再向下排列，其下放自身坐骑与圆形 AI 托管图标。托管图标仅场外可操作，进入战斗前确定控制权；战斗期间隐藏入口，控制器同时拒绝切换请求，恢复未结束战斗沿用检查点中的控制方式。陪伴聊天沿用玩家2工具栏的互动入口。

双人模式不再在两名角色头顶绘制固定“…”互动按钮。仅在两人距离不超过180世界单位时，在玩家2信息卡下方的工具栏显示一个“…”；菜单提供第二角色跟随/不跟随玩家1、查看信息以及AI队友聊天。进入战斗、暂停或打开第二角色窗口时隐藏入口；菜单打开时重新检查距离。

### 2026-10-07：共用互动菜单与两名玩家靠近NPC

两名玩家都保留坐骑按钮，无坐骑时打开自己的坐骑选择。玩家2工具栏的互动按钮使用圆形；队友菜单复用社交AI菜单的动作列表与好感解锁规则，邀请项替换为第二角色跟随/不跟随玩家1。两名玩家各自附近可见NPC气泡；同NPC归较近玩家（等距时玩家1），分别点击时打开对应左右窗口。表情/跳跃使用对应角色ID，NPC聊天、信息与学习奖励使用对应角色的独立会话。

### 2026-10-07：第二角色名称与坐骑隐藏修复

漫游中的第二角色名牌只显示角色姓名，不追加“玩家2”。第二角色绘制复用sceneMountSave，与主角一致应用自身mountHidden及组队/水上场景投影；不改实际装备及其战斗属性。

### 2026-10-10：跨地图与水陆连续跟随

显式跟随不再因距离超过180、切换世界或进入水域而自动解除，覆盖2026-10-07的距离取消规则。场景入口在首次绘制前同步第二角色的区域和位置；同地图传送也带走正在跟随的角色，清除旧寻路目标但保留跟随开关和AI跟随模式。两名玩家任意一方显式跟随，以及AI的“跟着我”模式，均通过adventure_local_follow_core复用队长实际轨迹；水上沿用紧密错位，回到陆地恢复步行间距。主动关闭跟随或手动接管仍沿用原操作。180单位仅继续作为近距离互动菜单的可见范围。

### 2026-10-07：有用的行动与自然交流

支持中英明确指令“跟着我 / follow me”“等我 / wait for me”“帮我采集 / go gather”“安静 / be quiet”，本地先执行，不等待模型或登录，不消耗对话额度。跟随模式不自行采集，等待模式原地停留但过远仍安全归队；继续/采集恢复自动模式。输入非空草稿、录音或等待玩家问题回复时暂停自主采集路径；空输入框仅获得焦点不会让伙伴一直停住。主动模型调用不阻断采集，也不能用goalId打断工作；玩家直接请求才可选择已校验的候选。

离线/未登录时，对简单指令、问候和当前活动给出本地中英回应；任意话题明确说明自由对话暂不可用。在线指引要求认真回应具体话题、承接明确兴趣和共同经历、解释选择、有自己的意见，避免把所有话题变成测验或重复鼓励。其他语言保留透明降级。对话质量与真实在线语音仍需实际账号体验确认。

### 2026-10-10：跟随镜头

玩家2跟随玩家1时（含显式跟随、AI跟随及追加组队），使用玩家1的单人镜头，不因玩家2的位置调整中心或缩放。停止跟随后恢复双人共享镜头；玩家1反向跟随玩家2仍使用原共享镜头。
