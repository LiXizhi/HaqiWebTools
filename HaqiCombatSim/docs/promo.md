# H5 宣传片放映室

入口：`HaqiPromo.html`。用 `npm run dev` 启动后打开 `/HaqiPromo.html`；普通 HTTP 静态服务器同样可用。构建包含放映室、独立舞台和剧本，不打包美术。默认图片仍使用既有 Keepwork CDN，源码 HTTP 服务下明确离线预览可用 `?assets=local`；不适用于未包含归档美术的 dist 目录。

## 使用

- 完整篇：17 个镜头，3 分 2 秒；精华篇：15 个镜头，85 秒。
- 点击播放，或选择章节、拖动时间条。暂停冻结时间轴；切到后台自动暂停。重新选镜头会从固定种子重建独立演示状态，再执行该位置之前的动作。
- 字幕支持中文、英文、关闭；可导出对应版本的 SRT。字幕语言同时控制放映控制台、章节标题和真实游戏界面；关闭字幕保留当前界面语言。中文默认母语中文、第二语言英文，英文版按原版选择器切换为母语英文、学习中文。语言切换保留播放时间并重建当前镜头。
- 录屏模式隐藏控制台，Esc 恢复；全屏只显示画面。画幅可选16:9横屏（默认）、4:3横屏、9:16手机竖屏。普通预览容器按所选比例紧贴画面，不再上下留黑；录屏与全屏模式仍按可用空间等比适配，不拉伸裁切；字幕直接叠在场景底部。横屏逻辑视口分别为1280×720、1120×840；竖屏按540×960的紧凑手机视口渲染，触发真实移动端布局。切换画幅保留当前播放进度。外部录屏可捕获完整画面。1×用于录制，2×/8×用于审片。本次交付 H5，无 MP4、配音或配乐。
- “运行整片检查”执行所有镜头和动作，抽查战斗起始/中间/结束帧；失败停下。“导出检查报告”输出 JSON，记录镜头、断言、战斗结果与排除范围。它是演示适配器的流程检查，不是对正式 `adventure_app.js` 全部按钮的端到端测试。

## 剧本编辑

唯一文案入口：`data/promo/film.json`。每个镜头包含稳定 `id`、`scene`、各语言 `title` / `subtitle`、长短版 `duration`（秒）和 `cues`。某版时长为 0 表示剪掉该镜头。动作 `at` 是镜头内 0–1 的位置，所以两个版本复用相同步骤。

例如把 `skills` 镜头的 `subtitle.zh-CN` 改成新文案，或调整 `duration.long`，不需要重新录制任何原始素材。新增语言时补齐每个镜头的对应语言键，并在放映室语言选项中登记；缺译回退中文。新增玩法需在舞台适配器中实现该 `scene` 或动作，再在剧本中引用，未知动作立即失败。

| 模块 | 职责 |
| --- | --- |
| `js/promo_timeline_core.js` | 纯时间轴、边界定位、字幕回退、SRT、动画帧时间计算 |
| `js/promo_app.js` | 播放、暂停、跳转、转场、字幕、检查报告、全屏 |
| `js/promo_stage.js` | 独立内存角色；调用正式视图、地图、副本和战斗规则 |
| `HaqiPromoStage.html` | 游戏样式隔离，避免控制台与游戏 CSS 相互污染 |

## 真实流程与演示边界

定位与文案依据当前 `HaqiOfficialWebsite.html`：宠物陪伴、冒险探索、营地中英交流，面向成年体验者的网页测试版。

地图使用现有六岛数据与渲染器，移动调用寻路与碰撞规则；卡包调用正式 `applyAction` 校验；副本实际加载并调用 `enterDungeon`；战斗由正式 PvE 引擎和 SimpleBot 运行，按事件快照播放。施法、伤害和治疗使用与游戏相同的时长，镜头余下时间停在结算画面，不编写伤害数字。检查同一检查点重演与原对局一致、无未支持卡型、可以结算。副本镜头只演示第一场遭遇，不声称完整副本通关。

每个镜头独立建立角色，部分镜头使用 15 级演示预置，不表示角色在片中自然升级。数据不写 localStorage、IndexedDB 或云端；不导入主应用，不调用账号、通信、支付、语音或 AI 客户端。剧本不演示云端旅途。好友镜头展示固定申请与列表，未向真人发送请求；语言镜头从实际课程读取示例问答，复用双语聊天组件，未运行真实语音或 AI 判断。画面不再叠加演示标识；演示范围保留在控制台说明与检查报告中。

检查通过只覆盖已列出的演示流程。发布前仍需独立完成正式应用交互回归、真实账号与云端读写、好友通信、语音、AI 服务及平台专项验证。

## 验证

`node --test tests/promo.test.mjs` 覆盖长短片时长、六岛、时间边界、非法剧本、语言回退、字幕时间码，以及异步加载后旧 RAF 时间戳不能导致进度倒退。`npm test` 保留全量游戏回归，`npm run build` 检查正式发布包。

漫游镜头会选择与居民、怪物保持距离的路线，出生位置也保留间距。开场、寒冰岛、营地与结尾通过 camera.zoomIn 配置缓慢推近；暂停和跳转按镜头时间重建缩放，减少动态效果偏好下关闭推近。

## 2026-09-30 界面与伙伴同步

创建角色直接复用原版左栏语言控件；选抱抱龙调用正式选择按钮，以同一 CSS 动画上前，动画按镜头时间采样，暂停和跳转保持位置。恢复正式 HUD 并移除覆盖 HUD 的影片品牌/章节叠层，章节仍可在控制台选择。地图增加四位内存 AI 伙伴，使用正式社交移动、人物渲染和头顶对白组件，演示中英文互学。对白固定剧本，不连接网络聊天或 AI 服务。

镜头准备会等待当前场景的NPC、怪物、主角和伙伴/随行宠图片加载后才解除遮罩并绘制首帧。图片使用正式缓存并限制预热并发；资源失败暂停并报错，避免暂停首帧留下占位人形。

## 卡牌策略镜头

卡包镜头使用20张容量的翡翠口袋和24张五系演示收藏，内存角色预置已学，配卡仍经正式规则校验。卡包完全沿用正式游戏的小图标布局，不使用放映专用卡面或布局；悬停使用原版inspect/完整卡面说明组件，时间轴依次展示术、陷阱、反射、减益和输出。完整版12秒、精华版10秒，字幕强调超强策略性；长短片总时长更新为182秒/85秒。

配卡动作通过正式卡库按钮点击执行，再点击正式保存按钮；数量由15/20依次增长为20/20，仅在Promo叠加72×96大鼠标和点击光圈；卡牌飞入与落点高亮复用正式卡包的同一动画，通过manual时钟采样，原界面与悬停尺寸均不改动；暂停和跳转按剧本时间重建。

## 发布前 QA 覆盖（2026-09-30）

放映室作为持续维护的核心 UI/逻辑辅助回归入口纳入 `haqi-release-qa`，见 [整体 QA](product-release-qa.md)。简单/核心/全部档分别分配约 30 秒/3 分钟/10 分钟，包含画幅与外层分辨率、播放控制、核心镜头、整片检查和导出。剧本驱动通过不替代正式游戏手动交互通过。
