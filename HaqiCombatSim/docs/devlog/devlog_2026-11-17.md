# 2026-11-17 · HaqiCombatSim 剩余代码逻辑模块化收尾与架构守护

## 交付

按架构模块化规划完成剩余控制器解耦、Presenter ViewModel 抽离、循环依赖与兼容 shim/barrel 清理、部分核心模块拆分及架构边界自动化测试，并更新 `docs/architecture.md` 架构图与 `.cursor/skills/locale-scan/scan-paths.json`。

## 关键改动

1. **消除模块循环依赖与历史兼容层（Phase 1）**
   - 新增 `js/adventure_city_dungeon_world_core.js`，配合 `js/adventure_world_core.js` 与 `js/adventure_city_dungeons_core.js`，打破 `adventure_coordinates_core -> adventure_world_core -> adventure_city_dungeons_core -> adventure_coordinates_core` 循环依赖。
   - 新增 `js/adventure_pet_rules_core.js`，配合 `js/adventure_pets_core.js` 与 `js/adventure_pet_interactions_core.js`，打破 `adventure_pets_core <-> adventure_pet_interactions_core` 循环依赖。
   - 迁移 `js/`、`tests/`、`tests/fixtures/` 及 `scripts/check_island_packs.mjs` 中全部调用方后，删除 5 个根目录兼容 shim（`view_adventure.js`、`view_adventure_controls.js`、`view_detail_dialog.js`、`adventure_renderer.js`、`view_home_art.js`）与 5 个未使用的 `index.js` barrel（`adventure/`、`home/`、`combat/`、`social/`、`ui/`）。

2. **冒险控制器与状态解耦（Phase 2）**
   - 新增 `js/adventure/app_bus.js` 与 `js/adventure/app_services.js`，将 `js/adventure/session_state.js` 内部重组为 `session`、`world`、`battle`、`ui` 四个状态切片并保留扁平 getter/setter 门面。
   - 从 `panel_controller.js`、`battle_controller.js` 拆出 `js/adventure/hud_controller.js`、`js/adventure/debug_edit_controller.js`、`js/adventure/battle_advisor_bridge.js`，统一通过 `{ services, bus }` 协作。
   - 修复 `battle_controller.js` 中对 `adventure_app.js` 所传 lazy getter（`wordLearning` / `hanziMemory` / `languageTasks`）未解引用直接访问属性的历史缺陷。

3. **Presenter ViewModel 与场景 Chrome 抽离（Phase 3）**
   - 新增 `js/adventure/presenters/hud_view_model.js` 与 `js/adventure/presenters/battle_view_model.js`，让 `js/views/adventure/view_hud.js` 与 `js/views/adventure/view_battle_layer.js` 消费 ViewModel；同步更新 `tests/teaching_mode.test.mjs` 的 VM 上下文。
   - 从 `js/home/view_home_scene.js` 抽离 `js/home/view_home_scene_chrome.js`（`view_home_scene.js` 缩减至 650 行）。

4. **核心大模块安全拆分（Phase 4，增量保留外部路径）**
   - 新增 `js/combat_card_targeting_core.js` 并由 `js/combat_cards_core.js` re-export。
   - 新增 `js/adventure_deck_core.js` 并由 `js/adventure_core.js` re-export（恢复 `adventure_core.js` 第 46 行 `clampDeck` 导入）。
   - 根目录剩余按域迁移的纯移动搬家项保留为可选后续整理，避免无收益打断现有脚本及源码切片测试路径。

5. **架构边界测试与配置同步（Phase 5）**
   - 新增 `tests/architecture_boundaries.test.mjs`（4 项断言：相对导入完整性、`*_core.js` 纯度与无浏览器全局依赖、JS 模块图零循环依赖、`views/` 与 `ui/` 不依赖控制器且旧 shim 已清除）。
   - 更新 `docs/architecture.md`（`## 架构图`）及 `.cursor/skills/locale-scan/scan-paths.json`（移除已删除的旧 shim 路径，加入 `js/adventure/presenters`）。
