# 家园：把故事角准备好，再一起找东西

2026-10-26 作者稿，已接入 english-home-practice.json；导出文本见 ../story-home-language.md。补 on、where、there、count、number；所有动作使用现有桌面槽位、真实找物和清点，不新增虚构库存。

## 书、杯子与盘子有自己的位置

伙伴想准备阅读或招待的角落，希望东西放在桌面上。开场解释 on 是“在上面”，孩子回答 `On the table.`，再实际把书、杯子或盘子拖到桌子上。结尾只在真实 parentId 桌面关联及保存成功后出现。地上物品与桌子图像重叠不算放上桌；满桌面不能生成无法完成的请求。

## 问清楚，再指出来

- where：孩子想找阅读用的书、游戏用的球或喝水用的杯子，先问 `Where is the book/ball/cup?`。伙伴邀它一起找，孩子实际点中物品后才出现 `There it is!`。
- there：伙伴询问物品在哪里，孩子回答 `There!`，再实际指给伙伴看。开场解释 there 指那件物品所在的地方，不要求虚构物品丢失、移动或已被拿走。

每词三种物品用途，分别有首次与复习变式。目标物品词须已认识，不额外计作本轮目标；独立发问与开放同义表达仍需后续扩展。

## 我会数数，也会报告结果

count 的场景先让孩子逐个点过一至三件真实书／球，再回应 `I can count.`，只计 count，不冒认已学数字。number 的场景要求本轮数字已认识；孩子清点后说 `The number is one/two/three.`，实际数量必须吻合，只计 number。每种数量有首次与复习稿，数量变化属于练习变式，不冒称不同剧情章节或额外核心词。

现阶段依然没有完整故事会／招待会后续、多步物品交付或语言毕业判定。物品实际布置、完成回执和规范词条记录仍是游戏负责，模型不代替判定。
