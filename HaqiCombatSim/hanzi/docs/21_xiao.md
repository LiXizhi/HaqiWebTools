# 21 · 小（`xiǎo`）—— 萤点微光聚溪畔（`hanzi_xiao.html`）

## 一、字源与教学边界

1. **读音与字义**：小，`xiǎo`。常用义是体积、面积、数量或年纪细微精巧，与「大」相对。《说文解字》：“小，物之微也。”甲骨文、金文的「小」用三粒细微的沙点或水滴表意；小篆将中间一点拉长为竖画，左右各留一小点，楷书定型为竖钩与左右两点。页面标注古字形为艺术示意。
2. **字形**：楷书三笔（Make Me a Hanzi 笔顺）：居中竖钩、左点（撇点）、右点。
3. **数据**：描红轮廓与中线直接嵌入 `data/adventure/dictionary/zh.json`（源自 `strokes.json`）的「小」（1024 字框，基线 900，y 轴向上），严格保持先中间后两边的三笔顺序与坐标。
4. **事实与想象**：夜溪浅滩上轻点草尖露珠、唤醒左右两只小萤火虫照亮折纸小船是字源岛溪边小村的原创故事。一缕垂露与左右萤点聚拢成「小」是服务笔顺记忆的视觉隐喻。

## 二、一句话

> 静谧的溪畔草叶垂下一缕细露，左右两粒小小的萤火轻轻依偎在旁，微光虽小，也能照亮一只远航的小船。

## 三、画面与声音

- **色彩**：夜溪靛青 `#18293a`、月影竹青 `#2c4c5e`、萤火暖金 `#f2d272`、朱砂印色 `#b94534`、宣纸米白 `#fbf5e8`。
- **层次**：弯弯浅溪与鹅卵细沙、垂向水面的纤细草叶、悬垂欲滴的晶莹露珠与左右飞舞的萤火微光、水面一叶折纸小船。
- **物件成字**：草尖拉长垂落的中线露珠对应第1笔居中竖钩；左侧亮起的小萤火对应第2笔左点；右侧亮起的小萤火对应第3笔右点，依次演示甲骨文三细点 → 小篆 → 楷书三笔。
- **声音**：用户手势启动音频；清脆水滴声、清亮铃鼓高音泛音与溪水轻吟。

## 四、七段分镜

| 进度 | 场景 | 字幕要点 | 互动 |
|---|---|---|---|
| 引子 | `sBrook` | 浅溪边的鹅卵石旁，停着一只掌心大的折纸小船。 | 观看 |
| 垂露 | `sDrop` | 草尖凝着一滴细细的露珠，轻轻一点让它垂成银丝。 | **点按草尖露珠**拉出居中银线（闲置自动推进） |
| 萤点 | `sFirefly` | 再唤醒左右两只小萤火虫，一左一右替小船掌灯。 | **点按溪畔两次**点亮左右萤火微光 |
| 成字 | `sGlyph` | 甲骨文用三粒细点表微物；楷书先写中间竖钩，再点左右两点。 | 观看甲骨文三点 → 小篆 → 楷书三笔拆解 |
| 写字 | `sWrite` | 三笔描红（竖钩、左点、右点） | 全部描完触发 `written`；支持「看示范」 |
| 词意 | `sWords` | 小船 / 小小 / 大小 | 词组依次点亮并与意境呼应 |
| 余韵 | `sFinale` | 每一粒细小的微光聚在一起，也能汇成温暖的星河。 | 点击溪面唤起细小涟漪与萤光；进入余韵触发 `completed` |

## 五、构图与适配

- 世界坐标宽 `1600`、高 `1000`：草尖垂露与左右萤火聚焦于 `(800, 520)`，纸船停泊于 `(800, 710)`。
- 桌面与 390px 竖屏均保证细微光点清晰可辨、触控热区宽裕；片头不发完成事件。
