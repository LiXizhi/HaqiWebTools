# 02 · 月（`yuè`）—— 夜海与湖湾的弯月（`hanzi_yue.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**：
   - **汉字**：月
   - **拼音**：`yuè`
   - **本义**：月亮、太阴（《说文解字》：“月，阙也。大阴之精。象形。”）。因为月亮有圆有缺（“阙”即缺），古人特意选取**弯弯的新月/弦月**形状来造字，从而与永远圆满的太阳（「日」）区分开。
   - **引申义**：月份（一月、十二个月）、岁月与时光。
2. **古文字演进（甲骨文 → 金文/小篆 → 隶书/楷书）**：
   - **甲骨文与金文**：画一弯竖立的月牙轮廓（外背圆凸、内弦弯曲），月牙中间有一短竖或一点，表示月中的微光（月魄）。
   - **小篆**：月牙上端渐趋平直，左右两侧向下舒展，内部稳定为两短横。
   - **隶变与楷书**：左弧化作长长的「竖撇（丿）」，右弧化作「横折钩（𠃌）」，中间包含两短横（「一」「一」），底部**不封口**，共四笔。
3. **事实与艺术边界声明**：
   - 动画中“体验月相圆缺变化后，定格于弯弯弦月并化作甲骨文「月」”严格贴合《说文解字》“月，阙也”的造字理据。
   - 教学拆解中明确指出「月」字左边是竖撇、底下不封口、里面有两短横，帮助儿童与四框封口、中间一横的「日」对比记忆。
   - 页面左下角保留说明：“古字形为依据通行字形的艺术示意”。

## 二、情感与动作主题（一句话）

> 静谧的江南芦苇湖湾，孩子拨开夜空云层、滑动月相看圆缺变化、用清冷银辉点亮桂花与流萤，看天边弯月化作甲骨文与楷书的「月」。

## 三、美术、色彩、构图与声音设计（对齐《光》《明》2D 标杆）

### 1. 色彩与光影递进
- **暮夜浓云（入夜/拨云）**：深邃夜蓝 `#060b1d`、墨青夜云 `#1e2b4a`、远山黛影 `#121c36`。
- **新月初现（盈亏变化）**：清冷月白 `#e6f0ff`、银蓝湖波 `#5c88c4`、暖金月晕 `#f3d285`。
- **清辉满湖（照亮风物/尾声）**：苍穹澄澈、银辉铺水，近岸竹亭、金桂花枝、芦苇流萤与湖心睡莲呈现柔和银白受光边与暖金点缀。

### 2. 桌面宽屏与手机竖屏自适应构图
- 统一世界坐标系与多机位摄影机 `VIEW`（`intro`、`lake`、`sky`、`phase`、`wide`、`reflect`、`glyph`、`finale`）。
- 竖屏（`portrait`）自动适配视场宽度 `pw` 与纵向中心 `pcy`，确保月亮、竹亭、轻舟、字形演进与四笔描红在 `390×844` 手机竖屏和 `1440×900` 桌面宽屏下均完整居中。

### 3. WebAudio 实时合成音景（零外部音频依赖）
- **夜湖轻波与晚风**：低通滤波噪声模拟湖水轻拍岸边与竹叶微风。
- **五声清越泛音与洞箫柔垫**：采用 F 大调五声音阶（`F4, G4, A4, C5, D5, F5, G5, A5, C6`），音色如古筝泛音与玉磬共鸣。
- **交互音效**：拨云柔风声、月相流转泛音、桂花风铃声、流萤轻吟声、描红逐笔琴音。

## 五、笔顺与字形数据（与字典 `zh.json` 严格对齐）

- 笔画数：**4 笔**（Arphic Public License / Make Me a Hanzi `月` 字骨架对齐）
  1. **第 1 笔 · 竖撇**：自左上起笔先竖直下行，至中下部自然向左下撇出。
  2. **第 2 笔 · 横折钩**：自左上横行至右上折向下直行，底端向左上方轻钩。
  3. **第 3 笔 · 横**：框内偏上第一短横，自左向右。
  4. **第 4 笔 · 横**：框内偏下第二短横，自左向右，底部不封口。
