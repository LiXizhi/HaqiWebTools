## 游玩

新建家园后，从目录选择物品看三组表达，或直接输入/按住说话：`I want a chair.`、`Create a table.`、`I want a red flower.`。目标语言取角色设置，首版支持英语和中文。每次有效表达得到一件物品，可反复练习；相同请求的重复回调不重复发奖。打字与语音同样能召唤，回执分别记录，不发冒险货币或战斗加成，不保存录音。

目录点击后展示召唤咒语，拖出只预选精确落点；正确朗读或输入任意一句后才生成到场景，未拖放时在角色附近寻找空位。仓库已有物品仍可拖放。桌面物品需要桌、柜或书架槽位。家具支持旋转、收回和再次摆放，桌子移动/收回时附属物品一起处理。旧铺路物品每件为一个3×3模块；连接式建筑构件见下文，无资源采集和高度堆叠。

当前角色全部已拥有宠物进入名册，包括按需宠物文件的摘要。宠物可查找、召到身边、拖动，拖到设施上会触发生活动作；默认停留在玩家摆放的位置，不再随机散步。每20秒只让一只处于实际视口内的空闲宠物尝试当前脚下设施或表达愿望；页面隐藏时不执行。漫游模式即可拖动宠物，保持抓取偏移，松开后保存精确位置。12类活动为睡觉、坐下、吃饭、喝水、洗澡、荡秋千、滑梯、玩球、读书、浇花、跳舞、野餐。活动为家园表演，不改冒险属性。宠物位置独立存于每个家园，休息、短期活动与愿望只在内存。

愿望气泡可点翻译，工具栏有“听宠物愿望”“帮它实现”和安静模式。帮它实现提供句子，不自动发奖。实际召唤、摆放、使用才触发对应感谢。没有麦克风或语音服务失败仍可打字和装修；真实识别及音质以账号和设备实测为准。

## 内容作者源与美术

唯一物品作者源为 `data/adventure/home/catalog.json`：8类各20种，共160个稳定物品ID，颜色不计入数量。每件记录中英文名、三组表达、别名、占地、层次、桌面槽位、互动、朝向、可选颜色和美术来源。修改现有ID会影响库存，不应按显示顺序重编号。

160种物品全部使用10张 `768×768`（4×4格，每格 `192×192`）透明背景 WebP 图集（`assets/adventure/home/home-atlas-01..10-*.webp`，单张体积 140KB–195KB，均 ≤200,000 字节），清单记录于 `data/adventure/home/home-art.json` 并已上传至永久 Keepwork CDN（`https://cdn.keepwork.com/keepwork/cdn/haqi/home/`），不再使用原生矢量占位。物品随占地方向与可选颜色（原图透明蒙版染色）绘制，并支持灯光、音符、水花、蒸汽、屏幕微光等场景互动特效，支持显式本地资源模式。

宠物简明双语反馈由目录内 `dialogue.HOME-PLACE / HOME-READY / HOME-USE` 和 `activityWords` 维护，分别只在实际召唤、附近摆放、设施使用后触发。它们是独立家园模板，不占用主线S/L场景编号，不修改既有故事登记表。请求句由已选物品词条生成，英语使用正确的a/an。

## 模块与接口

- `home_core`：坐标分块、确定性六大群落（翡翠草甸、樱花花谷、金秋枫林、阳光沙洲、晶莹雪原、星光秘境）、蜿蜒河流与自然木桥、广场石板路、句式匹配、占地及导入校验；`home_actions_core`：召唤、摆放、移动、收回的纯规则。
- `home_app`：当前账号/角色/家园会话、请求失效、宠物行为与事务；视图仅处理呈现和输入回调。按需加载，不参与冒险启动资源包。
- `home_store`：`list/get/read/create/mutate/snapshot/install/acknowledge`，所有物品变化在IndexedDB事务提交。
- `home_cloud`：`list/download/sync/remove`；复用冒险云客户端的 `homeRead/homeWrite`，路径只允许当前家园目录结构，认证检查和串行写入沿用现有适配器。

## 本机与云端

独立库 `haqi-homes-v1`，`homes` 键为 `[scope,homeId]`，`parts` 键为 `[scope,homeId,part]`。scope显式区分访客/账号和角色。part包括 `inventory`、`residents`、`chunk:x,y` 和 `receipt:attemptId`。发物品、扣库存、分块更新与回执在同一事务，失败回滚并提供重试。删除先标记本机家园移除，不误删别的角色。

地表按seed生成32×32分块，只保存人工修改。活动视口之外的分块缓存丢弃；渲染地表缓存与视口一致，宠物AI每20秒最多处理一只可见居民，图片缓存96项，染色缓存24张、最长边384。世界没有玩法边界，但受JS坐标安全校验（±10亿格）与浏览器存储容量限制，不能解释为无限磁盘。

云端位于 `HaqiAdventure/homes/<roleId>/`。目录 `index.json` 包含家园摘要与分文件引用；变化分文件使用不可变版本路径，最后发布目录。未变化分块复用引用，存档不混入冒险角色同步。仅目录在登录/角色激活时预读；库存与居民进入时下载，土地按视口分块下载并缓存，主动刷新重新读目录。读取直达服务器Cache，只有明确404认为不存在，其他错误不当作空目录。

手动同步捕获当前版本；收到成功应答后才确认该版本。上传期间的新修改继续保持dirty。远端版本与本地基线不同则先下载为新家园副本，再允许下一次同步上传本地版本，库存不合并。沿用项目单客户端写入假设，不提供服务端并发编辑锁。同步时暂时读取完整的已修改分文件快照，日常游玩只保留视口分块。云端来源引用单独保留，未访问的土地不需要预先下载；冲突副本完整下载后才确认，下载失败不覆盖本地。

召唤回执仅用于本机操作去重，不包含录音或识别文本，不随云文件反复积累。登录后可以从所有本机访客角色的家园中选择复制；访客原件不删除，也不自动转移。云端删除移除目录引用，未主动清理已无引用的版本文件。

### 家具图标操作栏与尺寸（2026-10-19）

保存标签时捕获当前练习回执，地块事务成功且确有非空文字变化后，发 label 事件（物品 ID、保存文本、回执）。控制器核对任务／角色／目标语言仍有效、正确物品和作者表达，再写 WordTree text 回执；旧任务结果、取消、原样保存、删除、其他物品和重复回调不计。学习记录保存失败可用同一回执重试，不要求重写已保存作品；切换游戏也会取消过期学习写入。原自由写标签路径没有活动任务回执时仍不计词语练习。


## 2026-10-26：家园页面标签完整链路验收

新增 home-learning-world 隔离场景，使用真实 openHomeSystem、物品编辑器、地块 IndexedDB 和 WordTree，不注入练习完成事件。桌面及手机已验证伙伴开场、直接编辑目标书本、错误文本保存而不计次、作者许可标签完成一次、原样保存不计次及刷新恢复。测试揭示并修复家园画布覆盖普通伙伴开场的问题：家园专属开场层级高于画布。另修复嵌套标签编辑器 Escape 被练习窗抢走；取消标签编辑后仍可继续原任务。

伙伴开场地点现在显示实际家园名称；不再沿用冒险角色最后所在岛屿。物品标签移到物品下方，避开编辑操作栏；移动端操作栏尺寸及视口边界已检查。场景验收为本地固定布局、隔离角色、显式本地资源模式，不等同正式 Haqi 入口、云端同步、真实语音或儿童教学效果验收。


## 2026-10-26：颜色情境与清楚的色标

家园颜色配置统一为 COLORS／HOME_COLOR_HEX，新增黑色与灰色；召唤句、目录色块、物品染色均支持。带颜色的物品下方显示该颜色的实心小圆点，标签在圆点下方，帮助初学者识别配置颜色，不依赖淡染后的原图色调。未带颜色的旧物品不冒认任何颜色。

作者任务可用 action.colors 指定一个或多个允许颜色，选择器必须匹配实际物品。单个颜色目标的 AI 情境也必须匹配，不能将蓝色对象作为 red 的完成动作。回执保存前和有效性回调复核当前对象；删除／颜色改变使该任务失效。十个颜色词各有初识找物、真实移动和写标签三段；colour 可作为颜色角的作品标题。橙色仍能用于家园布置，但当前核心 orange 教学目标是水果，因此不通过颜色练习计为水果教学覆盖。
