# 2026-11-06 · 新手入口与家园第一步

## Edge 试玩

- 用新角色从序章进入魔法营地，再按语言任务去字源岛。进入世界之前要经历序章、建角色、选抱抱龙和选系别。到营地后同时出现普通主线和语言任务。跟踪语言任务会跨地图，和阿初过三屏对白后才进入第一句英语练习。此次到达问候界面后转去家园。
- 从游戏菜单新建家园，默认地块显示容量 0 / 20,000。在线上版本打开「建造 → 卧室 → 毯子」，输入 `Can I have a blanket?` 后，容量变为 1 / 20,000。现有英语召唤可以产出真实物品，首次摆放需要先经过目录和练习。
- 阿初对白在自动化快照中有两份文本。额外节点是宽度 1px 的屏幕阅读器文本，保留原实现。

## 本地调整

- 创建角色时直接进入原向导，起名页提供「播放开场动画」。退出后返回起名页，并保留已填内容。序章直达 URL 继续可用。
- 空家园有驻场宠物时提供「给抱抱龙铺毯子」。在抱抱龙附近选一块空地，直接放置目录中已有的毯子。放置仍通过原家园校验、事务和撤销记录，不产生语言练习记录。
- 使用现有寻路让附近的抱抱龙走到毯子上休息。毯子被移走或收回时，取消依赖它的行动。

## 验证

- 角色创建、序章播放、家园编辑、寻路、宠物、房间、容量与建造策略的定向 Node 回归 38 项通过。新增用例覆盖放置范围、已有家具时拒绝再次使用入口、抱抱龙走过去及收回毯子后的状态。
- 本地精简工作副本缺少序章 WebP，完整资源副本中 12 张图片的文件大小和 SHA-256 均符合当前清单。
- Edge 本轮走的是线上旧版。新入口和毯子反应尚未在浏览器里端到端复测。本轮没有接入店员卖灯。

## 新手小屋样板

- 新建以英语为目标语言的角色时，在进入世界后打开抱抱龙的小屋。用现有木屋模板、家园家具和角色选择的抱抱龙。小屋按角色保存，已经编辑过的布局不会被初始布局覆盖。
- 起始位置能看到窗、椅子、毯子和抱抱龙。拖动初始家具不需要打开建造菜单。毯子移到窗边后，抱抱龙会走过去晒太阳，头上显示太阳。移到角落时会去睡觉。
- 移动毯子后可选「添一盏灯」，用原有朗读或打字召唤 `Can I have a bedside lamp?`。灯放到屋内的空位即亮，可继续拖动。成功练习沿用家园的词树记录。这个入口使用家园召唤，店员对话尚未接入。
- 用当前代码和原始家园素材复跑全部家园 Node 回归，以及相关建角与序章播放测试，261 项通过。覆盖布局校验、两处落点的实际寻路、召唤回执去重、重进保留已有家园和删除状态。新版还未发布或在 Edge 里完成端到端试玩。

## 复测后的调整

- 新手小屋里，抱抱龙去毯子时遇到挡路的家具会停下来，头顶显示问号并提示玩家挪开家具。编辑后重新寻路，毯子还在原位且路径恢复时自动继续。
- 小屋添灯优先示范 `Can I have a lamp?`，也接受 `Can I have a bedside lamp?`。两句成功时都走同一套练习回执，只记录 `lamp`。即使连续录音，漏掉或换掉目标词也不能从小屋入口拿灯。
- 用实际家园控制器连续模拟挡路、移开椅子、两种落点、输错词、说对短句、亮灯与重新进屋。本地流程通过，仍待新版浏览器试玩。
