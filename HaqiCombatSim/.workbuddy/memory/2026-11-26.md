## 汉字「游」3D 江上行剧场（hanzi/hanzi_you.html，新建）
- 结构同 chuan：动态 import Keepwork CDN 的 three r164，协议脚本/CSS 与 chuan 同源；六幕 江水→轻舟→孩子→成字→写字→遨游，三次互动 + 十二笔描红。
- 字形是**真 3D**：Make Me a Hanzi 轮廓 → ShapePath → ExtrudeGeometry（倒角），每顶点带 `aT`（到中线起点的弧长），onBeforeCompile 注入 `if (vT > uProg) discard` 实现按笔顺书写。
- 源码分片在 `tmp/youqa/`（p1.html + p2..p8.js + d.js），`node tmp/youqa/build.mjs` 组装；直接改 hanzi_you.html 会让分片过期。
- 无头验收可行：Playwright(keepwork-crm 的 node_modules) + 系统 Edge + `--use-angle=swiftshader`，进程内 http server；`node tmp/youqa/qa.mjs|qa2.mjs|qa3.mjs`（自动 / 真实指针交互 / 意境·竖屏·2D 保底）。软件渲染帧率低，虚拟时钟相关动画会被拉长，属验收环境现象。
- GLSL 里 `#include <fog_vertex>` 后必须换行再写 `}`，否则 `}` 被 `#endif` 吞掉。
- 已登记：hanzi_index.html、hanzi_story_animations.js URL 表、HANZI_STELE_SCROLLS（id you）、hanzi/docs/00_overview.md 第 31 行。未做：单独 docs 页、scripts/check_hanzi_you.mjs、locale 补录、devlog。
