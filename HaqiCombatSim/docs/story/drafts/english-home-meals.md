# 家园小饭馆：给这一餐起个名字

2026-10-26 作者稿。使用现有进餐设施和保存标签能力，不生成食物库存、不宣称真实钟点或营养状态。已接入 english-home-practice.json，由伙伴普通对话开场。

孩子和伙伴轮流扮演小饭馆的主人与客人。先从早餐、午餐、晚餐中认识一种，商量一餐，再实际带伙伴去进餐设施。复习时伙伴提出新的想象情境，例如准备一次从早晨开始的冒险、给玩耍安排休息，或为睡前故事准备晚餐。孩子也能把餐桌布置成自己的作品，保存英文标签。

## 教学顺序与能力边界

- breakfast（早餐）、lunch（午餐）、dinner（晚餐）各有一个明确介绍和一个复习邀请；前置为 eat，先认识进餐动作。
- 新词只计明确回应且真实 pet-use/eat 成功后的一次练习。当前不判断食物、时间或人体饥饿。
- 每个词另有餐桌标签任务，仅在词已经练习后出现；必须实际编辑并保存。邀请允许加 please 或 Let us eat ...；标签允许词本身及 My ... table.、Our ... table.。展示范例与自主写作证据分开，不能把抄写称为独立创作。
- 三个词目前各三个情境，仍缺跨会话完整十二次编排、独立听读和孩子主动设计多餐菜单。不能以这个小饭馆框架宣称菜单服务或来客系统已实现。
