# 连续家园故事：再玩一次，然后休息

2026-10-26 作者稿，已接入 english-home-practice.json 的 en-l1-play-again 四步及 en-l1-go-* 普通情境。伙伴想玩球；孩子先选球，再邀请伙伴去玩。伙伴玩过一次后，孩子学习 again（再来一次），实际再次带同一伙伴到同一只球；最后伙伴说想休息，孩子询问是否 tired 并带同一伙伴到休息设施。每次实际安置和活动启动保存后才算一轮，不把等待动画结束或播放示范算作新练习。

go 首次解释为“去”，用 Go to the ball. 或 Go to bed.；again 仅在连续故事中第一次玩球完成后引入，不凭一个已学词假装刚玩过。先前的球和伙伴身份都要保留；伙伴不在家时提示安置回来，不换一只假装同一角色。尚未到休息步骤前不能宣称已经休息。

新词预算仍为每次三个；如果球也是新词，第四步可以留到下次继续。已有球词基础的孩子可在同次学习 go、again、tired。点击与显示不计数，重复回执不推进，角色／语言切换取消旧结果。口语可改打字，但不把打字记为口语。
