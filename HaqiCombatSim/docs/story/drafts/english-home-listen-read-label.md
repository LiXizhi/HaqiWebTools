# 听请求、读线索、留下标签

英语 L1 已学词的三段连续复习故事，作者源 english-home-practice.json。三篇为《阅读角的书本标签》《认得自己的杯子》《留给下一场游戏的球》。分别复习 book、cup、ball，不增加唯一词覆盖。

伙伴有一个生活中的小愿望：为阅读角选书、选下次想用的杯子、为下一场游戏留球。孩子先听请求并点选真实物品；再读文字线索找到刚才实际选择的那件；最后给同一件物品写标签。既有家园显示和保存标签，不虚构独立书签、装水、宠物找物、来客读消息或奖励。

- D-home-modal-01：伙伴解释愿望，玩家听 Find the book/cup/ball.，然后在不同类实物之间辨认。多件同类都可选，保存孩子实际选中的身份。
- D-home-modal-02：文字请求再次使用已学词。必须点选第一步选好的物品；存在另一种可点选物品才能开始。不能用单选必对伪造理解证据。
- D-home-modal-03：给原物品写 My book/cup/ball.，也接受 A ... / The ...。开场解释 My 的句义，提供可选例子；保存后标签留在场景，不凭观看或原样保存计数。

语音播放失败可以重试，也可选择“改为读线索”。后者按有支持的阅读证据完成本故事步骤，绝不写听力成功。故事完成与听力能力是两回事。听读不会增加朗读／输入的 practiceCount、basic、最近战斗词资格或表达复习间隔；它们单独保留理解证据，并在同一去重事务推进故事。

这批提供一次连续的多方式复现，并不等同跨四次会话、三种生活情境或逐词十二次机会。三种物品选择均须已有教学记录。需要继续扩充其他词、延迟复习、独立表达、开放写作和儿童试玩。
