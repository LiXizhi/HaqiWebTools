# 英语：L0—L3 日常交流教学大纲

更新：2026-10-26。教学结构与故事群已设计；除明确列出的现有样例外，以下故事为待创作／接入的课程概要，不是已上线任务。返回[总纲](README.md)。

## 教材范围与语言专属路径

以 Cambridge YLE 的 Pre A1／A1 为主体，L3 选取 A2 Flyers 的日常目标；Kid’s Box New Generation 是教师备课参考。词表年份固定到已登记入口，L1 核心词已登记来源级别；L2／L3 逐词级别仍待核，不把自编故事当教材课文。

L0：名字中的字母、字母名称与常见发音分开认识；用眼前物品建立声音—意义联系。L1：在已理解的词中练字母音、简单拼读和常见高频不规则词，开始大小写、空格和句号。L2：读短句的意群，辨问句与陈述；听后拼写熟悉词，写简单留言。L3：读邀请、路线和事件顺序，自己写数句信息；不要求先记完音标表，也不把口音不同当作意思错误。

来源核验边界见[教材台账](sources-and-vocabulary.md)。本页例句是作者拟定的课堂表达，候选词不是完整官方分级词表，L1 的 180 词来源页码与 WordTree 映射见[核心词账本](en-l1-vocabulary.md)；具体故事语义、Can-do、语言复审与完整覆盖仍待 CUR-02、CUR-04 完成。

## Level 能力进阶

| 项目 Level | 听说目标 | 读写目标 |
| --- | --- | --- |
| L0 | 招呼、说姓名、听懂熟悉动作 | 认姓名字母和物品词，输入自己的名字 |
| L1 | 问人、位置、喜欢与需要；能请求重复 | 读图文标签与短请求；独立写一个有效短句 |
| L2 | 问时间、数量、说明感受与简单过去 | 读短消息／清单；写两三句需要、安排或道歉 |
| L3 | 确认约定、转告变更、分工和简单叙述 | 读数条相关消息；写三到五句邀请、路线或回顾 |

L0 小故事：认识自己的名字 → 听指令帮宠物做一个动作 → 给熟悉物品贴标签。三项均为新增教学设计，需各语声音／文字资源和实际动作接入，不用纯选择题冒充已经会听说读写。

## 九岛单元与故事群

各单元的 A／B／C 为三个主故事位，T1／T2／T3 为三个迁移故事位；每个故事都要另写完整分镜与真实动作。下列词以基本形式或固定语块列出，台词必须使用自然形式。每篇仅选其中少量首次教，其余分散到后续故事。

### EN-U01 · L1 · 字源岛：认识朋友，说明位置

**能做什么：** 问候、名字、关系、位置、请等待或重说。

**种子词／语块：** hello、name、friend、water、home、wait、here、there、where、come、go、help。

**关键表达：** Hello, Achu! / Where is my friend? / Please wait here.

**语言结构：** be、my/your、简单问句、位置语块；He is waiting 先整句使用。

**A → B → C 故事链：** 《让朋友找到你》：阿初与小灯约错水边，沿溪问人、战后请阿初原地等待，再找到小灯传话（已有六幕样例）。→《两张相似的名牌》：问名字找到正确伙伴。→《我没有听清》：更换等待地点，主动请求重复后再出发。

**T1／T2／T3 迁移变化：** 换一个等待者；换水边地标；家园找走错角落的宠物。换情境时不能给完整答案让孩子抄过关。

**读写落点：** 读姓名与 Here/Stop 等标记；独立写 I am here. 或一条等待消息。听力必须至少有一次隐藏原文后做动作；口语至少有一次只给意图、不给整句答案的回应。

**家园与战斗复现：** 家园从本单元已学目标中选 1—3 个，围绕照顾、找物、布置或轮流游戏使用；后续单元至少再次使用其中一个表达。文字卡只复现当前目标语言实际练习过的词。

## 单元之间怎样复现

U01 的招呼、问位置、请求重说贯穿九岛；U02 的喜欢和需要用于 U04 照顾；U03 的停止与求助用于 U05 旅行；U04 的时间用于 U07 约见；U05 的数量用于 U09 分工；U06 的解释与道歉用于 U08 澄清；U07／U08 的消息与位置最终在 U09 综合使用。每条目标的具体故事位置仍需在词条账本登记，不能只靠这段说明宣称已覆盖。

## 毕业任务与范围终点

用目标语言筹备一次小型聚会：听两位伙伴的需要，读一份物品清单，问清一处时间或地点，按真实场景完成一项行动，自己写一条有效邀请；随后对一个变化重新安排。允许查一个生词或请求重复，不能显示整句答案。再换 NPC／物品和另一次会话复测。听、说、读、写分别评价，任何一项缺证据都不标完成。详见[验收规则](assessment.md)。

L3 之后继续在基础结构内增加新情境、新词和新人物，不追加高级 Level。教材词汇预算及系统缺口见[词汇台账](sources-and-vocabulary.md)与[RSI 队列](backlog.md)。
