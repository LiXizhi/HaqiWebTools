# 开发日志 · 2026-10-13


## 汉字「国」互动动画（独立 H5）

- 需求：制作 30–60 秒的「国」字互动动画，体现象形之美和字形演变，含 1–2 次小交互，SVG 或 Three.js 均可，生成独立 H5。用户选定位置 `hanzi/hanzi_guo.html`，要求极具艺术感。
- 实现：单文件 `hanzi/hanzi_guo.html`，CSS、SVG、JS 全部内联，纯 SVG + 原生 JS，不加载任何外部库、字体、图片或音频，可直接双击或用 HTTP 静态服务打开。
- 流程：象形城邑 → 交互一（拖动青铜戈立到城邑旁）→ 甲骨文「或」（龟甲纹理、钻凿与卜兆裂纹）→ 金文「或」（青铜铜锈圆盘、雷纹、鎏金浮雕笔画，旁注何尊「宅兹中或」）→ 交互二（沿虚线描画城墙，按四边 48 段覆盖率判定）→ 小篆「國」与朱砂白文印 → 隶书 → 楷书 → 简体「国」（或化墨粒散去，玉以玉色辉光按笔顺写入并标笔顺号）→ 六体长卷，可点击任一字放大重播笔画。
- 笔画引擎：每笔为手绘中线路径，按弧长采样后逐段绘制，宽度由书体轮廓函数决定（甲骨刻划尖细、金文肥笔、小篆匀称、隶书蚕头燕尾、楷书提按与钩）；墨迹毛边、飞白、刻痕高光、铸造浮雕均为 SVG 滤镜。字形为依据通行字形的艺术示意，页面已注明。
- 其他：两次交互均有超时自动完成，拖动或描画中会延长等待；WebAudio 合成五声音阶拨弦、鼓点、笔刷声和低音铺底，可静音；`prefers-reduced-motion` 缩短过渡并停用远山漂移；横屏与竖屏（390px）分别使用不同 viewBox 与长卷布局；随机数使用固定种子的 mulberry32。
- 发布范围：`vite.config.mjs` 只构建显式列出的入口，`uploadRelease.mjs` 只上传这些页面，`hanzi/` 不会进入 `dist/` 或发布包，未改构建配置。
- 验证：本机无头 Chrome 155 通过 CDP 驱动（脚本在 git 忽略的 `.asset-cache/guo/`）。1280×800 不操作全程 52.6 秒，两次交互均超时自动完成；390×844（DPR2、移动模式）模拟拖动与描画，两次均判定为用户完成，全程 42.9 秒；减少动态效果模式 47.8 秒。三次均无控制台错误或异常，帧率采样约 60 FPS（无头环境，非实体手机）。逐场景截图已人工检查，修正了宣纸纹理平铺接缝、铜锈过重、笔顺号重叠、竖排年代数字方向和放大页标题被提示遮挡。
- 未做：未在实体手机、Safari 或 Firefox 上验证；声音只确认了代码路径，无头环境未实际听感检查。未改战斗引擎与共享 UI，未运行 `npm run test:battle`。未提交/推送。

### 第二轮：中英双语字幕与动态首页

- 用户要求：字幕中英双语、有动画、更大；整页适配手机与 PC；首页要有动画并明确告诉是哪个字，不显示「一字千年」。
- 字幕：标题为中文加英文小型大写，正文中文逐字「墨晕」显现（透明加模糊阴影收拢为实字），英文斜体随后上浮淡入；正文字号放大到桌面约 22–26px、手机约 17–21px。交互提示、竖排书体名、长卷标签、放大页标题与返回提示、重播与声音按钮均为中英双语。
- 首页：去掉「一字千年」，改为「今天认识一个汉字 / Today's Chinese Character」，大字「国」按笔顺写出，身后循环淡入甲骨、金文、小篆、隶书、楷书的虚影，写完盖朱印，玉部呼吸发光；随后依次浮现拼音 guó、「国 · 国家 country, nation」、简介和「开始 Start」。文字块按大字实际位置上下排布，横竖屏和矮屏均不遮挡。
- 手机：交互提示移到顶部（避开戈和城墙），长卷整体上移避开字幕。
- 验证：1280×800 不操作 52.6 秒；390×844 模拟两次交互均判定用户完成，43.1 秒；均无控制台错误，帧率采样约 60 FPS。已检查首页、各场景字幕和长卷截图。英文译文为本次撰写，未经母语审校。

## 汉字「国」动画：第三轮（仅中文、字幕放慢）

- 按用户要求去掉全部英文（字幕、竖排标题、首页、长卷、放大视图、按钮与提示），只保留中文。
- 字幕放慢：逐字显现改为每字 70ms、单字晕染 1.1s；`caption()` 改为异步，每条字幕至少停留 `350 + max(逐字显现完成, 字数×140ms) + 600ms` 后才被下一条替换，场景会等待字幕读完。
- 为控制总时长：金文、借字、简体三条字幕精简；两次互动的自动完成时限由 6s/6.5s 改为 5s/5.5s；甲骨文、金文、小篆场景内固定停顿各缩短约 0.5–0.7s。
- 验证（headless Chrome + CDP）：桌面 1280×800 两次互动均超时自动完成 57.3s，手机 390×844 模拟互动 52.5s；约 60 FPS，无控制台错误；截图确认仅中文。
