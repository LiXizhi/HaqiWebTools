# 本机学习周报、月报

2026-10-18 源码接入，未发布。本机统计累计学会的英文单词数、有效开口次数、本周和本月的新增词汇／开口次数，并向家庭平板发送成就摘要。字典首页不再展示这些统计，以及今日加成和阶段奖励摘要；保留今日进度、开始学习按钮与学习奖励入口。

## 计数

- 单词：现有英文字典 `languages.en.entries` 中 `learned=true` 的不同 ID。首次从已有字典读取只显示累计数量，不把旧数据记为本周／月新学。复习同一单词不重复增加新学数；汉字与旧导入记录不混入新学英文单词。
- 开口：`createLearningVoice.finish` 取得一次非空最终识别结果，记一次练习。不是识别字数，不要求答案正确，也不等同于奖励或每日加成次数。取消、失败、没有识别到内容、朗读播放、键盘输入都不计；同一录音的重复结束回调最多记一次。不保存录音或识别文本到统计记录。
- 周从本机周一开始，月从本机每月 1 日开始。开口次数从启用此统计后累计，不能还原旧版没有保存的历史。日汇总保留最近 400 天，累计开口总数另存。

## 本地存储和上报

复用 IndexedDB `haqi-dictionary-v1/learners` 的账号／角色键。`dictionary_store.update` 在同一个读写事务中记录原有学习数据与 `learningReport` 的每日增量；多个标签页由 IndexedDB 排序，不新增 localStorage 或 workspace 调用。持久化成功后发本页 `haqi:learning-progress` 通知。读取已保存字典也通知，使回到游戏时重算当前周／月展示。

`learning_report.js` 只接收当前账号、角色的状态。在家庭平板 iframe 中，按启动参数 `parentOrigin` 向直接父窗口发送 `{type:'updateDesktopUI',content}`。最多 200 个 Unicode 码点，包含简单 Markdown；统计不影响游戏奖励或存档的云端同步逻辑。普通独立打开同样保存本地统计，但不发送给无关页面。存储失败不向桌面上报未保存成绩。

语音开始时捕获账号／角色键，结束时再次核对，切换后不误算到新角色。家庭平板还会独立核验 iframe 来源、账号和应用身份。
