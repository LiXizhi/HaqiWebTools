# 到故事角站好

英语 L1 新动作 stand，含义“站立、站好”。伙伴想和孩子排一个故事开场：先找到椅子作为集合点，再让孩子的主角走到椅子附近站好，最后伙伴坐下听开场。主角不会因为孩子念了 stand 就自动瞬移；需要实际走一段路并停下。

复用家园主角真实逐帧移动和已有家具标记。开始站位后先走至少与原walk相同的一小段距离，再在原家具外侧附近停止移动。只路过、开场已经站在附近、远处停留、点击家具、跳变位置都不能完成。无需摄像头，不检测孩子身体姿势；只检验游戏角色站位。停留不做长时间倒计时或额外等待任务。

课程保留语音或打字回应，随后验证实际动作。目的地物品移动、替换、缩放或被移除，旧站位任务失效；进入布置模式或角色/语言切换也不能沿用旧结果。异步保存再次核对主角已经站定且仍在原位置附近。新能力写入共享WordTree，重复回执不计，不独立建掌握表。

连续故事计划ID `en-l1-ready-for-the-story`：chair 找椅子 → stand 主角站好 → sit 伙伴实际坐下。最多三个新词，有示范且每步目标明确。普通复习在椅子、桌子附近分别提供介绍与回访。后续仍需更多跨场景用途、独立听读动作指令、真实语音及儿童试玩；此功能不覆盖run、jump或真人动作识别。
