# HaqiCombatSim — 产品设计

## 用户与场景

- **数值策划**：想知道当前 kids / teen 配置下五系在 1v1~4v4 的胜率是否均衡，改一个系数后多久能看到结果，以及"应该往哪个方向调"。
- **开发者**：想在不启动 GameServer 的前提下验证某张卡、某条公式的实际效果，并把结论对照回 Lua。
- **测试**：想手动打几局，感受节奏（回合数、pips 积累、blade + 大招的爆发）。

## 页面

### 顶栏
- 版本切换：kids / teen（影响公式分支、上限常量、数据集）。
- 数据集状态：卡数、未支持 type 占比；若回退 sample 则醒目提示。
- 当前 BalanceParams 是否有未保存改动（相对基线的 diff 数）。

### 1. 对战页（battle）
- 阵容配置：模式（1v1 / 2v2 / 3v3 / 4v4）、等级、我方操控位（或全托管）、Bot 策略、动画速度、种子；每个槽位：系 + **配卡** 按钮（显示 `已配/容量`，自定义过的槽位高亮）。
- **卡包与配卡**（对应 Lua 卡包道具 `stats[167]` 总容量 / `stats[170]` 单卡上限）：
  - 容量与单卡上限来自数值面板 `deckCapacity` / `deckEachCapacity`（默认 40 / 6，接近正常玩家卡包；初始卡包为 kids 14/3、teen 18/5；0 = 不限）。
  - 配卡面板：该系 + 平衡系中引擎支持且等级达标的卡表（搜索、`-`/`+` 份数、teen 同名技能共享上限），当前卡组以芯片显示（点击 -1），一键「官方预设 / 清空 / 恢复预设 / 保存」；保存到 `settings.battle.decks[version][school]`，批量页勾选「用对战页配卡」即可复用。
  - 未自定义时从官方 Aggressive CSV 派生「玩家会带的」卡组：去掉 _Green/_Blue/_Purple 染色副本，攻击 / 治疗牌每种 `deckPresetCopies` 份（默认 3，高等级攻击优先），护盾 / 符咒 / 光环每种 ⌈copies/2⌉ 份，轮询展开后按容量裁剪——**带满不一定最好**，卡越多越抽不到关键牌，配卡本身就是要调的变量。
- **抽牌 / 弃牌 / 打空**（`player_server.lua` ShuffleDeck / PrepareCard / DiscardCard）：开局洗牌一次；每次轮到自己补到 8 张手牌；手牌可标记弃牌（弃牌模式或右键），随出牌 / 跳过一起生效，下回合替换为新牌；卡包剩余 / 手牌 / 未抽 / 已用 / 待弃 计数常显；卡包打空（无手牌且无可抽）只能跳过，双方全部打空且无 DOT 时直接判平局。
- 战场：**决斗圆盘（SVG）**。椭圆盘上下各一条弧，敌方在上、我方在下按槽位落在站位点；每个站位：系色圆形头像、名字 / 等级、HP 条与数字、魔力点（**普通魔力点蓝色、超级魔力点金色**，旁边 `n+m` 同色数字；右上角图例；teen 无超级魔力点，强力判定直接 +2）、卡包剩余、状态徽标（最多两行，悬停全文）。行动方金色描边，可选目标蓝色虚线环脉动，操控位标「你」，倒下变灰。
- 中央：默认显示回合数 / 行动方 / 剩余半回合 / 全场光环；播放出牌时显示**卡牌面板**（系色标题 + 类型 + 费用 + 卡名 + 「谁 → 谁」+ 附带效果摘要），并从施法者到目标画系色**能量束**（流动虚线 + 飞行弹丸），对自己施放则头像脉动环。
- 飘字：目标头顶 `-伤害`（暴击放大金色）/ `+治疗` / `+charm` / `+ward` / `吸收` / `DOT ×n` / `眩晕` / `失误`。
- 状态明细板：圆盘下方按敌方 / 我方列出每个单位的全部 buff / debuff 全文（charm / ward / 持续 ward / DOT 各段数值 / HOT / 姿态 / 小光环 / 眩晕 / 技能冷却）。
- 动画：事件流切成步骤（行动前 DOT/HOT 结算 → 出牌 → 换边生成能量 → 结束），HP 随步骤逐步扣减；速度 慢 / 正常 / 快 / 无动画，随时「跳过动画」；切到其他页再回来，进行中的对局会接回。
- 交互：点手牌 → 圆盘上高亮合法目标 → 点目标；单目标卡自动确认。「跳过（并弃 n 张）」「托管」「再来一局」。
- 日志：右侧（窄屏在下方）逐条事件文本，含伤害系别 / 暴击 / 闪避 / 跳过原因（眩晕 / 无手牌 / 卡包已打空）。

### 2. 批量模拟页（batch）
- 配置：参与系（默认五系全选）、模式（多选）、等级（单值或列表）、装备段、队伍组成（同系队 / 随机混编）、每对阵场次（100 / 500 / 1000 / 自定义）、seed。
- 运行：进度条（已完成 / 总场次、速度 场/秒）、可取消。
- 结果：
  - 5×5 胜率热力图（行 = 我方系，列 = 敌方系；对角线 50% 基线；单元格显示胜率与 95% 区间）。
  - 按模式切换的热力图；"各系平均胜率"条形图。
  - 表格：平均回合、场均伤害 / 治疗、fizzle 率、平局率。
  - 卡牌统计：使用频次、贡献伤害 / 治疗、fizzle 次数；未支持卡出现次数（红色标注）。
  - 导出 CSV / JSON；"发送到 AI 建议页"。

### 3. 数值面板（params）
- 全局常量：maxPips、maxRounds、handSize、critDamageRatio、dodgeDamageRatio、maxSpellPenetration、areaSiblingRatio。
- 按系系数：hp / damage / heal 乘子滑杆（0.5~1.5，步 0.01），accuracy / powerPip / resist / crit 加法百分点。
- 单卡表格：搜索 / 按系与 type 筛选；可编辑 pipcost、accuracy、damageMin/Max、heal 等；改动行高亮。
- 与基线 diff 列表；重置到基线；导入 / 导出 JSON；"用当前参数重跑上次矩阵"。
- HP 曲线预览：五系 L1~L50 折线（应用系数后）。

### 4. AI 建议页（advisor）
- 上半：自动调参器
  - 选择可调维度（默认各系 hp、damage）、步长、迭代上限、每次评估场次、目标矩阵（沿用批量页配置）。
  - 运行 / 停止；实时显示 loss 曲线与当前最佳参数。
  - 结果：参数改动清单（"烈火 damage ×0.96 → ×0.93"）、改动前后热力图对比、"应用到数值面板"。
- 下半：大模型建议
  - 设置：endpoint、model、API key（仅存本机）。
  - "生成建议"：把最近一次矩阵 + 当前参数 + 卡牌统计整理成 prompt 发送；展示 Markdown 回复；若含参数 JSON 块，提供"预览 diff → 应用"。

## 统计口径

- 胜率 = 我方胜场 / (总场 − 平局)；平局单独展示。
- 95% 区间用 Wilson score。
- 场均伤害 = 实际扣除 HP 之和（含 DOT），不含被 absorb 吸收部分；另列"吸收量"。
- fizzle 率 = fizzle 次数 / 施法次数。
- 未支持卡占比 = 卡组中未支持 type 的卡数 / 卡组总数（按系汇总）。

## 视觉

- 系色：烈火 #E5533D、寒冰 #4DA3FF、风暴 #8E6BFF、生命 #4CC36B、死亡 #6B6B7A、平衡 #D9A441。
- 深色背景，卡面浅色；移动端手牌横向滚动；最小宽度 375px。
- 不用 emoji；图标用 CSS 形状或 SVG 内联。
