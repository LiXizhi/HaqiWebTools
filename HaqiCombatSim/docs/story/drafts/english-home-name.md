# 留在书上的小名字

英语 L1 原创家园故事，目标 name。作者源为 english-home-practice.json；不是身份登记，不要求真实姓名。只支持初级句型 My name is …，允许自选的拉丁字母昵称、连字符和撇号；不宣称自由英语写作已全面实现。

伙伴想一起看书，却不知道这是谁的故事角。孩子先指出自己的书，再给它写昵称标签，最后根据刚写的标签介绍自己，带伙伴到同一本书旁开始阅读。名字由孩子决定，后一步读取实际保存的文字，不能固定要求示范中的 Pip。

| 场景 | 角色愿望与对白方向 | 实际操作 | 目标 |
| --- | --- | --- | --- |
| 选书 | 我想和你一起看书。先告诉我你选哪一本吧。 | 回应 A book. 并点书 | 复习 book |
| 留下名字 | 想知道故事角是谁的；解释 name 和 My name is …；鼓励用游戏昵称 | 在选中的同一本书上写并保存自己的短句 | name 首次介绍与写作 |
| 认识你 | 书上留下了昵称，伙伴邀请孩子亲口介绍 | 回应实际标签中的昵称，再将伙伴拖到同一本书开始阅读 | name 表达与实际互动 |

普通写作变式分别在书、纸、书包上留下昵称；各有介绍／复习版本。不强制孩子为了刷次数更换名字，不变的标签保存不计数，可以选另一物品或做其他玩法。普通回访只有书本上已有合法昵称标签时出现。

仅验证本轮句型、真实变更保存、对象与后续标签一致；不验证真实身份。错误文本保留为自由作品，但不计本轮练习。取消、重复保存及旧会话回调不计；后一步标签改变或物品消失使旧结果失效。名字本身不加入核心词、不因其拼写额外计分。查看例子不等于独立创作。
