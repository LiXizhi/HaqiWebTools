# 等我把小画画好

家园连续故事en-l1-wait-for-my-picture，优先补wait/like/friend复现，draw作为已学能力。玩家先请同一伙伴等一等，再在真实画纸上创作，在原纸写喜欢的事，最后回到原伙伴面前分享。

四步：Wait, please.（伙伴完整回应才计wait）→I can draw.（必须保存新笔画）→I like books./I like drawing.（在原画纸保存所选句子才计like）→You are my friend.（原伙伴回应后计friend）。作品可自由画；文字保留两个作者句，并支持 I like my/the 加当前家园中已学物品的英文名，不冒称任意自由作文或独立掌握。图画内容不由模型判定，不声称知道孩子画了什么。

前置chair、paper、draw、book已练习；wait/like/friend最多三个新词。全程保留原椅子、原画纸、原宠物身份；画作被清空或原物品/伙伴消失时不能冒认完成。分享只在家园留作品并和伙伴交流，不自动赠送、公开或发送。现有重玩入口可再画一次，重复回执不重复计数。

新故事增加一次创作情境，不自动等于三个生活情境或跨日复习。独立听读、更自由的表达和儿童试玩仍需继续。

正式场景S2826—S2829。作者/绘画核心15项加新原画纸与原伙伴绑定1项，共16项通过；1280/390浏览器分别写I like books./I like drawing.，实际保存笔画、空画不计、错误标签不计、原画纸/椅子/伙伴绑定、重载作品及进度通过。390使用触屏绘画，已查看完成截图。首次测试误用开场按钮寻找伙伴回复，改为现有对话默认按钮后完整重跑通过。导出/--check、Python12项、课程检查和相关diff检查通过。真实语音和儿童体验未验证。

## 开场与提示分离

四段 opening 分别由伙伴询问今天想玩什么、答应等待、请求给作品留一句话、邀请下次再玩。intro 是玩法说明，显示在练习面板的“故事与玩法提示”，不作为角色台词。伙伴不声称识别了画中内容。

写作支持 I like my chair.、I like the paper. 等有限句型；名词取自已练习且当前实际存在的目录物品，不读取自定义标签生成答案。绑定物品消失或被替换时旧练习失效，新增无关物品不改变已冻结的候选。仅目标 like 计数，句中辅助名词不额外计数。这仍不是任意自由作文。
