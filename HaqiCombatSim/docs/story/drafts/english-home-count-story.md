# 两本书的故事角

英语 L1 家园连续故事 `en-l1-two-books-for-story-time`，已接入本地，未发布。作者源 `english-home-practice.json`。正式场景 S2748—S2750。本轮补计数与连续故事的接线，不宣称已完成数字的岛屿课程。

伙伴想准备故事角，却担心把同一本书算两遍。孩子选一张桌子，逐本点数绿框中的两本书，再把清点结果写到原桌上。这是有实际用途的数量便条，不把口头报数视作真实清点。

| 步骤 | 目标与表达 | 实际动作 |
| --- | --- | --- |
| 选故事桌 | table / A table. | 找到真实桌子，保存其身份 |
| 数书 | two / Two books.（也允许 Two.） | 两本书都完整在计数区域内；逐个点击，每件只算一次；再说出或输入英语数量 |
| 留便条 | two / Two books. | 在第一步原桌保存文字标签 |

table、two 可分别首次引入，book 是已学支架；不绕过当前会话新词预算。目标词引用沿用完整 L1 规范词条账本。选择桌子和数量便条不自动搬动书，文案只说书在旁边；写下的是这次清点结果，不把便条当作实时库存显示。

计数时冻结整组物品身份与计数范围，临时增加、移除或替换目标物品须重新数。重复点击一件不计第二次，未点全不提供答题入口；打字输入“2”不代替英语拼写，语音数字归一化沿用原规则。数量回答与实际点数均通过才保存练习。错误便条不计，刷新不重复记账。

连续故事现允许 count 模式，但不允许把计数集合通过 useObjects 当成单件物品引用，也不通过已有单件绑定缩窄被数的集合。后续写作引用的是先前选好的桌子，不是计数集合中的任意一本书。计数集合的长期作品引用仍未实现，未来如需“给每一本数过的书写标签”须另行设计。

准备提示会说明所需实际数量及物品，例如在画面中间摆好两件书，让每件完整可见。一本或三本不伪装成两本。现有原生家园摆放、计数绿框、标签和 WordTree 记录复用，不新增库存或奖励系统。

桌面／390 宽度浏览器覆盖选桌、重复点数、错误数字和错误数量、正确清点、原桌写作及刷新保留。仍缺数字完整岛屿教学、更多数量的情境故事、真实语音与儿童试玩；一篇三步故事不代表足量复现或完整一级交付。
