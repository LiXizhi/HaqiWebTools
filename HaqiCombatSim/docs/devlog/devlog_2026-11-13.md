# 2026-11-13 · 汉字「传」Three.js 3D 夜驿剧场

## 交付

新增 `hanzi/hanzi_chuan.html`（单文件，原生 ES Module + Vanilla JS，Three.js 仅从 Keepwork CDN 静态引入），
以「一驿接一驿，把灯传下去」为主题的七幕 3D 互动动画，含三次互动与六笔真实楷书描红。
设计文档 `hanzi/docs/16_chuan.md`，总览 `hanzi/docs/00_overview.md` 增第 30 行。

## 关键实现

- **双 canvas 剧场**：`#glView`（WebGL）+ `#inkView`（2D 笔墨与引导线）。单 rAF、DPR ≤ 2、
  松林 / 树干 / 村舍 / 屋顶 / 窗火全部 `InstancedMesh`，孔明灯共享几何与材质，光轨用 `setDrawRange` 生长。
- **真实描红**：内联 makemeahanzi 固定 commit `bddc96d4` 的「传」六笔轮廓与中线；
  `Path2D` + 纯 JS 采样（`densify` / `resamplePoly` / `bezierChain`），不依赖 SVG DOM；
  古形 → 小篆 → 楷书三段 morph；宽容趋势投影判定，无永久毒化标记。
- **戏剧化光照**：冷月主光（1024 PCFSoft 软阴影）+ 青碧轮廓光 + 破晓暖阳光 + 四驿点光 + 烽火点光；
  自定义 shader 体积光柱（边缘 `pow(edge,1.6)` + 首尾双向 smoothstep 柔化）；线性雾；520 粒柔光贴图流萤。
- **声音**：WebAudio 原生合成古琴五声、驿铃、夜风、马蹄、印章闷响、低音铺底；默认开启，
  顶部 `#mute` 一键全静音并显示「声音 开 / 关」与 `aria-pressed`。

## 本轮修复的可观察缺陷

1. **页面全白**：首次 Write 被输出长度截断，`<script type="module">` 语法不完整导致模块整体抛错。
   改为分段追加补完，`node --check` 通过后才进浏览器。
2. **光柱是实心灰楔**：`MeshBasicMaterial` 锥体改为自定义 shader，按视线夹角与 UV 双向柔化。
3. **松林悬空**：几何原点移到底部、树干深埋坡面、树冠底缘压住地表。
4. **顶部提示与意境按钮重叠**：`#moodBar` 从顶部横排改为侧边竖排（桌面左 / 移动右）。
5. **片头字形在暗背景不可见**：新增 `glyph.gold`，无纸底阶段强制暖金书写 + 外发光。

   - 地形改为平缓谷地（不再抬升成墙），地面扩到 420×340 并把雾远端收紧到 46。
9. **竖屏布局**：品牌只留印章、进度条缩排一行、意境按钮移到右侧竖排、字幕字号下调。
10. **WebGL 禁用时控制台报错**：先用探测 canvas 判断上下文可用性，不可用则静默隐藏 `#glView` 走 2D，不再让 Three.js 抛错。
