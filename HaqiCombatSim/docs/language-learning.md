# 多语言与语言学习

默认界面仍是中文。设置里的「界面语言」可以改成 English、日本語或 한국어。日语和韩语目前没有词典文件，没有译文的句子继续显示中文。

中文原文就是词典的键。内容 JSON 和源码里的中文句子不改成编号。显示时用这句中文去查表。

英文对照在 `data/adventure/locale/en.txt`，一行一条。分隔符是这一行里最长的一串 `|`，通常写作 `||`。句子里如果已有 `|`，分隔符就用更长的一串。没有这一行时，画面显示中文键。没有 `zh-CN` 文件。

以后增加语言时，新文件的中文键要和 `en.txt` 对齐：

```text
node scripts/diff_locale.mjs data/adventure/locale/en.txt data/adventure/locale/ja.txt
```

语言学习关闭时，只切换界面语言。打开后要选母语和目标语言，两者不能相同。画面显示目标语言。鼠标悬停显示母语，并可以朗读目标语言。

自由交谈、商店的语言挑战、战斗顶部的对话进度都只在语言学习打开时出现。学习者档案写在 Keepwork 工作区 `HaqiAdventure` 的 `memory.md`，本地存档里留一份镜像。未登录时这些需要模型的功能会提示失败，游戏本身继续。

战斗里的说话进度到 50 会让对方失去四分之一生命，到 100 则直接判胜。这不改变卡牌伤害公式。
