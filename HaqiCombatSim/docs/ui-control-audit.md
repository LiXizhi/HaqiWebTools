# 游戏 UI 控件盘点与统一建议

2026-11-19，基于 `main` 的 `afb8915`。在正式游戏的 21 个界面状态中，18 个同时出现了贴图按钮或图集图标，以及 CSS、SVG 或原生表单控件。最值得先改的是**同一个选择或翻页动作换了外观**。普通按钮、页签、装备格各有用途，适合分别建立一致的样式。

## 从哪两处开始

| 优先级 | 玩家现在看到什么 | 建议改动 | 怎样验收 |
| --- | --- | --- | --- |
| 第一批 · 语言选择 | 设置的“语言”页同时显示三排四选一。“界面语言”的 4 个选项用共享页签，“母语”和“目标语言”的 8 个选项用主次按钮贴图表示选中。 | 让三排复用同一个单选按钮组。可将现有语言选择控件接受的选项、当前值和回调参数化。保留母语与目标语言联动的业务规则。 | 12 个选项使用同一选中标记。鼠标移开、键盘聚焦、切换语言后仍能区分当前值；另外两排的业务回调各自生效。 |
| 第一批 · 分页 | 背包、强化、镶嵌、任务手记、商城商品列表的上一页和下一页使用贴图按钮。卡包的两个同名按钮使用独立的 `.bag-page`，宠物横向列表用两个圆形箭头。 | 先给 6 个文字分页入口接同一个紧凑分页组件，沿用现有页码、禁用和焦点逻辑。宠物列表保留横向滚动，以同组的箭头样式实现。 | 逐个入口检查首页、末页、翻页后的焦点与选中项。文字版与箭头版共享边框、焦点环和禁用表现。 |
| 第二批 · 主界面图标 | 右上 4 个工具和底部 5 个入口已使用绘本图集。学习、私聊、字典的快捷入口使用线描 SVG，设置页签还使用系统表情。 | 先做并排图标样张，沿用已有绘本图标的色板与视觉尺寸。在同一工具栏使用同一套图标规范，把缺少的功能图标登记在共享入口。 | 在普通、选中、禁用和图片加载失败四种状态下，每个入口都能辨认；可访问名称和点击范围保持可用。 |
| 第二批 · 家园 | 家园场景的 7 个操作都由代码绘制。`.home-world` 的通配规则用 `!important` 重设大部分按钮，并隐藏除关闭按钮外的按钮伪元素。新接入的共享按钮也会受到影响。 | 逐组把外观移到明确的家园工具按钮类。保留场景底栏的紧凑尺寸，让普通确认、取消操作可直接使用共享皮肤。 | 同时检查场景底栏、编辑工具、命名对话框和返回操作。关闭当前弹窗后，焦点回到相应工具。 |

## 控件统计

数字表示某个界面状态中参与布局的交互元素，包含可滚动区域内及已禁用的控件。每个元素只进一列。角色列表、物品格、分页按钮按显示实例计数，切换状态后出现的共享关闭按钮会再计一次。这里统计的是控件出现次数。

- **贴图表面**。按钮自身或已显示的伪元素通过背景、边框或遮罩 URL 绘制，例如森林九宫格按钮。
- **图集图标**。控件自身没有贴图表面，内部显示共享 UI 图集中的图标，例如关闭、地图和背包入口。
- **内容图形**。前两项均未命中，控件内有参与布局的 Canvas、图片或宠物图层，例如商品、货币、卡面和角色。此列描述图形载体，未逐个判断 Canvas 像素来源。面板上的独立插画和地图底图没有计入。
- **代码外观**。其余可识别的 DOM 控件，包括 CSS 页签、SVG 工具、文字按钮、输入框、下拉框及折叠标题。CSS 渐变算在此列。

### 范围和复查方式

浏览器从本地资源启动隔离验收页，使用游戏视图和 `Haqi.html` 的样式顺序，等待森林皮肤生效后读取计算样式。统计覆盖标准表单、链接、折叠标题和脚本所列 ARIA 交互角色。整张画布里的命中区、影子 DOM、未打开的二级弹窗、不同存档解锁的状态未遍历。

仓库还有独立的工具、官网、宣传页和汉字故事。根目录共 11 个 HTML 入口（含游戏），`hanzi/` 顶层另有 32 个独立字页（已排除索引）。这些入口风格面向不同场景，未混入游戏样本。一次全仓 `js/` 源码核对还发现以下维护情况。

| 静态核对项 | 结果 | 对改造的意义 |
| --- | ---: | --- |
| 名为 `button` 或 `btn` 的函数声明、括号参数箭头函数定义 | 21 个文件各 1 处。学习 9，冒险视图 6，汉字 2，家园 2，大头贴 1，共享 UI 1。 | 相同调用名的默认外观有空类名和 `secondary` 两种。迁移时要检查原有翻译、禁用、异步互斥和回调。 |
| `createCloseButton(` 直接调用，已排除组件定义 | 41 个文件、46 处 | 关闭按钮已经具备跨功能复用的入口。共享组件挂一次点击事件，图集可用时显示贴图，缺图时显示 SVG。 |

在 `HaqiCombatSim/` 目录启动本地静态服务。统计脚本使用 Playwright 和 Chromium，可用 `--playwright`、`--executable` 指定本机路径。JSON 输出保留每个界面按元素、样式类分组的计数与示例文案。[统计脚本](../scripts/audit_ui_controls.mjs)

```sh
node scripts/audit_ui_controls.mjs --url http://127.0.0.1:8791 --out tmp/ui-controls-desktop.json
node scripts/audit_ui_controls.mjs --url http://127.0.0.1:8791 --mobile --out tmp/ui-controls-mobile.json
```

## 后续新增控件怎么选

| 交互用途 | 共用实现 |
| --- | --- |
| 确认、购买、保存，以及取消、返回 | 使用语义明确的原生按钮和现有主次操作皮肤。森林素材负责纹理与边框，DOM 负责文案、换行、翻译、焦点和禁用。 |
| 多选一、页签、筛选 | 使用共享的 `.gui-tabs` 与选中态。沿用纸色未选、深绿选中和金色底标。 |
| 关闭、工具栏图标操作 | 关闭统一调用 `createCloseButton`。图标按钮共用尺寸、焦点和可访问名称约定，允许图集与 SVG 回退。 |
| 编辑文字、数值、滑块和下拉 | 保留原生输入语义，用公共色值、边框、间距和焦点环对齐周围面板。 |
| 装备格、卡面、地图与场景工具 | 保留内容美术、地图徽章和紧凑操作形式，同一类对象的选中、聚焦、禁用反馈保持一致。 |

改造完成后按“同一动作有几套样式”复查。语言选择应归为一套，文字分页应归为一套。桌面与手机各检查长译文、键盘焦点和禁用态，再分别在图集正常与图片加载失败时验证相同行为。[GUI 规范](gui-style-guide.md) · [皮肤加载与回退](../js/adventure_ui_art.js) · [共享控件](../js/ui/controls.js)
