# 蓝色魔法星图集

原版依据：儿童版使用 character/v5/11vip/MagicStar/MagicStar.x；Pet/main.lua 第1906–1915行选择模型，第2027–2035行以 AddAttachment(asset,4,1)挂到角色。原版纹理已按assets_manifest.txt的MD5核验，完整条目保存在source.txt，解码参考为original-texture.webp。

本次使用内置 imagegen，根据原版纹理重绘，非原生模型动画导出。本机原生CLI未运行。生成图的完整PNG保留在工具输出目录，项目交付为透明WebP。

生成提示词：制作同一只蓝色、圆润、立体五角魔法星的连续16帧无缝循环，严格4列4行、按行排序，真正透明背景；亮青蓝色到宝蓝色的星体，淡金黄色中心光，没有五官、四肢、文字、网格或边框。参考图仅作为原版UV材质/配色依据。保持几何体、尺寸、照明一致，绕垂直轴从正面以每帧22.5度转完一周；第0帧正面、第4帧侧面、第8帧背面、第12帧另一侧，第15帧接回0帧。每格轻微上下浮动与俏皮倾斜，留透明边距，不在图中画角色或整条绕行轨迹。头顶公转由独立预览驱动。

播放参数：4×4、16帧、10fps、1.6秒循环。预览 tests/fixtures/magic-star.html 同时演示自身旋转和头顶绕行。图集仅为独立美术交付，未上传CDN、未替换游戏当前会员效果；正式接入时按角色/骑手头顶位置锚定，并遵循前后遮挡和减少动态效果设置。

清理提示词（第二次内置imagegen编辑）：保留全部16格的蓝金配色、旋转姿态、顺序和尺度；去除星体之外全部蓝色噪点、碎屑、散光和背景痕迹，仅保留干净的星形轮廓及中心光；每格四周至少40像素全透明边距，严格4×4等分，透明背景，无边框、文字或额外物体。

最终采用第一版：第二次清理没有改善造型，因此未选用。最终WebP为768×768，每格192×192，质量95，139,278字节；完整保留生成alpha。极低透明度的柔光未扣除，主体边界验证按alpha≥32计算，阈值记录于atlas.json。浏览器深色底和棋盘底合成显示正常。
