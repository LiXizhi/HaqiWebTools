**解读（供数值同学参考，非结论）**

- teen 生命系在官方 Aggressive 卡组下几乎不能取胜（43% 平局、0% 镜像胜率）：卡组攻击牌为 `Life_SingleAttack_Level1~6`，而所有系的 Aggressive 卡组都带 `Life_LifeGreatShield`（-70% 生命伤害）和 `Balance_GlobalShield`，治疗又受 80 半回合上限约束 → 对局拖到超时。建议观察点：生命系攻击牌数值 / 通用盾对生命伤害的覆盖 / `maxRounds`。
- 死亡系在 kids 团队模式随人数增长而走强（68.6% → 91.1%），主要来自 `Death_SymmetryGlobalTrap`（+110% 任意伤害）与吸血；寒冰在 kids 全模式稳定 65~74%。
- 先手优势 53~61%，团队模式更明显（每半回合行动方全员先动）。
- 以上均为 **Bot vs Bot、无装备属性（gear 区间取默认）、固定卡组** 的口径；真实玩家卡组与装备会改变绝对值，但矩阵的相对结构可作为调参起点。

### 2026-09-16 · 引擎修正（在基线前完成）

复核对局事件流时发现并修复三处与 Lua 不一致的行为，修复后重新生成上表：

1. **单体陷阱 / 虚弱贴到自己身上**：`Wards` / `Charms` 类卡以前一律按 `friendly` 选目标，Bot 选的敌方目标被 `validTargets` 拒绝后回落到自己（`Ice_IceDamageTrap` 变成给自己 +80% 受伤）。现由 `inferTargetKind` 按 charm / ward 模板的 `positive` 推断 `hostile` / `friendly`（`combat_params_core.js`），与 `deck_attacker_ai/*.csv` 首列一致。
2. **X 费 DOT 不结算**：`Fire_DOTAttack_LevelX` 的 `dots="42p,42p,41p"` 之前被 `Number()` 解析为 0。现按 `card_server.lua` L1246 `GetNumericalValueFromSection` 用实际消耗能量倍乘（kids 烈火对外胜率 8.3% → 21.0%）。
3. **溅射 DOT（负值段）被跳过**：`Fire_DOTAttackWithSplash_Level6` 的 `dots="-800,0,0"` 在 Lua L1978 为“溅射”，以绝对值打持有者及站位 ±1 的队友；现已实现。
4. `SymmetryWards`（`target_wards` / `caster_wards`）之前读不到参数，现分别贴到目标与施法者。
5. `firstMoveWinRate` 之前统计的是“近端胜率（含平局）”，现记录真实先手方并只在有胜负局中统计。

已补回归测试：`tests/engine.test.mjs`「DOT：X 费卡 "Np" 按实际消耗倍乘；负值段为溅射打持有者及相邻队友」。
