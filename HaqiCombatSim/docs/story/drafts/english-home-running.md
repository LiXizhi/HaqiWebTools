# 终点的小小啦啦队

英语L1真实跑步故事，目标run。先由伙伴邀请孩子选椅子作为终点，说明没有名次与倒计时；孩子回应后控制主角沿路跑到附近，最后实际把伙伴带到原椅子坐下。三幕分别计chair、run、sit，最多三个新词。另有椅子/桌子终点的首次与回访四变式。

跑步仅在本轮回应正确且主动按“开始跑步”后启用，结束或离开练习恢复普通速度。移动速度为6格/秒，原走路4格/秒；沿用寻路、碰撞与家园角色渲染，跑步每帧分两次碰撞检测，不跳过薄墙或河岸。不要求孩子在现实中奔跑，不使用麦克风音量、说话速度或限时判断。

共享移动轨迹验证至少1.5格连续真实跑动并到达原终点附近。仅说词、点选家具、站在终点、普通走路、传送及重复回调都不能当跑步完成。终点移动、进入布置或身份/语言变化使当前轨迹失效；切回后重新开始，不恢复未完成的跑动距离。只计明确目标run，不附带计walk或stand。

伙伴的“加油”为开场对白，不声称有新增啦啦队动画。角色复用现有移动表现，新增跑步速度，不是新的专属动作图集。双人家园仅练习者使用跑步速度，另一名角色仍保持正常移动及视野约束。

仍需补：run的独立岛屿故事、听令起跑/停止、自由口头描述和写作；更多生活情境及跨日复习；真实语音、触屏和儿童体验。跑过一段路加一次有效表达不是独立四技能通过或整级完成。
