# 家园配色游戏：一样的伙伴与不一样的选择

2026-10-26 作者稿，已接入 english-home-practice.json 并导出到 story-home-language.md。伙伴准备给家园配色，先用普通对话说明愿望，再用绿框标明真实参照物。same 表示相同，different 表示不同；本轮只比较颜色，不把不同形状混为颜色差异。

两个独立愿望：给球找颜色相同的伙伴；给餐桌选一个与参照杯不同颜色的杯子。书也可以用于给阅读角配色。每次至少有参照物、正确选择、干扰选择，参照物本身不是答案。所有符合颜色关系的选项都接受，不能暗藏唯一物件 ID。颜色没设置不猜图片颜色；物品消失或改色使旧轮失效。点击前要回应短句，点击本身不冒充口语练习。

每词三类物品（球、杯、书）各有介绍和复习稿，共十二个情境。数量是内容变式，不代表达到每词十二次、独立能力或完整故事章节。后续需接实际布置结果和跨会话任务。
