# 06 · 木（`mù`）—— 破土而出的树冠、树干与树根（`hanzi_mu.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**：
   - **汉字**：木
   - **拼音**：`mù`
   - **本义**：树木（《说文解字》：“木，冒也。冒地而生。东方之行。从屮，下象其根。”）。
   - **引申义**：木头、枝干、草木、质朴。
2. **古文字演进（甲骨文 → 金文/小篆 → 隶书/楷书）**：
   - **甲骨文与金文**：正中一竖代表挺拔的树干，上半部分向上分叉代表伸展向天空的枝条，下半部分向下分叉代表深入泥土的树根，上下对称、顶天立地。
   - **小篆**：上部枝条呈上扬弧线，下部树根呈下垂弧线，中间树干贯通。
   - **隶变与楷书**：上部展开的树冠枝条平直化为第 1 笔「横（一）」，正中树干化为第 2 笔「竖（丨）」，下部向左右扎入大地的树根化为第 3 笔「撇（丿）」与第 4 笔「捺（㇏）」，共 **4 笔**。
3. **事实与艺术边界声明**：
   - 动画同时展现地面之上的树干与树冠、以及泥土断面之下的分叉树根，帮助儿童直观理解《说文解字》“从屮，下象其根”的造字本义。
   - 描红环节严格遵循标准笔顺：**先横（树冠平枝）→ 再竖（通天树干）→ 后撇（左树根）→ 最后捺（右树根）**，体现“先横后竖、先撇后捺”的汉字基本笔顺规则。
   - 页面左下角保留说明：“古字形为依据通行字形的艺术示意”。

## 二、情感与动作主题（一句话）

> 春日山坡的湿润泥土里，孩子按住唤醒沉睡的橡果种子、向上提拉让树干破土伸展枝条并向下扎稳深根、依次点亮枝头新叶与林间小鸟松鼠，看树冠、树干与树根化作甲骨文与楷书的「木」。

## 三、美术、色彩、构图与声音设计（春野双层剖面 2D 剧场）

### 1. 色彩与光影递进
- **春泥待芽（寻种/催芽）**：温润春夜/晨曦天幕 `#0a1914`、湿润深褐泥土剖面 `#1c140e`、种子微光 `#a6e278`。
- **破土参天（拔干扎根）**：苍劲树干与深根 `#8c5a32` → `#b87e4a`、翠绿春野 `#285a3a`、阳光透叶 `#d8f598`。
- **枝繁叶茂（唤醒三处生机/尾声）**：满树翡翠新叶 `#52d68a`、黄鹂鸣枝 `#ffd258`、松鼠抱果 `#e68a42`。

### 2. 桌面宽屏与手机竖屏自适应构图
- 统一世界坐标系与多机位摄影机 `VIEW`（`intro`、`hill`、`seed`、`grow`、`wide`、`anatomy`、`glyph`、`finale`）。
- 巧妙设计**地上天空 + 地下透明泥土剖面**同屏构图：地平线位于 `y = 485`，上方展示树干与横向舒展的树枝，下方半透明土壤层清晰展示左右分叉扎根的树根，完美对应「木」字结构。

### 3. WebAudio 实时合成音景（零外部音频依赖）
- **春风拂叶声**：柔和带通滤波风声，随树木生长与叶片繁茂渐次丰满。
- **五声木琴/古琴音**：采用 F 大调五声音阶（`F4, G4, A4, C5, D5, F5, G5, A5, C6`），木质温润共鸣。
- **交互音效**：春雨润种声、枝干破土生长声、清脆鸟鸣与新叶舒展声、描红逐笔木琴音。

## 五、笔顺与字形数据（与字典 `zh.json` 严格对齐）

- 笔画数：**4 笔**（Arphic Public License / Make Me a Hanzi `木` 字骨架对齐）
  1. **第 1 笔 · 横**：上部横向舒展的枝条，自左向右平拉（`[20,38] → [78,35]`）。
  2. **第 2 笔 · 竖**：正中顶天立地的树干，自顶向下笔直贯通（`[49,12] → [49,90]`）。
  3. **第 3 笔 · 撇**：左下扎入泥土的树根，自交点向左下舒展撇出（`[47,38] → [32,61] → [14,78]`）。
  4. **第 4 笔 · 捺**：右下扎入泥土的树根，自交点向右下舒展捺出（`[51,39] → [68,64] → [88,75]`）。
