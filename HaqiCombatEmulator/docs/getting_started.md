# 使用入门

1. 按项目 README 启动静态服务，打开 `HaqiCombatEmulator.html`。
2. 顶部选择儿童版或青年版，对战页选择 1v1–4v4。切换人数会使用对应的实验预设重新创建阵容。
3. 配装页选择 A/B 队席位。快照模式直接使用最终面板，不叠加装备或 VIP；配装模式计算现有支持的装备、强化、宝石、套装和 VIP 属性。修改后点击“应用到阵容”，战斗重置。
4. 对战页点角色、选目标、点手牌，为同一行动方多个角色分别指定动作。点击“推进一回合”结算；未指定动作的角色由战术机器人接管。“全员托管”自动推进，可暂停、改速度或重置。
5. 批量实验选择当前阵容、五系矩阵、混编或职业替换。场数包含交换阵营的对局，选择 1,000 / 5,000 / 10,000。Worker 后台计算；取消只保留已经返回的完整分片。
6. 报告显示职业参与胜负、得分率、区间和阵容表现。载入某个样本会按种子重算；拖动回放进度可逐段核对动作。
7. AI 页先有完整的当前配置报告，再登录 Keepwork 并请求建议；也可自行填写数值补丁。复测不会改动当前基线。完成后可导出候选与证据。

顶部“保存实验”保存当前版本的阵容与种子。两个版本分别保存；实验报告与候选复测完成后自动保存。“导出”导出当前阵容；战斗和报告页分别导出战报与报告。“导入”支持这些 JSON 格式，要求版本和配置哈希一致。保存尚未应用的配装草稿不生效。

快照预设均为等级 50、生命 5,000 等显式控制变量；卡组从真实配置中选取，但不代表真实玩家装备或卡组分布。结果受机器人水平和当前已实现规则限制。

手机采用横向导航和可滚动卡牌。设备旋转后可重新打开对战页以重绘 Canvas。应用需要现代浏览器的 ES Modules、module Worker、IndexedDB、Web Crypto 和 structuredClone。补丁哈希使用 Web Crypto，需要 localhost 或 HTTPS 安全上下文。AI 使用 HTTPS CDN，网络或登录失败会显示错误，可继续本地模拟。

## 卡包、配卡与演示

配装页的“配卡”区域设置卡包容量、手牌容量、每轮补牌上限 N，并用卡牌目录的 + / − 调整每种卡的副本数。默认每轮补到最多 8 张，未使用手牌保留；N 是补牌上限，不是每轮把旧手牌全部换掉。

战斗页显示当前角色手牌、剩余牌库、已用、已弃与待弃数量。每张手牌下方可标记/撤销弃牌；推进回合才确认，下一己方回合补牌。成功使用及确认弃掉的卡不会再抽到，耗尽后只能等待。

圆盘的彩色点对应双方席位；每次结算逐张演示卡片与施法者→目标，连线箭头指向目标。手机将出牌卡片放在圆盘下方避免遮挡。角色状态栏以绿/红/紫区分增益、减益与光环，列出数值、剩余次数或触发消耗说明。暂停、导航或重置会停止演示计时器；动画不影响批量实验。

## 增益／减益自动配卡（v0.2.1）

此前默认卡组只选择攻击与治疗，未加入辅助牌。现在双版本五系默认卡组包含攻击、增益刀、盾、伤害陷阱，以及对应学系的弱化/群体陷阱/治疗增益或控制技能。每种通常配置 4 张，使用真实规则包中的技能；仍为实验组合，不代表实战最优卡组。

战斗页“全员自动配卡 · 含增益/减益”可替换双方卡组并重置本场，保留人物属性与卡包设置。配装页“自动配卡”只改当前角色草稿，点击“应用到阵容”生效。目录可按攻击、治疗、增益、减益筛选，卡牌显示效果数值。

载入本机保存时，精确匹配旧默认配卡的角色会自动升级；自定义卡组保持原样。容量较小的卡包优先分配不同种类再增加副本，不超容量。仍按种子随机抽牌，不保证每一手都抽到增益／减益。

手动点击辅助卡：优先使用当前合法目标；目标不合法时，优先选自己或首个合法目标，已选动作显示最终目标。增益给友方，陷阱/弱化给敌方。战术机器人 0.2 会评估辅助收益，并避免反复添加同一种已有刀/盾/陷阱。

## 精简配卡与魔力颜色（v0.2.2）

新建角色默认卡包容量 40 张，同一种卡（相同 key）最多 6 张；容量是上限，可以只携带 20 或 30 张，不必放入所有技能。加牌按钮达到副本或容量上限后禁用。已有显式容量保留，不自动改动自定义角色。

每种已配卡显示“首轮抽中”概率。例如同一张关键卡只带 1 张、首轮抽 8 张时，20 张卡组抽中的理论概率为 40%，40 张卡组则为 20%。该概率仅为均匀无放回模型；卡组是否更强仍需实测伤害、续航和耗尽风险，不能只按抽中率判断。

蓝色 ● 为普通魔力，金色 ◆ 为超级魔力。战场点数与各角色数量栏使用同一颜色；形状和文字也不同。儿童版超级魔力对本系抵 2 点、异系抵 1 点；青年版保持原先统一魔力池规则，超级魔力生成后转为 2 点普通魔力，不虚构额外金色点数。
