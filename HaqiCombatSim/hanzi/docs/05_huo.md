# 05 · 火（`huǒ`）—— 篝火跃动的焰苗与火星（`hanzi_huo.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**：
   - **汉字**：火
   - **拼音**：`huǒ`
   - **本义**：物体燃烧时升腾的火焰与光明（《说文解字》：“火，燬也。南方之行，炎而上。象形。”）。
   - **引申义**：火把、篝火、温暖、光明、红火。
2. **古文字演进（甲骨文 → 金文/小篆 → 隶书/楷书）**：
   - **甲骨文与金文**：底部如柴薪聚拢之形，正中一道高高窜起的主火苗，左右两侧各有向上腾跃的小火苗或飞溅火星，生动描摹篝火熊熊燃烧、炎上升腾之态。
   - **小篆**：正中火苗向上分叉舒展，两侧火苗向内呼应。
   - **隶变与楷书**：左侧小火苗化作第 1 笔「点（丶）」，右侧小火苗化作第 2 笔「短撇（丿）」，正中主火苗与底座化作第 3 笔「竖撇（丿）」和第 4 笔「长捺（㇏）」，共 **4 笔**。
3. **事实与艺术边界声明**：
   - 动画中“正中主焰冲天而起、左右两簇侧焰与火星相伴”严格对应甲骨文与金文「火」的象形构造。
   - 描红环节重点提示「火」字标准笔顺：**先写两边的小火苗（第 1 笔左点、第 2 笔右上短撇），再写中间的主火苗（第 3 笔竖撇、第 4 笔长捺）**，遵循“先两边后中间、先撇后捺”的笔顺规范。
   - 页面左下角保留说明：“古字形为依据通行字形的艺术示意”。

## 二、情感与动作主题（一句话）

> 寒夜林间空地上，孩子按住火石擦亮火种、向上提拉扇旺冲天主焰与两侧火星、依次温暖营地旅人茶壶与烤架，看跃动的篝火化作甲骨文与楷书的「火」。

## 三、美术、色彩、构图与声音设计（暗夜暖焰 2D 剧场）

### 1. 色彩与光影递进
- **寒夜待火（寒林/擦火）**：深蓝寒夜 `#070b18`、冷霜松林 `#121c34`、柴堆微烬 `#68321c`。
- **烈焰升腾（扇旺篝火）**：金红主焰 `#ff6a28` → `#ffd262`、两侧跃动火苗 `#ff9442`、暖光晕染大地 `#3a1c14`。
- **温暖人间（点亮营地/尾声）**：铜壶沸腾白气、旅人搓手展颜、松果烘香、漫天暖金火星。

### 2. 桌面宽屏与手机竖屏自适应构图
- 统一世界坐标系与多机位摄影机 `VIEW`（`intro`、`camp`、`hearth`、`flame`、`wide`、`blaze`、`glyph`、`finale`）。
- 竖屏（`portrait`）自动适配视场宽度 `pw` 与纵向中心 `pcy`，确保中央篝火、三股火焰、营地三处温暖互动点与四笔描红在 `390×844` 手机竖屏和 `1440×900` 桌面宽屏下均完整居中。

### 3. WebAudio 实时合成音景（零外部音频依赖）
- **篝火噼啪与暖风声**：粉红噪声滤波包络叠加清脆木柴爆裂微脉冲（crackle），随火焰高度动态增强。
- **五声暖阳琴音**：采用 C 大调/宫调五声音阶（`C4, D4, E4, G4, A4, C5, D5, E5, G5`），温润醇厚。
- **交互音效**：火石清脆碰撞声、火焰呼呼升腾声、铜壶咕嘟声、描红逐笔暖弦音。

## 五、笔顺与字形数据（与字典 `zh.json` 严格对齐）

- 笔画数：**4 笔**（Arphic Public License / Make Me a Hanzi `火` 字骨架对齐）
  1. **第 1 笔 · 点**：左侧小火苗，自左上向右下轻点（`[21,38] → [31,52]`）。
  2. **第 2 笔 · 撇**：右上小火苗，自右上向左下短撇（`[72,31] → [57,48]`）。
  3. **第 3 笔 · 竖撇**：中央主焰左支，自顶中竖直下行再向左下舒展撇出（`[48,15] → [48,48] → [17,86]`）。
  4. **第 4 笔 · 捺**：中央主焰右支，自中部向右下舒展长捺出锋（`[50,53] → [67,78] → [90,88]`）。
