# 留给明天的小画

英语 L1 创作故事；作者源 english-home-practice.json。复用已核验的画纸和原家园事务，新增真实笔画作品。核心词 draw；同时复习或介绍 paper、name，不把画中可能出现的其他物体自动算成已学词。

伙伴想给下次回来时留一件小作品。先找纸；伙伴邀请孩子自己决定画什么；孩子说 I can draw.，用画板画出自己的图案并保存；最后写一个自选游戏昵称，留下作者签名。绘画没有标准图案，模型不评价画得像不像。结尾只说明纸上保存了画和昵称，不宣称来客已经看到、理解了某种图案或孩子掌握其他词。

三个步骤：认识并点选 paper → 表达 draw 并在同一张纸保存新画 → 在同一张纸写 My name is …。名字可以虚构，不收集真实身份。普通画画活动另有初次介绍和复习，鼓励修改作品或画另一张，不强制刷笔数。

只有本轮实际改变且包含可见线段的成功保存可提供绘画动作证据；空白、点一下、原样保存、清空、取消、失败、过期回调和保存重试不计。仍须语言回应正确。撤销与重做保留原家园历史语义，不补发练习。自由绘画不带本轮回执，不自动记语言成绩。

作品保存在 paper 物品的 drawing 字段，版本 1、固定颜色、最多 32 笔及总计 1024 点；不保存任意图片 URL 或代码。只实现自由线条绘画，不宣称图像识别或自由作文。当前画板使用鼠标／触屏，键盘绘图、真实语音、儿童试玩和更丰富的作品分享仍待完善。

签名续章 requiresDrawing 核对同一张纸仍有实际笔画，并冻结作品快照；清空或修改后旧结果失效，准备提示要求恢复原画纸作品。不能在空纸上完成“给画签名”的剧情。

清空后提供“回到这张画纸”直接打开原作品编辑器；保存后可重新检查准备情况并继续签名。修复作品不重置故事、不增加 draw 次数，也不偷偷换成另一张纸。
