# 多语言冒险学习：魔法营地试点

更新时间：2026-09-25。本文是跨对话实施主入口。代码完成、自动验证、真人体验分别记录，不能互相替代。

## 已确认目标

只在魔法营地（camp）先做完整试点，用户确认体验后才扩岛。抱抱龙负责现场陪伴，NPC和固定地点承载课程。架构面向任何语言，首期中文与英语双向学习；界面语言、母语和目标语言独立。20组句型、中英各约120条示范表达；长期150组、各约900条，不要求逐字对应。暂不接入HelloTalk。

## 内容与本地化

课程使用稳定ID和语言无关的交流意图，配置事件、对象条件、NPC或地点绑定、难度、挑战子目标。复用localization解析、语言ID和按需加载，教学词典独立于UI词典；通过表达ID查中文源模板，先翻译再填命名占位符。中文有完整教学资源。词汇按实体/语义ID提供各语言词形、量词及常用称呼。缺目标语言内容时关闭该课程，不用中文冒充。分别声明内容、朗读、识别、挑战能力。学习记录按角色及目标语言隔离。

## 触发与交流

事件覆盖靠近/交谈NPC、到达地点、打开背包/选物、获得物品/换装、捕鱼结算、战前/决策/战后。只引用真实上下文；本地独立RNG抽1—2组问答，不改变战斗随机序列。自动提示全局90秒、同来源5分钟冷却；已有对白/录音/动画不插话。默认可忽略气泡，自动朗读需开启；主动发起不受冷却。

基础段可听示范、看字幕后录音朗读，用目标语言规则核对识别文本，不调用模型。打字、点选、播放示范不发口语奖励。

基础通过后开放剧情挑战，2—4个子目标合计100分，最多8轮。AI返回完成项、逐字玩家证据和NPC回复；程序核验证据并算分，同目标不重复。目标语言口语才计分，母语求助可获得帮助，专名允许。涉及操作必须有真实游戏事件，不能口头冒领。100分奖励，可反复练习。营地先简单请求/选择/澄清/解释，其他岛屿再增加复杂目标。

## 语音、奖励和兼容

优先Keepwork ASR/TTS/AIChat，实际线上与手机需单独验证。原始录音默认不保存，失败可重试；退出/换角色/换语言使旧结果失效。分别记录听懂、提示朗读、自主表达及复习时间。

BalanceParams初值：基础10奇豆/同课每日2次；入门30仙豆、进阶50仙豆、多步80仙豆/同课每日1次。角色每日总计100奇豆、200仙豆，北京零点重置；不同语言和同课不同入口共用额度。开始前显示实际可领，超限仍练习。唯一尝试ID防重，钱和账本先保存后生效。旧档空账本不追补。替换免费购物和说话直接判胜，旧战斗重演保留。
