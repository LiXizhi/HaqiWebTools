# 18 · 下（`xià`）—— 顺阶归村灯火暖（`hanzi_xia.html`）

## 一、字源与教学边界

1. **读音与字义**：下，`xià`。常用义是位置在低处，或由高处往低处走、落下。《说文解字》：“下，底也。指事。”页面说明指事造字思路，并标注古字形为艺术示意。
2. **字形**：甲骨文、金文的「下」以一道长弧横表示高处的基准线，在线的下方加一短横表示“低处”。小篆在横线下方垂下一竖并带短画。楷书三笔（Make Me a Hanzi 笔顺）：顶长横、竖、右侧短点。上面一长横像山岗屋檐的基准线，竖笔向下延伸，点画落在右旁，像雨滴与归人的脚步落向低处。
3. **数据**：描红轮廓与中线直接嵌入 `data/adventure/hanzi/strokes.json` 的「下」（1024 字框，基线 900，y 轴向上），保持原始轮廓、中线与三笔顺序不变。
4. **事实与想象**：暮色山梁、石阶归途、坡底亮灯小村与檐下春雨是原创故事。山梁化作上横、归途与檐滴化作竖与点，是教学视觉联想。

## 二、一句话

> 暮色降临时从高高的山岗顺阶往下走，屋檐落下一滴暖雨，坡底的村口灯火为你亮成「下」。

## 三、画面与声音

- **色彩**：暮紫靛蓝 `#222940`、山岗青黛 `#3c4e62`、村口暖橙灯晕 `#f2b365`、宣纸朱褐 `#9c4332`。
- **层次**：上景平整山梁石栏（基准线）、中景蜿蜒向下的归村石阶、下景坡底炊烟屋舍与暖灯。
- **物件成字**：山梁长石栏化作顶上第一笔长横；顺阶向下的路径化作第二笔垂露竖；檐角轻轻落下的一颗雨珠化作第三笔点，依次演示甲骨文 → 小篆 → 楷书。
- **声音**：用户手势解锁音频；暮风低鸣、下山轻快步点、檐雨清滴与归家木琴泛音。

## 四、七段分镜

| 进度 | 场景 | 字幕要点 | 互动 |
|---|---|---|---|
| 引子 | `sRidge` | 太阳快落山了，村子就在山坡下面亮着灯。 | 观看 |
| 下坡 | `sDescend` | 沿着石阶一步步往下走，离家越来越近。 | **点按石阶或按钮**三次顺坡而下（闲置自动推进） |
| 归村 | `sVillage` | 屋檐落下一滴小雨，坡底的门前已经留好了暖灯。 | **轻点屋檐或灯笼**听一声雨滴与招呼 |
| 成字 | `sGlyph` | 上面长横像山岗与屋檐，竖笔向下，一滴小点落在身旁。 | 观看甲骨文 → 小篆 → 楷书三笔拆解 |
| 写字 | `sWrite` | 三笔描红（横、竖、点） | 全部描完触发 `written`；支持「看示范」 |
| 词意 | `sWords` | 山下 / 下雨 / 坐下 | 词组依次点亮并与意境呼应 |
| 余韵 | `sFinale` | 顺着石阶往下走，温暖的家就在灯火下面等你。 | 点击村口夜空点亮归家流萤；进入余韵触发 `completed` |

## 五、构图与适配

- 世界坐标宽 `1600`、高 `1000`：高处山梁石栏在 `y=340`，向下石阶连至村口屋檐 `(800, 740)`。
- 桌面宽屏与手机竖屏均完整呈现高处基准、低处村屋、字格与字幕；片头不发完成事件。
