# 16 · 泉（`quán`）—— 明月松间，清泉石上（`hanzi_quan.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：泉；拼音：`quán`；本义：从地下涌出的水源；引申为泉眼、泉水，以及货币（古以「泉」通「钱」，取其流通如泉）。
   - 训诂与名篇：《说文解字》：“泉，水原也。象水流出成川形。”唐·王维《山居秋暝》：“明月松间照，清泉石上流。”
   - 常用词：`清泉`、`甘泉`、`山泉`、`清泉石上流`。
2. **古文字象形与楷书九笔**
   - 「泉」为**象形字**，非形声。甲骨文、金文上部象崖壁泉穴（穴中或点水），下部象水自穴中涌出、四散奔流之形。
   - 楷书定型后上半写作「白」形、下半写作「水」，共 **9 笔**：撇、竖、横折、横、横、竖钩、横撇、撇、捺。
   - **教学边界（重要）**：楷书上半的「白」是隶变后的**形体讹变结果**，并非「白色」之义，也不参与表音。页面在 `sGlyph` 与 `#note` 中明确标注“上「白」本象泉穴之形，下「水」象涌流；古文字为艺术示意，描红笔顺依规范楷书”，避免儿童误拆为「白 + 水」的会意字。
   - 页面展示的甲骨文与小篆形态为**艺术示意**（由 `bezierChain` 手绘生成），不作为字形学考据依据；只有描红所用的楷书轮廓与中线是规范数据。
   - 笔画轮廓与中线内联自 `skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（1024 字框，基线 900）。

## 二、一句话主题

> 空山新雨、明月松间，石头缝里藏着细细的水声；循声寻到崖壁泉眼，轻轻叩开石缝，一股清泉跳过层层山石汇成月色深潭——上象泉穴、下象涌流，就是「泉」。

## 三、美术、材质、色彩与声音

- **视觉语言：南宋马远《寒江独钓》空寂留白 + 王维诗境的月夜青绿山水。**
  - 纯原生 Canvas 2D 的**多层 2.5D 视差水墨剧场**，零外部依赖；`camCenter(px)` 统一各视差层的投影中心，绘制与命中测试共用同一变换，保证「看到即点得到」。
  - 离屏生成麻纸纤维肌理与暗角；专属配色：夜山玄青 `#0b1420`、泉脉青碧 `#5fc9c6`、月华玉白 `#8fe3d8`、明月暖金 `#f4dfa6`、朱砂印记 `#b5402c`、宣纸米白 `#f6f0e2`。
  - **构图层次**：夜空星子与明月 → 月华斜照光柱 → 远近两重分形山脊与崖顶苍松 → 云雾 → 承载泉眼的披麻皴巨崖 → 岸坡 → 月色深潭与破碎月影 → 三级叠石与粒子水流 → 流萤 → 前景雾 → 宣纸转场 → 字形。
- **声音设计（WebAudio 原生合成，全部与画面事件绑定）**：
  - 夜山空五度持续音（A2/D3/A3 + 低通 420Hz）与山风；寻声水滴与古琴拨弦（每处回声不同音高）；叩泉闷响与石裂；开泉奔涌（带通白噪 + 0.17Hz LFO 调制，`setFlow` 与 `W.flow` 联动）；叠石落水的三声递升滴答；成字与钤印的钟磬；余韵点击的水声与松风。
  - `#mute` 一键全静音；`#pause` 与页面切后台均调用 `Sound.setSuspended()` 冻结整条音频链。

## 五、响应式构图（横竖双幅）

竖屏不是横幅的裁切，而是独立的**立轴构图**，否则崖壁、泉眼与月亮会全部被裁出画外：

- `updateView()` 在竖屏改用 `vw=700`、`SH/1240` 的适配缩放（横幅为 `SH/880` 的覆盖缩放）。
- `VIEW_TALL` 提供六幕独立机位；`MOON_TALL`、`SPOTS_TALL`、`POOL_ROCKS_TALL` 提供竖幅天象与锚点；`moonPoolX()` 收拢潭中月影；流萤分布与钳位随画幅切换。
- `resize()` 切换画幅时同步锚点坐标并**保留已寻得的回声进度**；竖屏字号放大（描红 `GL.s=4.3`、词意 `3.2`）以保证落笔区域足够大。
- 交互提示层 `drawInteractHints()` 独立于景物绘制，排在潭水与雾之后，避免潭面光圈被水色填充覆盖。
