# 听懂、读懂伙伴的颜色请求

作者源：`english-home-practice.json`；目标 red、blue、green、yellow、purple、pink、black、white、brown、grey。每色新增 read／listen 两个普通家园情境，稳定 ID `en-l1-color-<颜色>-read/listen`。橙色 orange 与水果同形，本批不扩大其已有语义范围。

正式场景 S2386—S2405，完整对白见[家园故事集](../story-home-language.md)。当前共744个家园作者情境，听后／读后选择各覆盖43个核心词，家园总体仍覆盖140/180；本批加深已有词的练习，不冒充新增核心词覆盖。

伙伴想为家园搭一个小展览，却需要孩子帮忙选物。开场不说目标颜色，也不展示颜色英文，先说明“根据物品下方的颜色标记选”。读模式显示 `Find something red.` 这样的短请求；听模式必须完整播放请求，之后才接受选择。颜色已经由原跟说／布置故事介绍，未知词不作为听读目标引入。

## 真实选择规则

复用已支持颜色标记的球、杯子、椅子、书、床、桌子、玩具箱、花。至少有一种同类物品带不同颜色标记，比如红书和蓝书。只有红书和蓝杯时不启动这轮独立颜色选择，以免只凭物品种类区分；无标记的对象不能作为颜色干扰物。

所有符合目标的已记录物品都可正确选择，不只接受第一次选中的那一本。目标和干扰物的身份、类型、颜色冻结为当轮快照；改变颜色、删除最后一个目标或最后一个干扰物后，不接受旧结果。名称只是文字，不能替代真实颜色标记。

颜色是物品下方实际渲染的小圆点，不宣称整张贴图已染色。已有标签可能暴露答案，沿用辅助证据检测；听模式帮助显示文字后记为辅助，语音失败可改读线索，但不能取得听力证据。

## 记录与后续

本批只补听读理解机会。选择成功记录在独立 comprehension.read/listen 中，不增加朗读／打字练习次数，不凭听读将第九次表达升级为基本理解。原有有效回执去重、重试次数、首选正确和分技能复习间隔继续适用。

不把两种玩法当成两种生活情境，也不宣称每词已达十二机会或四技能迁移。后续还需让孩子根据不同角色需求自主布置、给别人留下可理解的颜色线索，以及跨会话验证。真人语音、触屏和儿童颜色标记可辨认性仍需实测。
