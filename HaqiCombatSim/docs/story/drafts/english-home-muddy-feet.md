# 泥脚印和泡泡

英语L1家园故事。伙伴讲述自己追影子踩进泥地的经历，孩子先理解dirty（脏），回应后带它实际洗澡，再照顾同一伙伴休息，最后邀请玩球。泥地与脚印是对白中的先前经历，不是当前家园新增的泥污贴图或卫生状态；不修改宠物健康数值，也不因洗澡宣称治疗效果。

三幕：You are dirty. → 浴缸洗澡；You can sleep. → 床上休息；Let's play. → 玩球。最后两幕复习已经学过的sleep/play，未学时由既有准备入口先教学。三幕始终绑定同一宠物。澡盆之外另有淋浴首次和回访；不能用另一只宠物的动作推进原伙伴的故事。

首次dirty的解释放在NPC对白中，先有动机，再有回应和动作。没有责备、清洁倒计时或强迫每天上线。语音可用时鼓励开口，也支持打字。只说对、只展示或错误设施均不计；必须完成对应真实互动。每幕只计明确目标词，不顺带累加bath、feet等词。
