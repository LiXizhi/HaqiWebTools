# 2026-09-24 开发记录

## 降雪不再用同一张灰团

- 雪不再贴天气图集里那一团四瓣雪花。近处画大小不同的六角雪花，远处是更小的白点，各自的下落速度和左右摆动都不一样。
- 沙尘、余烬、薄雾、灰烬和萤光仍用原来的图集。雪的数量仍限制在当前画面最多 64 个。
- 验证：天气图集与地图生成测试通过。寒冰岛北部雪岭预览里能看出大小不一的雪花，不再排成整齐的小点。
- 走进或离开降雪区域时，雪花用约 0.9 秒淡入淡出。同一画面最多两层粒子，各不超过 64 个。


## 地图行走不再周期性顿一下

- 大岛地形瓦片只画进当前格子范围的山、田、河、路和桥，海岸填充仍按整岛形状画，避免每跨过一块就重画全岛。
- 画面里的瓦片已经就绪时，沿行走方向预先准备下一块，且不会挤掉这一帧正在显示的瓦片。
- 走路时的存档和每秒一次的生命/签到界面更新改到下一拍执行。伙伴寻路在刚生成地形瓦片的那一帧先走直线，需要绕路时每帧最多搜一次。
- 暗角、地名牌宽度、天气粒子的固定参数和角色图集裁剪改为复用。NPC 上下缓动仍保留，因为整张地图本来就每帧重画。
- 验证：地形缓存、农田裁剪和伙伴跟随测试通过。浏览器在魔法营地按住右走约 3 秒，帧间隔最大 17 毫秒，没有超过 50 毫秒的停顿。


## 0 费攻击简化演出

- 按卡牌 pipcost 为 0 且类型包含 Attack / LifeTap 选择快速演出，适用于弧光及同类变体，不依赖中文名称。
- 演出时长 550ms，只画从施法者到目标的短粒子轨迹及命中散开；跳过技能主体、卡牌图片、法阵和全屏暗化。其他费用攻击及辅助卡保持原演出。
- 低动态模式保持 500ms，仅在目标处静态闪光；失误粒子只在施法者附近消散。不修改战斗数值、结算或随机数。
- 验证：spell_particle_layers 与 spell_effects 共 9 项测试通过，涵盖全卡库 Canvas 有限坐标及状态平衡、移动方向、无图片绘制、低动态、失误和其他卡牌时长；编辑器诊断无错误。
- 未运行构建，未进行浏览器视觉验收。

## 同时追踪最多三个任务

- 追踪列表最多 3 条，沿用原版 `QuestTrackerPage.max_size`。旧存档里的单个 `trackedQuestId` 在读档时并入这条列表。
- 手记里点「追踪 / 前往接取 / 前往交付」会把该任务放进列表。列表空着时，当前教学任务留在第一条，新任务排在后面。已经满 3 条时不再替换，提示先取消一条。
- 面板上，任务说明点击后追踪这一条。每条目标右侧都有「追踪」。从任务按钮打开手记时，列表停在当前岛屿；点标题才会打开对应任务。详情里可以「取消追踪」；进行中的任务还可以「放弃」。
- 换岛时，如果追踪少于 3 条，自动补上当前岛一条尚未追踪的任务。优先进行中，否则可接取。已满 3 条或岛上没有合适任务时不改列表。

## 任务大全可以放弃

- 教学任务和全岛任务在进行中或可交付时，详情底部增加「放弃任务」。确认后清除进度，并从追踪列表去掉，之后可以重新接取。已完成的任务不能放弃。
