# 余烬猎印与铁匠委托

完成开场冒险、达到8级后，从**装备 → 猎印锻造**进入。营地铁匠莫尼也会提供委托入口。

## 先准备，再挑战

接下铁匠的信，按当前目标前往露水草圃。读材料线索、选择对应材料，采集草药，再到营火制作轻露茶。带着茶赢得一次余烬守卫讨伐，回来寄出回信，可一次性获得80奇豆和2份装备精华。

中文、英文、日文、韩文线索均提供文字选择和提示，不需要成功识别语音。选错材料不会扣资源。接受委托后，草圃每天可免费采集3份草药；完成委托后仍可继续采集。

营火配方“草本轻露茶”使用3份草药／野花，材料不足时可花40奇豆补齐。它提供全队减伤8%、治疗加成15%和战后恢复；效果持续3场胜利，失败不消耗次数。制作其他带角色增益的料理会替换当前效果。生命不足时可在地图等待自动恢复，再决定是否购买补给。

## 选好目标，每次胜利都推进

挑战前可选择想获得的珍品：

| 珍品 | 带来的战术选择 |
| --- | --- |
| 余烬守誓帽 | 全体护盾卡，抵挡蓄力后的重击 |
| 余烬复苏帽 | 低耗治疗卡，在恢复窗口重整队伍 |
| 余烬破势帽 | 全体虚弱卡，削弱敌人后寻找反击机会 |

每次有效胜利必得**35奇豆、25经验、2枚余烬猎印和1顶巡林备用帽**，另有8%概率直接获得选定珍品。直接掉落不清空已有猎印。

40枚猎印可兑换一件指定珍品。从零开始，最多20次有效胜利即可攒够兑换所需猎印，之后在锻造界面选择兑换。失败不会扣除已有猎印。战斗会提供护盾应对机会；留意敌人的招式预告，先应对重击，再把握反击窗口。

## 重复装备和强化都有去处

本区域的巡林备用帽与三款珍品支持分解：普通重复件获得1份精华，珍品重复件获得3份。最后一件、已穿戴、已强化或带宝石的装备受到保护。其他区域装备尚不适用这条回收规则。

| 配方 | 花费 | 获得 |
| --- | --- | --- |
| 仙豆锻造 | 3份装备精华＋150奇豆 | 20仙豆 |
| 魔珠锻造 | 6份装备精华＋200奇豆 | 1祝福魔珠 |

三款不同型号的余烬珍品帽之间，可以花50奇豆继承强化。旧帽须未穿戴且已有强化，新帽须未强化；确认后旧帽强化归零，新帽获得原强化等级，双方装备和宝石保留，不另退强化材料。旧帽正在穿戴时，先完成换装，再办理继承。

资源账本可查看实际收入、支出，以及首次奖励与重复收入。已有库存不会算成新收入。制作前可以先看花费和剩余奇豆，为下一份补给留下余量。
