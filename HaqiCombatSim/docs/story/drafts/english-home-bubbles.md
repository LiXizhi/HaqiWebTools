# 玩球后的泡泡

英语 L1 家园连续故事，作者源 english-home-practice.json。伙伴想先玩球，再洗澡，最后休息。复用家园已有球活动、bathe 洗澡泡泡动画与 sleep 床上休息；目标为 ball、clean、bed，最多三个新词。

1. 伙伴提出一起玩球。介绍 ball，孩子说 A ball.，将伙伴实际拖到球上触发玩法。
2. 玩球后伙伴想洗澡。介绍 clean 是干净，解释 Let’s get clean. 为“我们洗干净吧”。孩子说邀请，再将同一只宠物带到浴缸，实际触发洗澡和泡泡。
3. 伙伴提出休息。介绍 bed（床），孩子说 A bed.，把同一只宠物带到床上。终幕只确认实际休息，不发明新的奖励。

第二、三幕用 usePet:0 锁定最初玩球的伙伴。刷新保留完成步骤与身份，丢失伙伴时走原准备提示。普通 clean 有浴缸和淋浴间各三段首次介绍／复习；不增加点燃、温度或清洁度数值。

clean 的本轮语义是希望变干净，而不是凭空判定宠物原来很脏。当前没有持久化泥污或清洁状态，因此 dirty 保持未覆盖。语言完成要求真实 bathe 动作发生；不能只答一句、把宠物放在水杯旁或等待自动生活动画计数。结尾只说已经开始洗澡，不冒称完整洗浴时长或医学卫生效果。

独立听读识别清洁状态、写作变式、充分跨日重复与儿童试玩仍待完善。没有新增素材或上传。

本地验收：最终ball／clean／bed三幕在1280与390宽度通过，包含错误设施不计、刷新及同宠物身份。完整快速回归1494/1494，故事12/12；手机宽度鼠标操作和测试语音不代替真实儿童验收。
