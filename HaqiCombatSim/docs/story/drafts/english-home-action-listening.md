# 小演员动作口令

walk/run/stand/jump的已学复习。伙伴想为小故事排一个开场，只用英语说一个动作；玩家先听，在走、跑、站、跳四个中文意图按钮中选择，选择正确后还须控制角色完成原有真实动作。没有倒计时，第一次错误可以重听或改读文字。四动作都已学、认识椅子且家园有伙伴和椅子才推荐。

每动作两张独立口令卡，标题不泄露动作；不是新增词首次教学，也不自动随机拼接故事。第一张给小演员安排开场，回访邀请换一个开场。原跑步、散步、站位、跳跃的动作规则不变；按钮选择不代替实际移动或落地。

只有播放完口令后才允许听力选择。语音失败可重试或“改读文字口令”；后者只记阅读，保留有帮助标记，不污染听力复习间隔。选择错误记录重试；场景标签若暴露目标，标记有帮助。先选对再实际完成才记录目标词听读理解，不增加朗读/打字practiceCount，不触发10次basic，不冒充孩子主动说出了英语。

这些任务是已学动作的理解练习，不能据此覆盖listen、say或speak三个词。固定口令卡仍需更丰富情境与延迟迁移，不能仅凭配置认定独立四技能或L1通过。

作者源english-home-practice.json，八张卡S2571—S2578。当前899家园情境、165家园目标、59岛屿目标；听力作者供给62词，阅读58词。首次介绍数量不增加。

作者/边界定向12/12；运行时改动完整战斗回归1531/1531，新增两项口令边界随后单独通过。故事导出/check、Python12/12、课程检查通过。四动作各1280/390浏览器验证听前点击无效、walk错选后重试、run语音失败转阅读、只选择不计、实际行动后理解计一次、原practiceCount不变、刷新保留。run回退不产生listen记录。

首轮浏览器因测试夹具把异步初始化放进同步回调而未启动，修正夹具后重测通过；不能把该失败说成通过。浏览器语音为替身、实际行动由鼠标控制，未验证真实语音自然度、触屏和儿童听懂比例。选择中文动作意图及固定卡片可能提供线索，仍需新情境迁移来证明掌握。
