# 森林营地急件：英语寻物与巡逻（2026-11-13）

## 玩家追求与产品区分

玩家应带着目的走进森林：读懂一个短线索，亲手找对物品，把物品带到需要它的人身边，获得能穿戴的装备，再学会一种战术去完成巡逻。英语帮助玩家理解物体、位置和行动，战斗检验准备是否有效；不能只有读长对白或领取奖励。

本章围绕“营地委托、现场寻物、任务物品携带、NPC递交、战术备战与巡逻实绩”展开。避开《山海灵语》的成语情境、伙伴奇遇/羁绊、调查救援和场景修复主轴。不以收集材料修建筑、抽取伙伴或收卡演出作为主要奖励。拖放、按钮和基础对话是通用操作，区分来自任务的目的、内容和后果。

## 首段：营地急件

- 类型：可选的营地 NPC 支线，进入世界并完成已有开场后可接；不阻断原主线。旧存档没有新增字段也可继续。
- 人物与地点：使用已有莫尼（36201）、茜茜（36200）、营地帐篷/学院建筑与石头美术。帐篷补给点、路线桌是 Web 新增可交互地标。
- 节奏：接单 → 帐篷寻靴 → 把靴子交给茜茜 → 比较/穿戴回礼 → 挪开石头取便签 → 确认巡逻 → 可选借卡练习 → 正式副本 → 归还便签领奖。
- 英语难度：短句与具体实物对应；可听线索、主动展开中文帮助。英语读写、语音识别和付费课程均不作为主线门槛。
- 任务物品：待送达的巡逻靴、路线便签放在单独委托袋，不混入可卖出/穿戴的正式库存。确认路线后保留便签供巡逻；汇报后才归还。

## 奖励的来源、用途和边界

送达先给本学派靴子：冰1256、死1257、命1258、风暴1259、火1260，实际模板增加20最大生命。完整巡逻后给5级背部披风：火舞1415（40生命）、霜冻1416（54）、激电1417（32）、袭魂1418（45）、碧波1419（48），各加4%本学派攻击。独立背部槽可与主线帽子、法袍同时穿戴，避免正常升级后奖励退化为重复补偿。必须手动穿戴才影响下一场战斗；预览展示真实属性差值与可能的卡组容量影响，不自动替玩家换装。使用原导出物品及现有图集，不添加虚构属性。

已经持有的同件装备每件转为200奇豆；两次回礼最多两件，不能反复交任务刷物品。完成增加“营地补给员”荣誉。巡夜灯原有的首次完整通关口袋奖励独立结算，不把它重复包装成委托另送一份。当前没有真正的服装外观管线，装备图标、属性比较和称号不能算作角色换装。

借卡练习不消耗或赠送正式卡牌。课堂可演示2对2、4对4职责，但本段巡夜灯是允许单人完成的副本；不能把课堂阵容或伙伴队伍称为真人多人。

## 可继续扩展，但尚未实现

1. 后续委托用两条短英语线索决定物品、位置或投递对象，让玩家在实景中摆放/递交；不要只增加选项题数量。每个错误动作应有具体、可逆的世界反馈。
2. 建筑逐步成为有用途的地点：补给帐篷负责装备来源，路线桌负责巡逻信息，训练点负责战术练习。避免仅更换地图皮肤，暂不以修复建筑为章节目标。
3. 中期正式2人/4人挑战需要可获得的伙伴、卡牌、装备和等级路线；先验正常养成的首通，再设计更少回合、保护队友等真实成绩目标。
4. 奖励形成可预期的系列：确定来源的功能装备、可见的纪念物/称号、能改变搭配的卡牌或伙伴。外观换装需独立核查美术与角色渲染，不用随机金币堆砌获得感。排行与公会等真实用户进入后再接，单人先比个人最佳。

## 实现与验收边界

`forest_commission_core` 管状态、距离、一次性奖励与可选云字段；`view_forest_commission` 管实物交互和意图；`adventure_scene_drag` 统一拖动阈值、指针取消与落点；应用层负责事务保存、角色身份和课堂返回。世界地标与NPC反应由同一保存状态派生。

首次“boots”选物只记录辅助阅读练习，保留实际尝试次数。默认追踪和NPC气泡不直接报答案，但物品无障碍标签、奖励上下文、错误反馈和可选中文帮助仍会提供支持，不能冒充独立回忆、口语或掌握。被动阅读的词树观察和明确提交的练习分开，保存失败可以重试；不另建学习进度库。

委托完成后按真实等级给下一步：未到6级先继续主线，到6级准备「走失的火种」2对2挑战。正式组队由玩家控制主角、伙伴AI出牌；「对白与表情」里的「我在憋大招」「给我加血」只在下一次决策提出强化/保护或治疗请求，仍受手牌、费用和目标限制，不承诺指定伙伴必出某张牌。

自动检查覆盖五学派真实装备属性、现场距离、取消/多指/错落点、选错物品、旧存档/云恢复、重复奖励、保存失败、NPC与场景反馈。四个固定种子共40条路线从1级自然推进到真实四波巡逻；40条路线均继续升到6级，使用实际获得的伙伴完成2对2挑战；旧角色通过既有编队操作让抱抱龙独立出战。伙伴使用正式当前AI，组队战中途云恢复保留行动、生命与状态。这些路线使用推荐卡组和自动策略，不证明全部种子、新手配卡或中后期难度已平衡。浏览器布局、触屏手感、配音效果与“是否好玩”仍需真实试玩，不能用这些测试代替。
