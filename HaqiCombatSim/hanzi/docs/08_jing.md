# 08 · 径（`jìng`）—— 曲径通幽（`hanzi_jing.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：径；拼音：`jìng`；本义：小路，步行的小道。
   - 《说文解字·彳部》：“径，步道也。从彳，巠声。”本页只引用“径，步道也”。
   - 引申：径直（直接向前）、直径（穿过圆心的直路）、大相径庭（相差很远；尾声只呈现前两组，“径庭”不向低龄儿童展开）。
2. **字形结构（规范楷书，8 笔）**
   - 左部「彳」`chì`：与行走、道路有关，是全字的意义线索；三笔——撇、撇、竖提。
   - 右部「巠」`jīng` 的简写形：是全字的声音线索，与“径”读音相近；五笔——横撇、捺、横、竖、横。其下半“三横一竖”如田间小路穿过田埂，为帮助记忆的画面联想，字幕与注释明确标注“画面是联想”，不冒充字源事实。
   - 笔顺与轮廓取 Make Me a Hanzi（Arphic Public License）「径」的轮廓与中线（1024 字框，基线 900），与 `hanzi_men.html`、`hanzi_ren.html` 的描字坐标约定一致。
3. **事实与艺术边界**
   - “曲径通幽”出自唐代常建《题破山寺后禅院》“曲径通幽处，禅房花木深”。本页将其改编为孩子走竹林小径、抵达安静小亭的旅程，并在尾声注明出处，不把诗句说成字源。
   - 竹叶交错比作右上两笔、田埂比作下半三笔，均为现代艺术联想；页面左下角保留说明：“左彳右巠是字形线索；竹林画面为艺术联想，书写使用规范字形。”

## 二、一句话主题

> 竹林里本没有现成的路，孩子踩着青石一步一步走，弯弯的小径在脚下长出来，通向雾后一盏灯、一座小亭——路，是走出来的。

## 三、美术、色彩、构图与声音

- **视觉语言**：青绿水墨竹林。深竹青 `#16382c`、苔绿 `#4a7a5c`、雾白 `#eef3e6`、青石 `#7d8b84`，只在小亭灯火与成字朱印处使用暖琥珀 `#e9a954` 与朱砂 `#b04a32`。全片如一幅缓缓展开的长卷，不用艳色，不用圆角卡片堆叠。
- **构图**：世界坐标宽 `0..2400`、高 `0..1100`；一条 S 形石径自右下入林、向左上盘升，穿竹桥、过小溪，止于左上高处的小亭。镜头 `VIEW`：`intro`、`gate`、`path`、`bridge`、`pavilion`、`glyph`、`finale`，竖屏用 `pw` 缩窄视场，保证孩子、下一块青石、字形与描红区同屏。
- **光影叙事**：清晨薄雾压林，越往前走，雾越淡；抵达小亭时灯火亮起，林梢透出金色晨光。走过的青石逐块泛起微光，身后留下一条看得见的“来路”。
- **声音（WebAudio 合成，零外部音频）**：低五声音垫（宫调式 `G3, D4, E4, A4, B4, D5`）；踩石的轻叩声按音阶上行；竹叶摩擦的带通噪声；溪水低通噪声；抵达时一记清钟与灯火的暖和弦。由“开始”按钮手势解锁，支持静音与暂停。

## 四、分镜（七段 · 约 2–3 分钟）

| 进度 | 场景 | 画面与字幕 | 互动 |
|---|---|---|---|
| 片头 | `introPlay` | 雾林长卷上，毛笔逐笔写出「径」，竹叶轻晃 | 点击「开始」进入正片；片头不发 `written`/`completed` |
| 入林 | `sGate` | 竹门半掩，林间无路，只有落叶与第一块青石。“竹林里，藏着一条小路。”“小路在哪里呢？” | 观看，建立悬念 |
| 曲径 | `sPath` | 孩子立于林口，S 形石径隐没在竹影里 | **互动 1（踩石寻径）**：依次点亮 6 块青石（或按按钮“向前走一步”，支持空格/回车），孩子逐块走近，石上亮起脚印光，弯曲的来路在身后连成线；12 秒无操作自动向前一步 |
| 通幽 | `sReveal` | 石径尽头被垂竹与薄雾遮住，只透出一点灯火 | **互动 2（拨竹见亭）**：按住并横向划动（或按住按钮“拨开竹叶”）拨开竹帘，雾散、灯亮，小亭与小溪显形；9 秒无操作自动拨开 |
| 成字 | `sGlyph` | 宣纸淡入；来路的光点收拢，先写「彳」三笔（朱砂，标注“彳 · 与走路有关”），再写右部五笔（墨色，标注“巠 · 声音的线索”），合成「径」；引用“径，步道也” | 观看；部件分色拆解，不把竹影说成字源 |
| 写字 | `sWrite` | 8 笔描红：起点光点、虚线轨迹、终点箭头，逐笔计数“第 N 笔，共 8 笔” | **互动 3（八笔描字）**：从起点沿虚线描，偏离温和退回重描；“看示范”逐笔演示；超时自动示范。完成瞬间发 `written` |
| 余韵 | `sWords`、`sFinale` | 「径」下依次点亮三组词：`小径`、`径直`、`曲径通幽`（注明唐·常建诗句）；字形融回竹林，孩子在亭中挂灯，走过的路在身后发光 | **点竹林**唤起竹叶轻响与落光；进入尾声发 `completed`；“再看一次”重播 |

## 六、协议、多语言与验收

- `<head>` 内联 Haqi H5 Protocol v1：独立打开无父窗口不报错；`ready → init → translate → written → completed` 与既有页面一致；字幕走 `haqiHanziCaption` 双语同显，UI 走 `haqiHanziUi` 单语切换。
- 新增中文文案补入 `data/adventure/locale/en.txt`、`ja.txt`、`ko.txt`；在 `hanzi_index.html`、`js/adventure_dictionary.js` 的 `localAnimations`、`js/hanzi_story_animations.js` 登记 `hanzi_jing.html`。
- 验收：桌面 1440×900、手机竖屏 390×844、横屏；`?fast` 加速、`?auto` 自动完成互动；`window.__jing` 暴露场景、互动记录与 `pose()` 供无头截图；减少动态效果、静音、重播均可用；0 外部请求（字体/音频均为系统与合成）。
