# 给故事家人的小画与邀请

英语 L1 家园作者故事，已接入 `english-home-practice.json`。新增七篇三幕作品故事及28个书本留言／邀请座位练习，覆盖 mother、father、brother、sister、grandmother、grandfather、family。sister 原先已有练习，故新增六个核心词的家园覆盖。岛屿衔接见 [一张变长的邀请](en-town-family-invitation.md)。

正式导出场景 S2326—S2374，逐故事 ID 对应 [家园作者故事集](../story-home-language.md)；完整对白维护在 JSON 作者源，不手改生成集。

## 故事里的愿望

每篇由伙伴先用 NPC 对话讲清具体原因，孩子再说短句并动手；不在对话框塞作者说明。

| 故事 ID 后缀 | 标题 | 给孩子的创作理由 |
| --- | --- | --- |
| mother | 给妈妈的小画 | 故事里的妈妈忙了一天，留一幅休息时可以看的画 |
| father | 给爸爸的小画 | 爸爸好奇今天玩了什么，画一件自己喜欢的事 |
| brother | 给兄弟的小画 | 兄弟还没猜出想玩的游戏，画一条线索 |
| sister | 给姐妹的小画 | 姐妹想听故事，画一个开头让她猜后续 |
| grandmother | 给奶奶或外婆的小画 | 把她讲过的故事中喜欢的一幕画下来 |
| grandfather | 给爷爷或外公的小画 | 他想了解你的家园，画出自己喜欢的角落 |
| family | 给家人的小画 | 家人喜好不同，画一件大家可以一起做的事 |

以上人物和偏好都是可选的故事设定，不是对玩家真实家庭或不同亲属的固定描述。入口明确可以选择虚构人物，不要求真实姓名或家庭资料。画面内容、颜色和细节由孩子决定；不根据画作判断家庭关系或认定画的是哪位亲人。

## 三幕实际操作

连续故事 ID 为 `en-l1-picture-for-<后缀>`，每篇步骤固定为 `-paper`、`-draw`、`-label`。

1. 先认识／复习 paper，说 `Some paper.`，点击真实画纸。
2. 认识／复习 draw，说 `I can draw.`，在同一张纸实际画出并保存新笔画。空白、取消、相同保存不计。
3. 介绍一个明确亲属词及 `For my …` 意义；写 `For my mother.` 等短句并保存到同一幅作品。没有已保存画作不能进入签名练习，写错收件人不算本轮成功。

最多三个新词，沿用共享会话预算。纸和画法已有学习记录时作为复习，不重新假定为新词。作品留在真实家园物品上，可重开与修改；结尾明确未替玩家送到别人那里。这里是有示范的收件人写作和自由绘画，不能称作自由英语写作已通过。

## 四个普通复习情境／每个称呼

`en-l1-family-<word>-book-meet/review`：选择书，写短句给故事收件人，标签保存在书上；书留在原处，不虚构赠送。

`en-l1-family-<word>-seat-meet/review`：伙伴扮演客人，询问还邀请谁；孩子说 `My mother.` 等，随后实际让伙伴坐下。对话和坐下分别验证，不会召来虚构家人。meet 先解释词义，review 面向已学词复现。

这四轮不是十二次有效掌握机会，已有标签原样保存也不增加练习次数。以共享 WordTree 回执计数，10次只提高本地基本理解，不授予四技能通过或掌握奖励。
