# 08 · 西（`xī`）—— 小雀回家（`hanzi_xi.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：西；拼音：`xī`；常用义：太阳落下的方向。
   - 《说文解字·西部》：“西，鸟在巢上。象形。日在西方而鸟栖，故因以为东西之西。”页面只引用“西，鸟在巢上。象形。”，后半句改用孩子能懂的话转述：“太阳落到西边，鸟儿就回巢歇息。”字幕说明这是《说文》的讲法。
   - 词语：西边、东南西北、西瓜。
2. **古文字演进**
   - **甲骨文 / 金文**：多写作一只编织的鸟巢（或篮筐）形，有外框和交叉的编纹。页面的甲骨文示意为：上方一根枝条、左右两道巢壁、圆底、里面两道交叉的编纹。
   - **小篆**：《说文》所收字形上部弯曲，许慎解释为“鸟在巢上”。页面示意为：上方枝条化为一只弯身的鸟，下面是更规整的巢。
   - **楷书**：六笔——横、竖、横折、撇、竖弯、横。下部方框是巢，里面的撇和竖弯对应巢里的编纹（艺术示意）。
3. **笔画数据**
   - `data/adventure/hanzi/strokes.json` 尚未收录「西」。页面内联的轮廓与中线取自同一来源、同一提交：`skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（已核对该提交中「目」与 `strokes.json` 逐字节一致）。1024 字框，基线 900。不改 `strokes.json`：它是游戏运行时数据，并由字源岛内容校验。
4. **事实与艺术边界**
   - 小雀、雀妈妈和补巢是创作故事。鸟巢变成甲骨文、鸟落巢上变成小篆，以及楷书各笔与巢的对应，都是艺术示意。左下角保留说明：“古字形为艺术示意；故事为原创”。
   - “鸟巢表示西”的解释出自《说文》，字幕写明出处；不说成唯一定论。

## 二、一句话主题

> 太阳落山的时候，鸟儿都往家飞；小雀跟着太阳一路向西，和妈妈一起补好被风吹散的巢——太阳落下、鸟儿回巢的地方，就是「西」。

## 三、美术、色彩与声音

- **材质：层叠剪纸的黄昏。** 远山、近丘、芦苇、村庄和大树都是带纸边的剪影层：每层顶边有一道浅色纸边高光，下方有一层柔和投影，像一张张剪纸叠在一起。整帧叠纸纹（`multiply`）与暖色暗角，区别于《目》的宣纸水墨与《光》的暗夜火光。
- **时间推移即色彩叙事**：`W.sunT` 从 0（傍晚金色）到 1（日落）再到 2（入夜）。天空渐变从杏黄、珊瑚、玫瑰紫，推到靛蓝；山层从暖棕红逐层加深到梅紫。太阳是一枚大而低的暖色圆盘，带呼吸光晕，河面上有一条碎金倒影。
- **太阳在无穷远处**：太阳按镜头中心偏移绘制（视差为 0），镜头平移时太阳不动、山层按视差移动；成字时把太阳偏移调到鸟巢正后方，让巢的剪影压在落日上。
- **小雀**：程序绘制的剪影小鸟——圆身、圆头、短喙、翘尾，翅膀按 `flap` 相位扇动；朝太阳一侧有一道橙色轮廓光。雀妈妈稍大，胸口一抹暖色。
- **鸟巢**：直接按甲骨文示意的六条路径绘制成一束束弯曲的细枝，每补一根，就沿路径一根根编上去。所以成字时，巢与甲骨文天然重合。
- **沿途**：芦苇荡、小河、远处一字排开回家的雁阵、村口炊烟与亮起的窗灯，都在说“傍晚回家”。
- **声音（WebAudio 合成）**：温暖五声音垫；拨弦；小雀啾啾（短促上滑高音）；扇翅（短促带通噪声）；补巢（木枝轻敲）；入夜时远处一声钟和虫鸣。

## 六、协议与验证

- `<head>` 内联 Haqi H5 Protocol v1。片头 `introPlay` 不发 `written` / `completed`。
- `?fast` 加速、`?auto` 自动完成全部互动；`window.__xi` 暴露场景、事件与坐标换算。
- 验收：桌面 1280×800、手机竖屏 390×844、横屏 844×390；`?auto&fast` 事件顺序为先 `written` 后 `completed`；减少动态效果；静音；重播。
- 「西」不在字源岛 30 字词典内：只加入 `hanzi_index.html`、三种语言词条与测试，不写 `zh.json` 与 `localAnimations`。
