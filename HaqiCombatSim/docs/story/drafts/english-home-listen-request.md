# 先听清，再找道具

listen（听）的家园首次教学和复习。伙伴想准备一个小故事，选择书、球和杯子，一次只说一个请求。孩子先学并表达I can listen.或Let me listen.，再播放伙伴的真实请求，从当前家园物品中点选目标。三幕只有listen是明确练习词，book/ball/cup须预先认识，不顺带给它们加次数。

每种物品另有首次及回访各一变式。必须有至少一种不同物品作为可辨认选项；只有唯一目标物品时不开始。说对listen回应后，也不能直接点目标完成，须播放完请求或显式改读文字；错误物品、未听/未读、对象删除及过期会话不计。

这轮计的是明确的listen词语表达及响应请求的完整互动，不是独立listen听力考试。语音失败可以重试或改读文字，后者有帮助标记且不创建听力证据；不会逼迫孩子开麦。回执仍按自己的回答方式记speech/text；仅试听不计有效练习，也不把请求中的book等词假装成已练。

找出道具不等于已搬动、已读书、已玩球或已喝水；结尾明确物品留在原位，后续布置和宠物互动由孩子实际做。尚需listen岛屿教学、更多句型与跨日情境、独立四技能和儿童试玩。say/speak仍不因本玩法接入而算已教。
