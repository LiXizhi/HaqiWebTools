# 07 · 目（`mù`）—— 画龙点睛（`hanzi_mu_eye.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：目；拼音：`mù`；本义：眼睛。
   - 《说文解字·目部》：“目，人眼。象形。重童子也。”页面只引用前半句“目，人眼。象形。”
   - 引申：看（目光）、要看准的地方（目标）、给大家看的表演（节目）。
2. **古文字演进**
   - **甲骨文**：一只横放的眼睛，外为眼眶，中间圆圈或圆点为眼珠。
   - **金文 / 小篆**：字形竖起，外轮廓变长，眼珠写成中间两横。常见解释是竖写更适合竹简直行书写；页面用“后来，眼睛竖了起来”叙述字形变化，不把竖排原因当作定论。
   - **楷书**：五笔——竖、横折、横、横、横。外框是眼眶，中间两横是眼珠。描红使用 `data/adventure/hanzi/strokes.json` 的「目」轮廓与中线（1024 字框，基线 900）。
3. **事实与艺术边界**
   - 「画龙点睛」出自唐代张彦远《历代名画记》中张僧繇的传说：画龙不点眼睛，点上就会破壁飞去。本页改编为一个孩子替老画师点上一只眼睛，字幕标明“传说”。
   - 龙眼化作甲骨文、竖起成小篆、再成楷书，是艺术示意；三个阶段的背景分别是龟甲、竹简和宣纸，用来提示书写材料的变化。左下角保留说明：“古字形为艺术示意；故事改编自画龙点睛的传说”。

## 二、一句话主题

> 一条没有眼睛的墨龙，被孩子点上一笔眼睛；它睁开眼，看到哪里，哪里就有了颜色——眼睛让世界“活”过来，这就是「目」。

## 三、美术、色彩与声音

- **材质**：全片为宣纸水墨。底色为生宣暖白 `#efe6d2`，墨色分焦、浓、淡三层 `#1b1916 / #3b3a36 / #8d887c`，朱砂 `#b8432c` 只用于印章、龙舌与孩子的发带。整帧最后叠一层纸纹（`multiply`），让人物、龙和字都像画在同一张纸上。
- **色彩叙事**：开场只有墨色。龙看见山，远峰染上青绿 `#5f8f7a`；看见水，溪流化为石青 `#4f8fae` 并开始流动；看见天，天空显出淡蓝、云边镶金。三处都看过后，松树和屋瓦一起上色。
- **龙**：程序绘制的水墨龙。头部有鹿角、鬃毛、长须、张口与朱砂舌；身体由“蛇形跟随”轨迹生成，墙上的画与飞起的龙是同一条轨迹：头一动，身子就顺着头走过的路从墙里游出来，墙上只留淡淡墨痕。
- **眼睛**：点睛前是空白杏眼；按住时墨点在宣纸上晕开（不规则边缘与淡墨晕圈）；睁眼后金色虹膜、黑瞳与高光出现，瞳孔跟随手指。
- **构图**：世界坐标宽 `0..2400`、高 `0..1000`；寺墙 `x 300..2150`，龙头在墙右下，孩子站在龙头右侧。镜头 `VIEW`：`intro`、`wall`、`dot`、`gaze`、`fly`、`finale`，竖屏用 `pw` 缩窄视场，保证龙头、孩子、三处目标与字幕同屏。
- **声音（WebAudio 合成）**：低沉五声音垫；拨弦（古琴感）、钟磬；墨滴声（下滑正弦加短噪声）；风声与远雷（低通噪声）；目光落到目标上时一声清亮的钟。

## 四、分镜（七段）

| 进度 | 场景 | 画面与字幕 | 互动 |
|---|---|---|---|
| 古寺 | `sWall` | 镜头从龙尾沿墙推到龙头，龙随镜头被一笔笔画出。“传说，很久以前，有位老画师在寺墙上画了一条龙。”“可是，这条龙没有眼睛。”“老画师说：点上眼睛，它就会飞走。” | 观看 |
| 点睛 | `sDot` | 老画师把笔递给小墨，小墨伸笔够到龙眼。 | **按住**屏幕或按钮，把墨点进眼睛；松手墨不消失，按满为止；9 秒无操作自动完成 |
| 睁眼 | `sGaze` | 墨点一亮，龙眼睁开。“它想看看这个世界。” | **移动手指**，龙的目光跟着走；让目光停在山、水、天三个光圈上，各自染上颜色。按钮“让龙看一看”逐个引导；闲置后自动 |
| 飞龙 | `sFly` | 风起雷动，龙从墙里游出，绕山飞上天空；墙上只剩一片白。龙回头停在小墨面前，镜头推向它的大眼睛。 | 观看 |
| 成字 | `sGlyph` | 纸色淡入，龙眼的眼眶与眼珠被墨线描出 → 龟甲上的甲骨文「目」（横眼）→ 旋转竖起，背景变竹简（小篆）→ 宣纸米字格上的楷书；标注“眼眶”“眼珠”。引用《说文解字》。 | 观看 |
| 写字 | `sWrite` | 五笔描红，起点光点、虚线与箭头；偏离温和提示；“看示范”。 | **描字**；全部完成后发 `written` |
| 余韵 | `sWords`、`sFinale` | 目光、目标、节目三词；回到上色后的山水，龙在天上游。“眼睛睁开，世界就有了颜色。” | **点天空**，龙飞去看那里；进入尾声时发 `completed` |

## 五、协议与验证

- `<head>` 内联 Haqi H5 Protocol v1。片头 `introPlay`（大眼睛跟随指针眨眼）不发 `written` / `completed`。
- `?fast` 加速、`?auto` 自动完成全部互动，便于无头浏览器验收；`window.__mueye` 暴露场景、事件与坐标换算。
- 验收：桌面 1440×900、手机竖屏 390×844、横屏 844×390；减少动态效果；静音；重播。
