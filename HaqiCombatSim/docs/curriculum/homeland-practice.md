# 家园：完整词表的反复使用与 Level 进阶

更新：2026-10-26。本文区分教学规格与已接入部分；下方实施增量记录本地进展，不代表完整课程已经交付。返回[总纲](README.md)。


## 当前决策：用家园承担练习量，而不是延长岛屿对白

岛屿故事结束后，把已教目标交给家园复习队列；角色下次回家，优先继续相关生活故事。推荐任务写成“帮伙伴准备野餐”“把阅读角布置好”，不写成“再刷十二遍 apple”。孩子可以选活动、结束或自由搭建，系统负责防止某些词长期漏练。

### 当前覆盖快照与下一批交付

以下按本地作者配置核对；历史增量中的旧数量仅代表当时状态。

| 指标 | 当前状态 | 完成条件 |
| --- | --- | --- |
| 英语 L1 核心词 | 180 个规范词条 | 每词有明确教学入口、理解／表达目标 |
| 家园作者情境 | 1000 个，涉及 180 个唯一目标词 | 情境总数不能代替逐词覆盖或熟练度 |
| 尚无家园作者情境 | 0 个核心词；仍未完整验收整级 | 每词至少一种能真实执行的玩法，再扩充变式 |
| 每词重复供给 | 尚未逐词达到标准 | 至少 12 个使用机会，编排到 4 次会话、3 种生活情境 |
| L1 到 L2 准备度 | 尚未实现与教学验收 | 延迟回忆、新情境使用及四技能出口证据；不靠剧情完成数 |

逐词供给以[自动生成报告](en-l1-coverage-report.md)为准。运行 `npm run curriculum:audit` 更新报告，`npm run curriculum:check` 检查报告是否过期及词条引用是否失效、重复或遗漏。命令通过仅代表报告与作者源一致，不代表课程完成。当前只有11词具备至少12个不同家园作者机会；岛屿明确目标覆盖94词，独立听后选择63词、读后选择59词，标签写作70词。四次会话、三种生活情境不能按故事ID或玩法数自动推断，仍需逐词设计和验收。

下一批内容按缺口选择，而非继续堆容易生成的数量变式：先让缺失的词拥有真实玩法；再按词检查是否只有跟读、只有同一情境或没有独立表达。遇到玩法缺失，记录所需动作，不用一句 NPC 台词冒充动作已实现。

每轮迭代交付一组可玩的连续家园故事，同时更新逐词账本：目标词、首次教学、前置句型、生活情境、听说读写方式、提示程度、真实动作、复习窗口、验收证据。更换数字或物品颜色可以增加练习，但不自动算新的生活情境。RSI 依据这些缺口提出下一轮工作；只改文案或增加数量不能把“未验收”改成“完成”。

### 一次回家的编排示例（设计，需试玩校准）

以孩子已经学过食物和简单请求为前提，先由伙伴提出“想准备一个野餐角”的愿望。安排约 6—10 次短互动，每次明确练 1—3 个目标词，以复习为主：听请求选食物、读标签找饮品、自己说需要什么、实际摆放、写一个标签。完整答案先隐藏，遇到困难再给关键词或示范；不能把帮助过的回答记为独立成功。

下一次回来可以清点野餐物品；更晚换成收拾厨房或寻宝，再使用相同词。这些后续剧情和动作须分别实现与审核。一次成功不取消后续复习，一次失败也不清空旧进度。若某种玩法只覆盖少数词，推荐其他可玩活动补齐，不能为了服从当前玩法而永久忽略其他词。

孩子可以继续探索 L2 的岛屿；课程推荐是否转入 L2，以本页准备度规则为准。尚不稳定的 L1 词继续随家园活动出现，不要求重玩已经会的整级内容。

## 岛屿引入，家园练熟

岛屿故事提供第一次认识词语的理由；家园是主要练习场。完成几个岛屿任务不能直接升级。每一级先建立完整核心词表，再给每个词安排首次教学、家园反复使用和迁移任务。现有单元的十二个种子词只是举例，不能作为整单元的全部教学量。

英语 L1 以约 180 个核心词／固定语块作为首轮内容设计目标，处于既定 150—250 的预算内；[180 词清单](en-l1-vocabulary.md)现已登记来源位置和 WordTree 身份，语义在具体故事中的教学仍须复审。这不是已完成课程，也不是 Cambridge 官方词数或学习效果保证。其他语言各自选词，不逐词翻译英语清单。

词表按人物、家居、位置、物品、动作、饮食、身体、感受、颜色、数量、动物及礼貌交流组织。高频功能词通过可理解的句型反复学习，不能藏在“辅助词”里而从不教。每个词标明理解目标与表达目标；不是所有词都要求相同次数的拼写。

每个短场景引入 2—4 个新词。故事数量随完整覆盖需求增加，既有每单元三个主故事是组织框架，不是内容上限。可拆成多次短委托；不能把 60 个新词塞进一段开场对白。未在岛屿引入的词，可以由家园来客的完整小故事首次教学，必须同样登记作者稿、目标和词条。

## 重复量怎样落实

首轮内容预算：每个核心词准备至少 12 个有效使用机会，分布于至少 4 次会话和 3 种情境；对需要主动表达的词，其中至少安排 2 次无完整答案的主动使用。这里的 12 次是内容供给底线，不是孩子答对 12 次就掌握的判定。

以 180 个词估算，需要至少 2165 个“目标词使用机会”。一次短任务若真正验证两个目标词，可以提供两个机会；句子里顺便出现的其他词不算。可以通过受约束的场景组合提供变式，不要求写 2160 篇故事，也不能用无限随机对话代替覆盖账本。

| 阶段 | 家园中的体验 | 教学记录 |
| --- | --- | --- |
| 认识与模仿 | 宠物表达需要，孩子听示范、跟说并操作 | 有支持的有效练习；播放不计 |
| 回忆 | 同次稍后换一个对象，再提出相似请求 | 是否依赖提示；不能连点同题刷证据 |
| 隔次复习 | 下次回来再次使用，再逐步拉开间隔 | 距上次练习的时间、结果与支持程度 |
| 迁移 | 换来客、摆放或需求；孩子读／听后解决 | 新情境理解、说写分别记录 |
| 创作 | 孩子决定布置、邀请或游戏规则并表达 | 信息是否被理解，实际动作是否完成 |

暂定复习窗口为同次稍后、下一次会话、约 3 天、7 天、14 天；这只是可调初值。答错或需要整句答案时缩短间隔、降低负荷；稳定独立成功时延长。缺席后只给适量回顾，不积压“欠作业”，不清空进度，不以连续登录维持等级。

## 家园中的故事与游戏

先让 NPC 或宠物提出具体需要，再进入互动。任务面板显示目标和下一步，不作为做题页面；情境描述不放进角色对白。下面均为需接入真实动作的设计，不宣称现有家园已经能接待来客、处理邀请或完成所有物品操作。

| 活动 | 孩子为什么要交流 | 变化与重复 |
| --- | --- | --- |
| 照顾宠物 | 弄清是渴、饿还是困，选择对应设施 | 换宠物、需求和设施位置；从跟说到自己问 |
| 藏物与寻宝 | 听懂或读懂线索找到物品，再轮到自己出题 | 换物品、颜色和位置；必须有可验证的位置关系 |
| 为朋友准备角落 | 问清喜好，选物并实际摆放 | 同一家具用于休息、阅读或招待；孩子有选择权 |
| 野餐和来客 | 读清单、问需要、分配份数、留下便条 | 来客和需求改变，旧词在新问题中复现 |
| 小小导演 | 安排宠物先后动作，给场景写标签或台词 | 保存作品、再修改；不强制写统一答案 |
| 宠物当老师 | 宠物给指令，之后孩子给指令或纠正误会 | 轮流听说；可请求重复、拒绝不合适的动作 |

例如 `water`：故事里理解水边线索 → 家园给渴的宠物取水 → 来客时说 “Water, please.” → 野餐前读清单拿对饮品 → 自己留下 “Bring water.” 的便条。不是所有例句都在第一天出现；结构必须先教。听音选对象、照示范说、独立写便条分别提供不同证据。未实现取水或便条消费逻辑前，只能标为内容提案。

## 每次回家怎样安排

给孩子两三个具体活动选择，例如“陪宠物找球”或“布置阅读角”。孩子选玩法，系统把适合该玩法的待复习词放进故事。建议一段约 5—10 分钟，可随时结束，也可继续自由创造；时长由试玩调整。

首轮调度配比可从 60% 到期复习、30% 最近新词、10% 熟悉词轻松回顾开始。不强行凑比例，当前场景没有可验证动作就换活动。每轮明确练 1—3 个词；新词尚不稳定时暂停增加生词。

选择优先级：已教但从未有效练习的词 → 到期且容易忘的词 → 缺某种技能／新情境证据的词 → 最近新词 → 熟悉词。需要同时限制连续重复同一个词，并提高长期未练词的优先级。不能一直取最近练过的三个词，让其他词永远没有机会。

AI 接收已选目标、熟悉表达、当前真实物品／动作、故事状态及提示等级，生成短而自然的变式。选词与完成判定由游戏负责。AI 失败时提供经过审核的作者变式或保留重试与自由家园；不能换成未学词或虚构动作。

## 将重复预算做成可交付的家园内容

以下是新增实施规格，尚未接入调度。一个词不能因为有一个故事引用就标记“家园覆盖完成”。每个词的覆盖账本须列出至少 12 个可执行机会的场景、动作、技能、提示程度和复现条件；运行时另存孩子实际完成的证据。两张账不能混为一谈。

以需要主动表达的物品词为例，四次会话安排如下。会话表示不同次实际学习，不是反复关闭窗口；后三次应按复习窗口分散，不要求连续登录。这是作者编排模板，孩子答错时可以多练，已有基础时可用诊断证明能力。

| 会话 | 三个有区别的使用机会 | 提示如何减少 |
| --- | --- | --- |
| A：认识并使用 | 听示范后说出需要；读物品标签找对对象；同次稍后回应伙伴的同类需要 | 首次可给完整示范，之后先让孩子回忆；第一次答错保留帮助 |
| B：隔次回忆 | 听请求选物；自己提出请求并完成动作；关掉示范后写一个物品标签 | 听任务不先显示文字，表达先给意图或图片 |
| C：换场景运用 | 读不同需求的小清单；向另一伙伴问答；写自己的短消息让接收者据此行动 | 改变人物、物品位置或用途，不只换背景图 |
| D：延迟迁移 | 听懂新请求并行动；主动说明自己的选择；为自己的布置写标签或短说明 | 不给完整答案；可请求重复，使用提示后如实记录 |

不是每个词都机械套十二题。动作词通过指令和执行复现，礼貌语通过请求与回应复现，位置词必须核对真实位置；功能词在已教句型里练习。读写负荷按词条目标安排，不要求初学者写尚未教过的句子。若标签、清单、消息接收或位置校验尚未实现，对应格保持“缺玩法”，不能用跟读代替并打勾。

180 个核心词至少需要 2160 个可验证的目标词使用机会。假设一个短互动平均验证两个明确目标，就是约 1080 次互动的内容容量；这只是规划算术，不是强制刷题次数或学习时长承诺。优先制作可复用、有结果的玩法，再为每个词审核自然变式，避免为凑数量堆出上千个同样的对话框。

每次回家以一件孩子关心的小事串起若干互动，例如“为宠物准备阅读角”：先问需要，再找书和椅子、实际摆放，最后留下自己写的标签。准备、误会、解决和成果构成小故事；词语在其中复现。完成后可以保留布置、再修改或换伙伴玩，而不是自动弹出下一套题。相关作品保存与消息玩法仍待实现。

### 全词表覆盖的交付门槛

1. 先为全部 180 词补齐教学入口与至少一个真实家园玩法，消除当前仍有核心词没有作者家园情境的缺口（最新快照见下表）；不因此宣布 L1 完成。
2. 逐词补齐 12 个机会、4 次会话、3 种情境的作者编排，并接入提示与技能证据。故事换标题、同句换声音、重复回调都不能作为新变式。
3. 调度必须从整个已教词表选择，包含已教但尚未成功练习的词。达到本次新词预算后继续玩旧词，不靠不断塞新词维持内容。
4. 当场有答案的练习可以按既有规则计 WordTree 有效练习，但进阶另看延迟回忆和新情境使用。某词不稳定就补它，不让孩子重刷整级。
5. 内容容量与实际表现分别展示给维护者：180 词中多少有入口、多少达到变式预算、多少缺听读／自主表达；不能以对话总数或 AI 可无限生成代替这些指标。

## 从 L1 到 L2 的规则（能力准备度）

区分“故事完成”“词语基本理解”“课程准备度”和“地图可进入”。地图仍可自由探索；教学推荐依据准备度调整，不强迫开麦，也不把学习认证当作世界通行证。

候选准备度规则如下，需儿童试玩后校准，尚未实现：

1. 完整核心词表全部有教学入口和覆盖记录；未学、未练、仅模仿的词明确显示，不能靠完成少量故事隐藏缺口。
2. 至少 90% 的核心词有跨会话、跨情境的稳定证据；其余进入 L2 持续复习。求助、停止、位置、需要等关键交流功能不得空缺。稳定证据暂定为至少 3 次会话、2 种情境的独立正确使用或理解，包含一次间隔至少 7 天的回忆；按词条的理解／表达目标判定，不要求每词都同时口述和拼写。
3. 通过[四技能出口任务](assessment.md)的候选要求：8 个生活任务、至少 2 次会话和 3 种情境，各技能有独立证据。反复抄同一句不能替代出口任务。
4. 没有麦克风或语音服务失败，仍可学习和探索；口语标为待验证，不能用打字结果冒充口语通过。已有基础的孩子可通过诊断取得准备度，不必强刷次数。

WordTree 的 10 次有效练习仍只标本地 `basic`，不改为上述准备度，也不直接授予掌握奖励。12 次内容机会、10 次 basic 与独立能力证据是三种不同口径。

## 实现与验收清单

- 完整核心词清单：来源、规范词条、理解／表达目标、引入故事、家园变式及缺口；按唯一词条统计，不把复数和词形重复算新词。
- 调度核心：覆盖全词表，保存间隔、错误和提示依赖；固定输入可复现；离线、换角色／语言和重新进入均正确恢复。
- 证据：关联现有 WordTree，补课程版本、技能、支持程度、情境、会话与回执；旧练习不能追溯伪造独立证据，重复回调不得重复计数。
- 内容检查：每个核心词满足机会预算，有自然的可执行变式；缺道具、动作或作者稿时显示缺口，不生成假完成。
- 玩家验证：孩子知道在帮谁、为何开口，愿意再次使用；统计提示依赖和隔次回忆，不能只看在线时长、点击量或当场正确率。
- RSI 未来每轮修一个覆盖缺口／不自然情境／遗忘问题，以未见变式验证；不通过降低标准、增加答案提示来提高分数。不自动启动循环。

当前调度已经有第一版到期复习和新词预算，详见下节；它仍不能证明逐词内容量或课程准备度。建设顺序：补齐英语 L1 每词教学与真实玩法 → 补足跨会话、跨情境变式 → 完善错误、提示与技能证据调度 → 出口验收与儿童试玩，再推广到其他语言。


## 已接入的复习调度第一版（2026-10-26）

新增 home_review_core，附在同一角色／目标语言的 WordTree 本地记录上，不另建掌握清单。只有已校验且未重复的家园练习回执更新复习信息；记录玩法、text／speech 次数、最近最多十二个作者来源和有效会话数。来源只是活动身份，不自动等同独立情境迁移，支持程度目前统一 unknown。

- 会话以两次有效家园练习之间至少 30 分钟的空隙划分；这是产品调度定义，不是“不同天”或能力证据。关闭／打开练习窗口、刷新页面或换另一座家园，不重置同角色同语言的当前会话。
- 每会话新词预算默认三个；实际首次完成后才占用。预算耗尽仍可玩已学词。最近最多 64 个已完成作者故事身份跨窗口保留，帮助轮换变式。
- 初次练习后约五分钟再次复习；只有另一次会话中到期完成，才逐步使用一天、三天、七天、十四天的间隔。同次到期复练仍只延后五分钟，不晋级间隔；未到期提前练习不推迟原复习日期。
