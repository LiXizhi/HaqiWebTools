# 家园食物道具与餐桌准备小委托

2026-10-26 作者稿，已接入 english-home-practice.json 的 en-l1-food-* 场景及家园 catalog.json。十二件真实可摆放道具：苹果、香蕉、橙子、梨、一碗米饭、完整鸡蛋、一盘熟鱼、一盘熟肉、烤鸡、一杯果汁、一瓶牛奶、一块面包。食物只为摆放与辨认道具，本轮不提供烹饪、消耗库存或宠物实际进食的新机制。

每个词安排六个有区别的入口：首次找物并解释含义；为早餐／午餐／野餐准备的复习找物；决定摆放位置并真实移动；在道具上写并保存自己的标签；读一行请求后选实物；听完请求再选实物。听读只用于已学词，隐藏听力原文并记录提示，必须存在其他种类的干扰物品。

水果和鸡蛋用 a/an；rice、meat、juice、milk、bread 作为不可数食物用 some；本轮 fish/chicken 指熟食，不宣称孩子已经掌握活鱼／小鸡的其他词义。orange 明确是橙子，不把颜色橙色当作该词条练习。

每轮只计一个目标；展示、播放和场景里的其他食物不附赠计数。第一次有三个新词预算，不能一次展示十二件就宣布全部学过。每词六个作者情境仍低于十二次跨会话使用目标，且完整菜单、来客和食物交付故事仍待接入。
