# 14 · 知（`zhī`）—— 矢口为知，一语中的（`hanzi_zhi.html`）

## 一、字源、训释与教学边界

1. **基本字义与读音**
   - 汉字：知；拼音：`zhī`；本义：知晓、明白，心有所悟而能敏锐道出。
   - 《说文解字·矢部》：“知，词也。从口从矢。”清·段玉裁注：“识敏，故出于口者疾如矢也。”意即心中真正透彻明白，脱口而出便如飞箭正中靶心般迅速准确。
   - 常用词与文化意象：`知道`、`知识`、`知音`（俞伯牙与钟子期高山流水遇知音）。
2. **古文字演进与楷书八笔**
   - **甲骨文 / 西周金文**：左（或上侧）为一支带锋镝与尾羽的箭「矢」，右（或下侧）为「口」，会“心明口敏、出言如矢中的”之意，亦为「智」之初文（后加「日/曰」分化出「智」）。
   - **小篆**：左「矢」修长劲挺，右「口」方正端凝。
   - **规范楷书（8 笔）**：
     - 左部「矢」（5 笔）：1. 撇 2. 横 3. 横 4. 撇 5. 点（原「矢」末笔为捺，入「知」字左旁时收敛化为**点**，礼让右部「口」，体现汉字结构“左右避让”之美）。
     - 右部「口」（3 笔）：6. 竖 7. 横折 8. 横。
   - 笔画轮廓与中线内联自 `skishore/makemeahanzi@bddc96d41bef78427ed0e034e9f7e31d71fd1b92` 的 `graphics.txt`（1024 字框，基线 900）。
3. **事实与艺术边界**
   - 页面准确呈现《说文》“从口从矢”的会意解说，用“心里想明白了，说出的话像箭一样又快又准”向儿童传达“认真观察、真正懂得”的道理。
   - 书院夜灯观察影子、回声与北极星的情节为原创互动故事，左下角注明字源依据与故事创作边界。

## 二、一句话主题

> 夜晚的竹简书院里，先静下心看清三道自然的谜题，当心里豁然明亮，说出口的答案便如金羽飞箭一击中的——左「矢」右「口」，就是「知」。
