# 把小故事搬进屋

英语L1家园位置词in。伙伴想把小故事搬到屋里讲，先放书，随后揭晓另一件会滚的道具是球；孩子分别回应Put it in.或In the room.，实际拖入房间的不同空位。结尾保留实际摆放结果，可以自由改造或邀请伙伴。首幕解释in是“在里面”，第二幕复用；另有书/球首次和回访各一情境。

这次明确目标只有in。room是辅助词义“房间”，尚未作为独立目标记录，不能把它算作已完成的核心词教学。书、球须已经练过，可通过既有准备入口先学。只说对不计，旋转、在外面移动或原地保存不计，真实位置改变且通过校验才累计一个明确词；不会顺带给book、ball或room增加次数。

首版房间识别支持连续完整矩形地板，长宽各3—16格，四周每个边界格有墙、门或窗，没有内部分隔墙。不要求屋顶或关门。缺格、缺边、只铺地板、围栏、缩放/自由摆放的边界及不规则多房间尚不支持。当前位置必须完整在边界内，距外沿至少四分之一格；家具还须通过原摆放规则。屋顶/桌面挂载、占墙边或仅部分进入不计。结构身份和位置冻结，本轮拆墙或替换构件后需重选。

纯核心home_room_core识别结构；home_position_core完成绑定及保存前重验；控制器共用原place真实move事件与WordTree回执。房间范围显示于地板上方，拖动时隐藏浮动编辑菜单，松手后恢复。没有新建另一套掌握状态，没有完成剧情就自动摆物品。

需继续补room独立教学、岛屿场景、更多跨日用途、听读辨认与自由表达；当前两步故事和独立回访不是足量四技能迁移证明。真实触屏、房间复杂形状和儿童试玩待验证。
