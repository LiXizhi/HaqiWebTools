# 椅子后面的球

英语 L1 连续家园故事。权威作者源 english-home-practice.json；核心词 behind，复习或介绍 ball、next to，前置 chair。使用现有球和椅子，不假造容器或 NPC 找物动画。

伙伴提出一个放球、找球的小游戏。孩子先选一个真实球；把它放到椅子后方；游戏结束后给同一个球选一个椅子旁边的位置，下次容易拿到。三步都先有伙伴开场，再回应、亲手操作。球不必完全被遮住，不做“明明看得见却假装消失”的剧情；伙伴只承认当前实际完成的摆放。

- D-home-behind-01：认识 ball，回答 A ball.，点选真实球。
- D-home-behind-02：认识 behind，回答 Behind the chair.（也接受 Behind.），把同一个球移到标出椅子后方的地面。
- D-home-behind-03：认识或复习 next to，回答 Next to the chair.（也接受 Next to it. / Next to.），把同一个球移到本轮标出椅子旁边。

“后方”采用从玩家视角看向场景的方向：参照物画面上侧，目标整体在后，横向投影有交集，地面间隔不超过两格，不重叠。不会把简单的左右、斜上方、桌面重叠或挂到参照物上当成 behind。每轮参照物身份、位置、尺寸冻结；移动、删除或替换参照物使旧答案失效。最终旁边步骤可以选本轮另一张椅子，不谎称跨步骤锁定了同一张椅子；球身份始终保留。

普通复习另有球／椅子、书／桌子的首次介绍及再次布置，共四段。尚不等同三种独立生活情境或每词十二次机会。under、in 仍需真实桌下／容器空间及渲染，保持未完成。真实语音、儿童空间词理解、独立听读找物与更丰富的藏物玩法待验收。
